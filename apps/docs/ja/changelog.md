# 変更履歴 {#changelog}

## Unreleased {#unreleased}

### 非推奨 {#unreleased-deprecated}

- **画像の目標サイズ圧縮オペレーション 5 件は非推奨になりました。** `/api/v1/tools/image/compress-image-to-20kb`、`-50kb`、`-100kb`、`-200kb`、`-500kb` は OpenAPI 仕様で非推奨としてマークされており、少なくとも 1 つのマイナーリリースの間は維持されます。`POST /api/v1/tools/image/compress` を送信し、`settings` に `{"mode":"targetSize","targetSizeKb":20}` (または 50、100、200、500) を設定してください。出力は同じです。PDF プリセットのパスは変更ありません。

## v2.3.0 {#v2-3-0}

SnapOtter の Docker Hub と GHCR での合計イメージプル数が 100 万回を超え、GitHub のスターも 3,000 に達しました。これだけ多くのセルフホストサーバーが動いているということです。このリリースは、運用してくださっているすべての方への感謝のしるしです。

早めのアップグレードをお勧めします。2.3.0 では 6 件のセキュリティアドバイザリーを解消しており、そのうち 1 件は重大度が高いものです。詳細は下の「セキュリティ」セクションをご覧ください。

修正に加えて、新しいツールもあります。PDF Multi-Tool のページエディター、画像と PDF のワンクリック目標サイズ圧縮プリセット、Organize PDF でのドラッグ&ドロップによるページ並べ替えです。OCR はアラビア語を読み取れるようになり、pdf-to-text はスキャンされた PDF に出会うと OCR を提案します。SnapOtter はリバースプロキシの背後で `/snapotter` のようなサブパス配下でも動作します。アプリの実行に Postgres のスーパーユーザーは不要になりました。ロックアウトされた管理者はコマンドラインから復旧できます。残りの約 1,400 件の修正は、そのほとんどがみなさんから報告いただいた問題に対するものです。

> [!IMPORTANT]
> 以下の 6 件のアドバイザリーはすべて 2.2.0 に影響し、一部は 2.0.0 までさかのぼります。インスタンスを他のユーザーと共有している場合や、自分のネットワークの外部に公開している場合は、アップグレードしてください。

### セキュリティ {#v2-3-0-security}

- **SVG のアップロードでサニタイズが省略される場合がありました (GHSA-9c7h-xjrp-8gh3、高)。** 画像デコーダーに拒否された SVG が、サニタイズされずにそのまま保存・配信されていました。影響範囲: 2.2.0 以前。@xaferima さんによる報告。(#1211)
- **ジョブの進捗ストリームがリクエスト元を確認していませんでした (GHSA-ff22-w6x2-fm98、中)。** サインインとジョブの所有権を要求するようになりました。影響範囲: 2.0.0 から 2.2.0。(#1750)
- **結果のダウンロードリンクから元のアップロードファイルも取得できました (GHSA-jgv3-2jc6-f628、中)。** 影響範囲: 2.2.0 以前。@emirhancatkin さんによる報告。(#3623)
- **証明写真と背景エフェクトが、クライアントから渡されたジョブ ID を信頼していました (GHSA-3c8g-8v4x-qq9j、中)。** 影響範囲: 2.2.0 以前。@shaoyuuuuu さんによる報告。(#3623)
- **URL インポート、アップロード、プレビューで、ロールと API キーの権限チェックが省略されていました (GHSA-8xxr-g2w8-7f9r、中)。** 影響範囲: 2.2.0 以前。@nguyenvantiennani さんによる報告。(#3780, #707)
- **SSO の強制により、緊急用ユーザー名が判別できました (GHSA-q6fg-vvw9-cr8r、低)。** 拒否されたローカルログインは、他の失敗したログインと同じ 401 を返すようになりました。影響範囲: 2.0.0 から 2.2.0。(#2148)
- **Postgres をスーパーユーザーで実行しなくなりました。** アプリはデータの読み取りと書き込みしかできないロールで接続するようになりました。マイグレーションには、別の任意の接続を使用します。「アップグレードに関する注意」をご覧ください。(#918)
- **依存関係のパッチ適用**: dompurify と handlebars のオーバーライドの下限を、修正済みバージョンに引き上げました。(#4247)

### 新機能 {#v2-3-0-new-features}

- **PDF Multi-Tool**: ページの並べ替え、複製、回転、削除ができ、他の PDF からページを取り込めるページエディターです。最終的なファイルはサーバーが組み立てます。(#1338)
- **ワンクリックで目標サイズに圧縮**: 画像用の 5 つのプリセット (20、50、100、200、500 KB) と、PDF 用の 5 つのプリセット (100、200、500 KB、1 MB、2 MB) があります。(#1250, #1377)
- **サブパス配下で SnapOtter を実行**: `BASE_PATH=/snapotter` を設定すると、同じイメージがそのパスで提供されます。結果のリンク、Cookie、SSO のリダイレクト、API ドキュメントもすべてそれに従います。(#1252, #1324)
- **アラビア語 OCR**: アラビア語を明示的に選択するか、自動モードに検出させることができます。画像 OCR と PDF OCR の両方で動作します。(#4130, #4183)
- **pdf-to-text が OCR を提案**: PDF、またはバッチ全体にテキストレイヤーがない場合に、空のファイルを返す代わりに OCR を提案します。(#4142, #4198)
- **Organize PDF でのドラッグ&ドロップによるページ並べ替え**: マウスでもタッチでも操作できます。(#1249, #2601)
- **複数ファイルの実行前にファイルを並べ替え**: merge、stitch、collage などの複数ファイルツールが、設定した順序を維持します。(#756, #757)
- **バッチとパイプラインの実行をキャンセル**: サーバー側の処理も実際に停止します。(#807)
- **`snapotter-admin` のリカバリーコマンド**: `reset-password`、`create-admin`、`unlock-user`、および MFA のリセットです。Web UI からロックアウトされた管理者のためのものです。(#4016)
- **ログイン時の MFA 登録**: MFA が必須の場合、未設定のユーザーはブロックされる代わりに、その場で設定できます。
- **カメラ撮影とインストール可能なアプリ**: モバイルで撮影した写真をそのままツールに渡せます。また、SnapOtter を PWA としてインストールできます。(#773)
- **エディターのキャンバスサイズダイアログで透明な余白を追加できます。** (#4111)
- **管理者向けのアップデート通知**: 新しい SnapOtter が公開されると、管理者にはリリースノートへのリンク付きで、閉じることのできる通知が表示されます。このチェックは既存のアナリティクス接続を通じて行われるため、アナリティクスがオフの場合は無効になります。

### 改善点 {#v2-3-0-improvements}

- **背景除去が 2 回目以降に高速化**: リクエストのたびに再読み込みせず、モデルがリクエスト間で読み込まれたままになります。(#4144)
- **バッチアップロードのメモリ使用量を大幅に削減**: 各ファイルを一時ディスクに置き、RAM に載せ続けずに 1 件ずつ処理します。(#2687)
- **AI バンドルのインストールが失敗時に適切に終了し、ロールバックされます**: 中途半端にインストールされた venv が残りません。Proxmox LXC での背景除去のインストールが再び動作するようになり、メモリの少ないホストでは、ジョブの開始前に適切な CPU 制限が設定されます。(#2628, #2597, #2526, #2546)
- **GPU の検出がより確実に**: CUDA はドライバー経由で検出され、RTX 50 シリーズのカードは失敗せずに CPU にフォールバックし、ハードウェア動画エンコーダーは使用前にテスト実行されます。(#4225, #4075, #3980, #3983)
- **`MAX_WORKER_THREADS` が機能するようになりました。** これまでは解析されるだけで、適用されていませんでした。(#3249)
- **長時間かかるツールには長いタイムアウトを適用**: pdf-to-word、compress-pdf、convert-document、コンテンツ認識リサイズが、大きなファイルで早すぎるタイムアウトを起こさなくなりました。(#3276)
- **Compress PDF はスキャンの可読性を維持**: 目標サイズに到達できない場合は、読めないファイルを生成せずにその旨を伝えます。(#4112)
- **失敗したログインをユーザー名ごとに制限**: 15 分間に 10 回を超えると、`Retry-After` 付きで 429 が返されます。(#827)
- **エラーが原因を具体的に伝えます**: バイナリの欠落、ストレージ障害、メモリ不足による強制終了、アップロード制限について、単なる 500 や 422 ではなく具体的なメッセージが表示されるようになりました。
- **監査ログがツール、バッチ、パイプラインの実行を対象に**: ユーザー、ロール、チーム、GDPR に関するイベントでは、誰が誰に何をしたかが記録されます。(#3991, #3984)
- **オールインワンコンテナは、最初の起動に失敗すると停止します**: 無限に再起動を繰り返さなくなり、組み込みの Postgres と Redis には起動の期限が設けられました。(#3008, #1130)
- **日付と複数形が言語に従います**: 残っていたハードコードされた英語の文字列も翻訳されました。
- **モバイルとエディターの改善**: スマートフォンでのスライダー、Sign PDF、切り抜きのレイアウト、タッチ操作でのドラッグ、ピクセルブラシの高速化、そして Levels と Curves の元に戻す操作と自動保存への対応です。

- **ライブラリへの自動保存がストレージ容量を無視していました**。ストレージのカウンターがマイナスになることもありました。(#2389, #2585)
- **再起動後に停止していたジョブ**は、起動時に整理されるようになり、「処理中」のまま表示され続けなくなりました。(#3219, #3193)

- **無効にしたパスワードルールが、ユーザー作成時に引き続き適用されていました。** (#1028)
- **破損した PDF で、失敗するまで 30 秒間ハングしていました。** (#920)
- **AI バンドルのディスクチェックが、1 つのバンドルのインストールに約 18 GB を要求していました。** (#1248)
- **Compress Video が、可変フレームレートの画面録画で失敗していました。** (#2427)

- **設定画面の数値フィールドが、入力中にクリアできませんでした。** (#1449)
- **アナリティクスをオフにしても、キューに残っていたイベントが約 30 秒後に送信されていました。** オプトアウトすると破棄されるようになりました。(#4270)

### アップグレードに関する注意 {#v2-3-0-upgrade-notes}

マイグレーションは起動時に自動で実行されます。SQL を実行する必要はありません。

- **データベースのロール。** 標準の Compose ファイルでは、アプリにデータの読み取りと書き込みしかできないロール (`DATABASE_URL`) と、起動時のマイグレーションと権限付与にのみ使用される別の特権接続 (`DATABASE_MIGRATION_URL`) が与えられるようになりました。既存の Compose ファイルは従来どおり動作します。`DATABASE_MIGRATION_URL` を未設定のままにすると、SnapOtter は 1 つのロールで動作します。ローカル以外のデプロイでは、`POSTGRES_PASSWORD` と合わせて `POSTGRES_APP_PASSWORD` を設定してください。
- **起動時のチェックが厳格になりました。** これまでは後から、または黙って失敗していたものが、変数名を示すメッセージとともにコンテナを停止させるようになりました。対象は、サポートされていない `DEFAULT_LOCALE` (`de_DE` ではなく `de` のようなサポートされているコードを使用)、SSO が有効な場合の不正な形式の `SAML_IDP_SSO_URL`、`SAML_CALLBACK_URL`、`OIDC_ISSUER_URL`、無効な `TRUST_PROXY` のリスト、不正な `BASE_PATH`、書き込みできない `LOG_DIR` です。
- **`TRUST_PROXY` はホップ数を受け付けなくなりました。** `TRUST_PROXY=2` のような数値を指定すると、プロキシを一切信頼しないまま黙って動作するのではなく、起動時にコンテナが停止します。プロキシのアドレスまたは名前付きの範囲を設定してください (デフォルトは `loopback,linklocal,uniquelocal`)。SnapOtter の前にプロキシがない場合は `false`、公開アドレス上に自分で管理するプロキシが前段にある場合にのみ `true` を設定します。(#998)
- **`MAX_WORKER_THREADS` が有効になりました。** これまで設定しても変化がなかった場合は、今後は反映されます。
- **API のステータスコード。** エンジンとストレージの障害は 503 `ENGINE_UNAVAILABLE` を返します (バッチのエンドポイントはこれまで 422 を返していました)。上限を超えたアップロードは 413 を返します (以前は 400)。不正な形式の `clientJobId` は 400、再利用されたものは 409 を返します (以前は 500)。自分のパイプラインバッチを再実行すると 202 を返します。`targetSizeKb` のない `mode=targetSize` は 400 を返します。SSO の強制下で拒否されたローカルログインは、403 `SSO_ENFORCED` ではなく 401 を返します。制限されたログインは 429 `LOGIN_THROTTLED` を返します。背景除去の結果に `originalUrl` が含まれなくなりました。
- **新しい任意の変数**: `BASE_PATH`、`DATABASE_MIGRATION_URL`、`GDPR_EXPORT_TIMEOUT_MS` (デフォルトは 15 分で、`0` で無効化)、`EMBEDDED_REDIS_TIMEOUT_S` (180)、`EMBEDDED_POSTGRES_TIMEOUT_S` (600) です。
- **Compose ファイルはリリースに同梱されます。** `docker-compose.yml` と `docker-compose-gpu.yml` がこのリリースに添付されているため、リリースページから直接ダウンロードできます。

## v2.2.0 {#v2-2-0}

2.2 の大半はハードニングです。委任された `users:manage` ロールを持つ管理者以外のユーザーがインスタンスを乗っ取れる問題があり、すべてのツールエンドポイントで権限チェックが欠けていました。複数のユーザーで運用している場合は、アップグレードしてください。

残りは、セルフホストにおける細かな問題の数々です。開始されたまま終わらないダウンロード、2 つ目のファイルを追加した途端に壊れるプリセット、Postgres がまだ起動中にクラッシュループを起こすコンテナなどです。新しいツールも 2 つ加わりました。ドキュメントと Web サイトは 21 言語に翻訳され、インターフェースもついに WCAG AA のコントラスト基準を満たしました。

> [!IMPORTANT]
> カスタムロールを通じて管理者以外に `users:manage` を付与していた場合、2.0.0 から 2.1.0 では、そのロールで管理者アカウントを乗っ取ることができました。詳細は「セキュリティ」をご覧ください。

### セキュリティ {#v2-2-0-security}

- **委任された `users:manage` ロールによる権限昇格 (GHSA-9xgh-95qh-2x7h)。** カスタムロールを通じて `users:manage` を持つ管理者以外のユーザーが、組み込みの管理者を含む、より高い権限のアカウントのパスワードをリセットしたり削除したりして、インスタンスを乗っ取れました。パスワードのリセットとアカウントの削除では、対象に対する呼び出し元の権限を確認するようになり、委任されたロールが自身のレベルを超えて操作できなくなりました。影響範囲: 2.0.0 から 2.1.0。李春来 (Chunlai Li) さんによる報告。(#616)
- **すべてのツールエンドポイントにアクセス制御を適用しました。** ツールへのアクセスはルートごとに強制されていたため、手書きの 45 のルートすべてが同じ呼び出しを忘れずに行う必要があり、実際には誰も行っていませんでした。`tools:use` のないロールでも、image-to-pdf、erase-object、upscale、sign-pdf などを実行できました。このチェックは、一致したルートをキーとする 1 つの preHandler に集約され、サブパスや今後追加されるルートも対象になります。(#646)
- **Docker のインストールでレート制限を回避できました。** イメージは `TRUST_PROXY=true` を指定した状態で提供されていたため、クライアント IP がリクエストヘッダーから取得され、偽装された `X-Forwarded-For` でログインの制限をすり抜けられました。デフォルトはプライベートネットワークの信頼リストになりました。(#649)
- **設定の書き込みは、入口で一度だけではなく、設定ごとに確認されます。** また、設定のインポートはトランザクションになり、拒否されたキーによって設定が中途半端に適用されることがなくなりました。(#618)
- **ライブラリのファイル名が保存先のルートの外に出られなくなりました。** 悪意のある 1.x の SQLite インポートがそのままコピーする細工された保存名によって、ファイルディレクトリの外のファイルを読み取ったり削除したりできました。この経路に到達できるのは、運用者が攻撃者の用意した 1.x の SQLite データベースをインポートした後だけです。保存名を選べる唯一の経路だからです。@Alpastx さんによる報告。(GHSA-55w2-8cqf-w969, #600)
- **ジョブのキャンセルで所有権を確認するようになりました。** 認証済みのユーザーが、ID を指定して他のユーザーのジョブをキャンセルすることはできなくなりました。@Alpastx さんによる報告。(GHSA-wqxf-gj2p-689x, #599)
- **2.0 のツリー全体を再監査し、残っていた問題を洗い出しました**: 取得された SAML アサーションを再利用できたこと、MFA のチャレンジが何度誤ったコードを入力しても有効なままだったこと、リクエストごとの API キーの検索がテーブル全体のスキャンだったこと、`MAX_WORKSPACE_SIZE_GB` が機能しない設定だったこと、そして SVG サニタイザーが引用符なしの `javascript:` の href を通していたことです。(#620)
- **公開済みの 9 件の CVE にパッチを適用しました**: fast-uri、svgo、sharp、tar (推移的な依存関係として) (#619)、および Pillow 12.3.0 (#517) です。arm64 での RAW デコードは、パッチ未適用のシステムのコピーをリンクする代わりに、LibRaw 0.22.2 をソースからビルドするようになりました。(#649)

### 新機能 {#v2-2-0-new-features}

- **Rounded Crop**: 角丸の正方形と iOS 風のスクワークルのマスクを、角の半径のコントロール付きで提供します。favicon やアプリアイコン向けです。(#602)
- **Remove GIF Background**: アニメーション GIF、WebP、APNG の背景をフレームごとに除去し、透明なアニメーションを取得できます。(#502)
- **Object Eraser の投げ縄と高品質モード**: すべてのピクセルをなぞる代わりに、自由な形のループをドラッグできます。さらに、広い範囲をよりきれいに塗りつぶすために、拡散モデルによるインペインティングのバンドルを任意でインストールできます。(#503, #566)
- **新規として保存するか、上書きするか。** ライブラリのファイルを編集すると、これまでは黙って元のファイルが置き換えられていました。今後は編集のたびに選択でき、デフォルトでは元のファイルが残ります。(#564, #577)
- **Resize のアスペクト比プリセット。** 1:1、4:3、16:9 を選ぶと、拡大せずに 2 つの寸法が固定されます。(#530)
- **2 段階の OCR**: 高速な段階はイメージに組み込まれ、ダウンロードなしでオフラインで動作します。より精度の高いランタイムは、必要に応じてインストールされます。(#519)
- **どこでも入力して検索。** ダッシュボードやホームページで入力を始めると、検索ボックスに入力されます。(#644)
- **ドキュメントと Web サイトが 21 言語に対応**: ドキュメントサイト、ランディングページ、API リファレンスのすべてが翻訳され、アプリのインターフェースと並びました。新しい低リソース向けのデプロイガイドでは、Raspberry Pi や 2 GB のマシンについて説明しています。(#548)
- **より分かりやすいツール名**: あいまいだった 18 のツール名を明確にしました。たとえば「Compress」は「Compress Image」になりました。ツール ID とルートは変わらないため、ブックマークは壊れません。(#520)

### 改善点 {#v2-2-0-improvements}

- **インターフェース全体で WCAG AA のコントラストに対応**: パレットを調整し、鮮やかなオレンジは塗りに限定して、テキストとラベルにはアクセシブルなインクトークンを使用するようにしました。57 のフォーカスインジケーターすべてが、非テキストの 3:1 の基準を満たしています。(#567, #574)
- **Upscale と背景除去が固まったように見えなくなりました**: 進捗バーは 30% で止まらず、推論中も進むようになりました。どちらのツールも、CPU のみのホストでは大幅に遅くなることを警告します。(#605, #608)
- **タイムアウトのメッセージが本当の原因を示します**: CPU のみのホストを考慮し、アップロードのせいにしなくなりました。(#596)
- **SnapOtter は起動時に Postgres と Redis を待ちます**: クラッシュループを起こしません。Compose でもオールインワンイメージでも同様です。Proxmox LXC でのインストールでは、この修正前に 76 回再起動していました。(#537, #595)
- **ダウンロードがリバースプロキシを越えて完了します**: SnapOtter は nginx および互換プロキシに、ファイルのレスポンスをバッファリングしないよう要求します。これが、セルフホスト環境でダウンロードが開始されたまま終わらない典型的な原因でした。(#604, #607)
- **Compress PDF は目標サイズに近づきます**: 目標に届かない場合は、その旨を正直に伝えます。(#522)
- **モバイルのツールコントロールに常に手が届きます**: アプリのシェルが動的ビューポートに合わせたサイズになったためです。(#559)
- **Convert Audio にサンプルレートの設定を追加しました。** (#561)
- **管理者が最小パスワード長を緩和できます**: 信頼できる LAN のインスタンスでは 1 まで下げられます。(#543)
- **MFA をセルフサービスで利用できます**: ポリシーによるロックアウトは解消され、OIDC または SAML のログインでも、強制ブロックではなく本来の MFA チャレンジが表示されます。(#531, #536)
- **単なる `Error: Error` でも原因が分かるようになりました。** sharp のエンコード失敗、AI サイドカーの終了、ドキュメントサイドカーの非 JSON 出力、背景除去の失敗では、これまで理由が削除された状態で届いていました。(#532, #534, #535, #538, #612)
- **ヘルプダイアログを翻訳しました。** ショートカットのラベルと使い始めのテキストはハードコードされた英語で、完成した翻訳が 21 のロケールファイルすべてに使われないまま残っていました。(#647)

### アップグレードに関する注意 {#v2-2-0-upgrade-notes}

移行作業は不要ですが、出荷時のデフォルトが 2 つ変わりました。

- **`TRUST_PROXY` のデフォルトが `loopback,linklocal,uniquelocal` になりました。** すべてのピアを信頼する設定ではなくなりました。Docker のブリッジネットワークと Compose のネットワークはこの範囲に含まれるため、ほとんどの構成では変更は不要です。リバースプロキシが公開アドレスから SnapOtter に接続する場合は、`TRUST_PROXY` を明示的に設定してください。そうしないと、レート制限と監査ログがすべてのリクエストをプロキシからのものとして扱ってしまいます。
- **`MAX_AI_JOBS_PER_USER` のデフォルトは 5 です。** これは、ユーザーごとの処理中の単一ファイル AI ジョブの数です。バッチとパイプラインでの AI の実行には上限がありません。

新しい任意の設定項目: `DB_STARTUP_TIMEOUT_MS`、`SUBPROCESS_MEMORY_LIMIT_MB` (デフォルトではオフ)、`GIF_BG_MAX_FRAMES`。

## v2.0.0 {#v2-0-0}

SnapOtter 2.0 は、画像ツールキットを完全なファイル操作スイートへと発展させます。5 つのモダリティ (画像、動画、音声、PDF、ファイル) にわたる 200 以上のツールを備え、Postgres 17 と Redis ベースのジョブキューで再構築され、1 コマンドの `docker run` で起動できます。これはメジャーリリースです。1.x からアップグレードする前に、「破壊的変更」をお読みください。

### 新機能 {#new-features}

- **4 つの新しいツールのモダリティ**: 動画、音声、PDF、ファイルが画像に加わり、ツールのカタログは 200 以上になりました。
- **耐久性のあるバックグラウンドジョブ**: Redis ベースのキュー (BullMQ) が、すべてのツールを追跡可能なジョブとして実行し、SSE でリアルタイムに進捗を伝えます。
- **オールインワンの単一コンテナモード**: 1 つの `docker run` で、組み込みの Postgres と Redis を備えた完全なインスタンスが起動します。
- **オンデマンドの AI バンドル**: 背景除去、OCR、文字起こし、アップスケール、顔の検出と補正、オブジェクトの消去、カラー化、写真の修復を UI からインストールできます。GPU アクセラレーションはフレームワークごとに検出されます。
- **Sign PDF**: 署名を描画、入力、またはアップロードして、ブラウザー上で PDF に配置できます。
- **Automate**: ツールを連結するビジュアルなパイプラインビルダーで、9 つの用意済みテンプレートがあります。
- **83 のワンクリック変換プリセット**: JPG から PNG、MP4 から GIF などの専用コンバーターで、あいまい検索に対応しています。
- **レイヤーベースの画像エディター**: `/editor` にある Konva ベースのエディターで、ブラシ、図形、調整、フィルター、カーブを備えています。
- **ファイルライブラリ**: あらゆる結果を保存して、別のツールの入力として再利用できます。
- ピン留めしたツール、キャンバス内でのズームとパン、21 言語、そしてエンタープライズ向け機能 (OIDC/SSO、SAML、SCIM、S3 ストレージ、ツールごとの権限、監査のエクスポート、分散トレーシング) があります。

### 改善点 {#improvements}

- 実行中の処理をキャンセルできます。(#137)
- DNG を含め、LibRaw による RAW のフル解像度デコードに対応しました。(#289)
- 非 root および外部 UID でのデプロイに対応しました (TrueNAS、Unraid、OpenShift、PUID/PGID)。(#230, #127)
- AI のインストール検出が正確になり、インストールの流れが強化されました。(#214, #352)
- プライバシーの強化: サードパーティへの自動的な外部通信はなく、任意の厳格なオフラインモードがあります。
- アナリティクスがオフでも、フィードバックボタンは常に表示されます。

### バグ修正 {#bug-fixes}

- `RATE_LIMIT_PER_MIN=0` で、ツールのルートに対するレート制限が再び無効になります。(#271)

- **AI キャンバス拡張** - AI による塗りつぶしで、画像の境界を広げます。GPU の使用時間とのトレードオフに応じて、3 つの品質段階 (高速、バランス、高品質) があります。

## v1.14.0 {#v1-14-0}

GPU の自動検出に対応した統合 Docker イメージです。1 つのイメージで CPU と GPU の両方のワークロードを処理できます。Compose を、ログローテーション付きの単一ファイルに簡素化しました。モデルの事前ダウンロードには、検証とスモークテストが含まれるようになりました。

---

## v1.13.0 {#v1-13-0}

ロールベースのアクセス制御 (RBAC)。14 のきめ細かな権限、3 つの組み込みロール (admin、editor、user)、カスタムロールのサポートがあります。すべての API ルートで権限チェックを行います。フロントエンドのタブは、ユーザーの権限に応じて絞り込まれます。

---

## v1.12.0 {#v1-12-0}

PDF to Image ツール。PDF のページを、任意の DPI で PNG、JPEG、WebP、TIFF に変換します。GPU の自動検出に対応した統合 Docker イメージです。

---

## v1.11.0 {#v1-11-0}

AI に適したドキュメントのために、vitepress-plugin-llms による llms.txt の自動生成を追加しました。

---

## v1.10.0 {#v1-10-0}

顔の保護に対応したコンテンツ認識リサイズ (シームカービング)。重要な内容を保ったまま画像をリサイズします。

---

## v1.9.0 {#v1-9-0}

Stitch / Combine ツール。画像を左右に、上下に、またはカスタムのグリッドで結合します。

---

## v1.8.0 {#v1-8-0}

Edit Metadata ツール。EXIF、IPTC、XMP のメタデータを、削除/保持を細かく選べるインターフェースで表示および編集します。
