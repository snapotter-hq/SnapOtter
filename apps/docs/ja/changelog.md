# 変更履歴 {#changelog}

## v2.2.0 {#v2-2-0}

2.2 の大部分は堅牢化です。委任された `users:manage` ロールを持つ非管理者がインスタンスを乗っ取ることができ、さらにすべてのツール エンドポイントで権限チェックが欠けていることが判明しました。複数ユーザーで運用している場合はアップグレードしてください。

残りはセルフホスティングの細かな不具合です。開始したまま終わらないダウンロード、2 つ目のファイルを追加した瞬間に壊れるプリセット、Postgres の起動中にクラッシュループするコンテナなど。新しいツールも 2 つ追加されました。ドキュメントとウェブサイトは 21 言語に翻訳され、インターフェースはついに WCAG AA のコントラスト基準を満たします。

> [!IMPORTANT]
> カスタム ロールで非管理者に `users:manage` を付与していた場合、そのロールは 2.0.0 から 2.1.0 で管理者アカウントを乗っ取ることができました。詳細はセキュリティの項にあります。

### セキュリティ {#v2-2-0-security}

- **委任された `users:manage` ロールによる権限昇格（GHSA-9xgh-95qh-2x7h）。** カスタム ロールを通じて `users:manage` を持つ非管理者が、より高い権限のアカウント（組み込みの管理者を含む）のパスワードをリセットしたり削除したりして、インスタンスを乗っ取ることができました。パスワード リセットとアカウント削除は、呼び出し元が対象に対して持つ権限を検証するようになったため、委任されたロールが自身のレベルを超えることはできません。影響範囲: 2.0.0 から 2.1.0。報告: 李春来 (Chunlai Li)。(#616)
- **すべてのツール エンドポイントがゲートされるようになりました。** ツールへのアクセスはルートごとに強制されていたため、手書きの 45 ルートすべてが同じ呼び出しを書く必要がありましたが、どれも実装していませんでした。`tools:use` を持たないロールでも image-to-pdf、erase-object、upscale、sign-pdf などを実行できました。チェックはマッチしたルートをキーにした単一の preHandler に移されたため、サブパスや今後追加されるルートもカバーされます。(#646)
- **Docker インストールではレート制限を回避できました。** イメージは `TRUST_PROXY=true` を出荷していたため、クライアント IP がリクエスト ヘッダーから取得され、偽造した `X-Forwarded-For` でログインのリミッターをすり抜けられました。デフォルトはプライベート ネットワークの信頼リストになりました。(#649)
- **設定の書き込みは入り口で一度ではなく、設定ごとにチェックされます**。設定のインポートもトランザクション化されたため、拒否されたキーが中途半端な設定を残すことはありません。(#618)
- **ライブラリのファイル名はストレージ ルートの外に出られません。** 細工された保存名（悪意ある 1.x SQLite インポートがそのままコピーするもの）によって、files ディレクトリの外のファイルを読み取ったり削除したりできました。到達可能なのは、攻撃者が用意した 1.x SQLite データベースを運用者がインポートした場合だけで、保存名を選べるのはその経路だけです。報告: @Alpastx。(GHSA-55w2-8cqf-w969, #600)
- **ジョブのキャンセルで所有権が強制されます**。認証済みユーザーが他人のジョブを ID でキャンセルすることはできなくなりました。報告: @Alpastx。(GHSA-wqxf-gj2p-689x, #599)
- **2.0 コードベース全体の再監査で、まだ開いていた問題が見つかりました**: 傍受した SAML アサーションを再生できること、誤ったコードを何度入力しても突破できる MFA チャレンジ、リクエストごとの API キー検索がテーブル全体のスキャンになっていたこと、機能していない `MAX_WORKSPACE_SIZE_GB` 設定、そして SVG サニタイザーが引用符なしの `javascript:` href を通していたこと。(#620)
- **公開済み CVE を 9 件修正**: fast-uri、svgo、sharp、tar の推移的依存 (#619)、および Pillow 12.3.0 (#517)。arm64 での RAW デコードは、未修正のシステム コピーにリンクする代わりに LibRaw 0.22.2 をソースからビルドするようになりました。(#649)

### 新機能 {#v2-2-0-new-features}

- **角丸クロップ**: 角丸スクエアと iOS 風のスクワークル マスク、角の半径コントロール付き。ファビコンとアプリアイコン向けに作られました。(#602)
- **GIF の背景除去**: アニメーション GIF、WebP、APNG からフレームごとに背景を除去し、透明なアニメーションとして返します。(#502)
- **オブジェクト消去の投げ縄と高品質モード**: すべてのピクセルを塗る代わりに自由な輪を描け、オプションで拡散インペインティング バンドルをインストールして大面積をよりきれいに埋められます。(#503, #566)
- **新規保存または上書き。** ライブラリのファイルを編集すると、以前は元ファイルが黙って置き換えられていました。編集ごとに選択できるようになり、デフォルトでは元ファイルが保持されます。(#564, #577)
- **リサイズのアスペクト比プリセット。** 1:1、4:3、16:9 を選ぶと 2 つの寸法がロックされ、アップスケーリングは行われません。(#530)
- **2 段階の OCR**: 高速ティアはイメージに組み込まれ、ダウンロードなしでオフライン動作します。より高精度なランタイムはオンデマンドでインストールできます。(#519)
- **どこでも入力して検索。** ダッシュボードやホームページで入力を始めると、そのまま検索ボックスに入力されます。(#644)
- **ドキュメントとウェブサイトの 21 言語対応**: ドキュメント サイト、ランディング ページ、API リファレンスがすべて翻訳され、アプリのインターフェースに加わりました。Raspberry Pi と 2 GB マシンを扱う低リソース環境のデプロイ ガイドも新しく追加されています。(#548)
- **わかりやすいツール名**: あいまいだった 18 の名前が自己説明的になり、「Compress」は「Compress Image」になりました。ツール ID とルートは変わらないため、ブックマークは壊れません。(#520)

### 改善点 {#v2-2-0-improvements}

- **インターフェース全体で WCAG AA コントラスト**: パレットが調整され、鮮やかなオレンジは塗りに残しつつ、テキストとラベルはアクセシブルなインク トークンを使用します。57 個のフォーカス インジケーターすべてが非テキストの 3:1 基準を満たすようになりました。(#567, #574)
- **アップスケールと背景除去が固まって見えなくなりました**: 推論中もプログレス バーが 30% で止まらずに進み、どちらのツールも CPU のみのホストでは大幅に遅くなることを警告します。(#605, #608)
- **タイムアウト メッセージが実際の原因を示します**。アップロードのせいにせず、CPU のみのホストを考慮します。(#596)
- **SnapOtter は起動時に Postgres と Redis を待つようになりました**。Compose でもオールインワン イメージでも同様で、クラッシュループしません。ある Proxmox LXC インストールでは、これ以前に 76 回再起動していました。(#537, #595)
- **ダウンロードがリバース プロキシを越えて生き残ります**: SnapOtter は nginx および互換プロキシにファイル応答をバッファリングしないよう要求します。セルフホストのダウンロードが始まって終わらない通常の原因はこれでした。(#604, #607)
- **Compress PDF が目標サイズに近づくようになりました**。到達できない目標には正直にそう伝えます。(#522)
- **モバイルのツール コントロールが届くようになりました**。アプリのシェルがダイナミック ビューポートにサイズ設定されるようになったためです。(#559)
- **Convert Audio がサンプルレート設定を公開しました。** (#561)
- **管理者が最小パスワード長を緩和できるようになりました**。信頼できる LAN インスタンスでは 1 まで下げられます。(#543)
- **MFA がセルフサービスになりました**。ポリシーによるロックアウトも解消され、OIDC または SAML ログインでもハード ブロックではなく実際の MFA チャレンジが表示されます。(#531, #536)
- **単なる `Error: Error` が原因を示すようになりました。** Sharp のエンコード失敗、AI サイドカーの終了、JSON でないドキュメント サイドカーの出力、背景除去の失敗は、これまで理由が削り取られた状態で届いていました。(#532, #534, #535, #538, #612)
- **ヘルプ ダイアログが翻訳されました。** ショートカット ラベルと getting-started のテキストは英語でハードコードされていましたが、21 のロケール ファイルには完成した翻訳が未使用のまま存在していました。(#647)

### バグ修正 {#v2-2-0-bug-fixes}

- **変換プリセットが 2 つ目のファイルで失敗しました**: jpg-to-pdf とその image-to-pdf 系、さらに pdf-to-png、pdf-to-jpg、pdf-to-tiff は、2 つのファイルをアップロードすると `Tool not found` を返していました。(#633, #643)
- **PDF 変換プリセットのダウンロード ボタンが失われていました。** (#629)
- **無制限の処理タイムアウトが尊重されていませんでした**。停滞した進捗ストリームも、インターフェースを待たせ続ける代わりに復旧するようになりました。(#638)
- **保存されたファイルが記録された長さより短い場合、ダウンロードが失敗せずにハングしていました。** (#617)
- **PDF ページ ツールが短いファイルと暗号化ファイルで失敗しました**: Remove Pages は 6 ページ未満のドキュメントには存在しないページ範囲をデフォルトにし、パスワード保護された PDF はワーカー内部で不可解に失敗していました。(#594)
- **PDF to Text がスキャン PDF で黙って空のファイルを返していました。** OCR を案内するようになり、テキストは UTF-8 で提供されます。(#603)
- **PDF to Word**: 色付きのテキスト ブロックを落とし、ページ全体に分割していました。(#500)
- **Object Eraser**: ゴースト状の残骸を残し、高解像度画像の小さなオブジェクトをぼかしていました。(#501)
- **Stabilize Video が faststart なしで再生できない出力を書き出していました。** (#593)
- **画像エディタの修正**: 回転、反転、リサイズ、レベル、カーブ、フィルター、レイヤー ロック。(#597)
- **Sign PDF が PDF の読み込み失敗理由を報告する代わりに空白のキャンバスを表示していました。** (#545)
- **ファイル ライブラリ**: 0x0 の寸法を記録し、HEIC、RAW、PSD のアップロードでプレビューをスキップしていました。(#636, #637)
- **複数の AI バンドルのインストール**: 共有 virtualenv が複数バージョン混在になり、3 つのツールが静かに壊れていました。(#649)
- **品質 1〜4 での JXL 変換**: 500 を返し、ffmpeg が見つからない場合は破損したアップロードとして報告されていました。(#649)
- **一時的な Postgres 障害**: 完了済みジョブを置き去りにし、出力がディスク上に残ってもそれを指す行がありませんでした。レコンサイラーがその作業を破棄せず引き継ぐようになりました。(#649)
- **アドレスが変わった Redis エンドポイント**: すべてのコンシューマーを詰まらせ、その間もヘルスチェックは 200 を返していました。(#649)
- **ウェブサイトとドキュメントの修正**: ローカライズされたリンクが `#` フラグメントを落としたり `zh-CN` を小文字化したりしなくなり、ドキュメントのナビはタブレットでもビューポート内に収まり、どちらのサイトもブラウザから GitHub API を呼び出さなくなりました。(#516, #562, #570, #560)

### アップグレード ノート {#v2-2-0-upgrade-notes}

移行作業はありませんが、出荷時のデフォルトが 2 つ変わりました:

- **`TRUST_PROXY` のデフォルトが `loopback,linklocal,uniquelocal` になりました**。すべてのピアを信頼する代わりです。Docker ブリッジと Compose ネットワークはこの範囲に含まれるため、ほとんどの構成では変更不要です。リバース プロキシが公開アドレスから SnapOtter に到達する場合は、`TRUST_PROXY` を明示的に設定してください。そうしないと、レート制限と監査ログがすべてのリクエストをプロキシに帰属させます。
- **`MAX_AI_JOBS_PER_USER` のデフォルトが 5 になりました**。ユーザーあたり同時実行中の単一ファイル AI ジョブ数です。バッチおよびパイプラインの AI 実行に上限はありません。

新しいオプション設定: `DB_STARTUP_TIMEOUT_MS`、`SUBPROCESS_MEMORY_LIMIT_MB`（デフォルトでオフ）、`GIF_BG_MAX_FRAMES`。

## v2.0.0 {#v2-0-0}

SnapOtter 2.0 は、画像ツールキットを本格的なファイル操作スイートへと進化させます。5 つのモダリティ（画像、動画、音声、PDF、ファイル）にまたがる 200 以上のツールを、Postgres 17 と Redis ベースのジョブキュー上に再構築し、ワンコマンドの `docker run` を実現しました。これはメジャーリリースです。1.x からアップグレードする前に、破壊的変更をお読みください。

### 新機能 {#new-features}

- **4 つの新しいツールモダリティ**: 動画、音声、PDF、ファイルが画像に加わり、カタログは 200 以上のツールに拡大しました。
- **永続的なバックグラウンドジョブ**: Redis ベースのキュー（BullMQ）が、すべてのツールをトラッキング可能なジョブとして実行し、SSE によるライブ進捗を提供します。
- **オールインワンのシングルコンテナモード**: 1 つの `docker run` で、Postgres と Redis を組み込んだ完全なインスタンスが起動します。
- **オンデマンドの AI バンドル**: 背景除去、OCR、文字起こし、アップスケーリング、顔検出と顔補正、オブジェクト消去、カラー化、写真復元を UI からインストールできます。GPU アクセラレーションはフレームワークごとに検出されます。
- **Sign PDF**: 署名を手書き、入力、またはアップロードし、ブラウザ上で PDF に配置できます。
- **Automate**: ツールを連結するビジュアルなパイプラインビルダー。9 つのプリセットテンプレートを備えています。
- **83 のワンクリック変換プリセット**: JPG-to-PNG、MP4-to-GIF などの専用コンバーターと、あいまい検索。
- **レイヤーベースの画像エディタ**: `/editor` にある Konva 搭載のエディタ。ブラシ、シェイプ、調整、フィルター、カーブを備えています。
- **ファイルライブラリ**: 任意の結果を保存し、別のツールの入力として再利用できます。
- ピン留めツール、キャンバス内でのズームとパン、21 言語、そしてエンタープライズ機能（OIDC/SSO、SAML、SCIM、S3 ストレージ、ツール単位の権限、監査ログのエクスポート、分散トレーシング）。

### 改善点 {#improvements}

- 実行中の処理をキャンセルできるようになりました。(#137)
- LibRaw を通じたフル解像度の RAW デコード（DNG を含む）。(#289)
- 非 root および外部 UID でのデプロイ（TrueNAS、Unraid、OpenShift、PUID/PGID）。(#230, #127)
- 正確な AI インストール検出と、強化されたインストールフロー。(#214, #352)

### 破壊的変更 {#breaking-changes}

2.0 では、組み込みの SQLite データベースを Postgres 17 に置き換え、ジョブキュー用に Redis 8 を追加しました。1.x のデータは初回起動時に自動的に移行されますが、コンテナスタックが変更されているため、まず `/data` ボリューム全体をバックアップしてください（1.x は SQLite を WAL モードで実行するため、コミット済みのデータは通常 `snapotter.db-wal` に存在します）。その後、シングルコンテナイメージ（組み込み Postgres と Redis、root のみ）または Compose スタック（アプリと Postgres 17、Redis 8）を選択してください。[移行ガイド](https://github.com/snapotter-hq/SnapOtter/blob/main/MIGRATING.md) と [アップグレードガイド](/ja/guide/upgrading) を参照してください。

## v1.17.0 {#v1-17-0}

5 つの新ツール、本格的な画像エディタ、SSO ログイン、20 言語。おそらく 3 つの別々のリリースにすべきでしたが、こうなりました。

### 新機能 {#new-features-3}

- **画像エディタ** - レイヤー、ブラシ、シェイプ、調整、フィルター、カーブ、キーボードショートカット。ブラウザ内で動作し、処理はあなたのハードウェアで行われます。
- **OIDC / SSO 認証** - Google、GitHub、Okta、または任意の OpenID Connect プロバイダーでログインできます。いくつかの環境変数を設定すれば、チームは既存のアカウントを使えます。
- **ミームジェネレーター** - opentype.js によるテキストレンダリングに対応した 100 の組み込みテンプレート。独自の画像をアップロードすることもできます。
- **Beautify** - スクリーンショットを入れると、洗練された画像が出てきます。デバイスフレーム（macOS、Windows、ブラウザ）、シャドウ、グラデーション、ソーシャルメディア用プリセット。
- **色覚異常シミュレーション** - 1 型色覚（protanopia）、2 型色覚（deuteranopia）、3 型色覚（tritanopia）などの色覚特性で画像がどう見えるかをプレビューできます。
- **PNG 透明度修正ツール** - 偽の透過 PNG を検出し、BiRefNet HR マッティングで修正します。LaMa インペインティングによるウォーターマーク除去はオプションです。
- **AI キャンバス拡張** - AI フィルで画像の境界を拡張します。GPU 時間をどれだけ費やすかに応じて 3 つの品質ティア（fast、balanced、quality）を選べます。
- **20 言語** - アラビア語、中国語（簡体字/繁体字）、チェコ語、オランダ語、フランス語、ドイツ語、ヒンディー語、インドネシア語、イタリア語、日本語、韓国語、ポーランド語、ポルトガル語、ロシア語、スペイン語、タイ語、トルコ語、ウクライナ語、ベトナム語。アラビア語では RTL が機能します。
- **URL インポート** - ドロップゾーンに URL を貼り付けるか、リストから一括インポートできます。SSRF 保護付きのサーバーサイドフェッチ。
- **複数ファイルの消しゴム** - 複数の画像にまたがって消去マスクを描き、ワンクリックですべて処理できます。ストロークは画像ごとに保持されます。
- **パイプラインのインポート/エクスポート** - ツールチェーンを JSON として保存し、他の人と共有できます。
- exiftool による **17 の新しいカメラ RAW フォーマット**、さらに QOI、JP2、EPS、DDS、CUR、DPX、FITS、PPM/PGM/PBM、SVGZ、APNG の入力に対応。BMP、ICO、JP2、QOI の新しい出力コーデック。以前失われたブランチから AVIF、TIFF、GIF、JXL、PSD のエクスポートを復旧しました。

### 改善点 {#improvements-2}

- **画像補正** - 古いパイプラインを CLAHE + normalise + gamma に置き換えました。新しい Deep Enhance トグルは、より積極的な結果を得るために AI モデルを使用します。
- **写真復元** - 8 方向の Otsu フィルタリングでスクラッチ検出を書き直しました。LaMa インペインティングがネイティブ解像度で実行されるようになりました。
- **どこでもエキゾチックフォーマット** - OCR、image-to-PDF、ファビコンジェネレーター、合成、スティッチ、ベクター化のすべてが HEIC、RAW、PSD をデコードできるようになりました。
- **圧縮** - ターゲットサイズの許容誤差を 5% から 1% に厳しくしました。ターゲットサイズがデフォルトモードになりました。ステッパーボタンと KB/MB の単位セレクターを追加しました。
- **Sentry のクリーンアップ** - 対応不要なイベント 644 件をフィルタリングしました。実際のエラーは適切に処理されるようになりました。
- **GPU 検出** - CUDA は存在するが nvidia-smi がないコンテナ向けに、診断を改善しました。
- **認証無効モード** - 匿名ユーザーが admin ロールで DB にシードされます。API キー、パイプライン、ユーザーファイルが FK 制約で壊れなくなりました。
- 単体、統合、E2E にわたる **2,705 以上の新しいテスト**。

### バグ修正 {#bug-fixes-3}

- CPU でのアップスケールが、NAS 機器や低電力ハードウェアでタイムアウトしなくなりました。
- QR コードのロゴでプレビューが永久に消えることがなくなりました。
- 縦長のポートレート画像でのクロップのオーバーフローを修正しました。
- TIFF アルファファイルが、破損を生じさせる代わりに正しく PNG 出力を強制するようになりました。
- HDR/EXR のデコードが CLAHE の前に 8 ビットへ変換されるようになり、デコード失敗を修正しました。
- 顔ランドマークの入力バッファが Python サイドカーの前に PNG へ変換されるようになり、クラッシュを修正しました。
- 重複検出が、混在フォーマットのバッチとネットワークエラーを処理できるようになりました。
- Beautify のプレビューがリアルタイムで更新されるようになりました。
- スティッチとベクター化の進捗バー。
- SVGZ を SVG-to-raster で処理するようにしました。
- 非 ASCII のファイル名を、パーセントエンコードされた X-File-Results ヘッダーで修正しました。
