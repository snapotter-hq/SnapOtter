# エラーコード {#error-codes}

すべての JSON エラーレスポンスは同じ形式です。

```json
{
  "error": "Job not found",
  "code": "NOT_FOUND",
  "requestId": "req-42"
}
```

| フィールド | 常に存在 | 意味 |
|-------|----------------|---------|
| `error` | はい | 人が読めるメッセージです。ユーザーに表示しても問題ありません。パースしないでください。 |
| `code` | はい | 安定した機械可読なコードです。分岐にはこれを使います。 |
| `requestId` | はい | このリクエストに対するサーバー側の ID です。問題を報告するときに添えてください。サーバーログと一致します。 |
| `details` | 場合による | 一部の 4xx エラーに付く追加情報です。たとえばバリデーションメッセージです。 |

メッセージはリリースごとに変わることがあります。コードは変わらないため、クライアントのロジックは `code` に対して書いてください。

## HTTP ステータスから決まるコード {#status-codes}

ルートが独自のコードを設定していない場合、サーバーはステータスからコードを導きます。

| HTTP ステータス | `code` |
|-------------|--------|
| 400 | `BAD_REQUEST` |
| 401 | `AUTH_REQUIRED` |
| 403 | `FORBIDDEN` |
| 404 | `NOT_FOUND` |
| 409 | `CONFLICT` |
| 413 | `PAYLOAD_TOO_LARGE` |
| 415 | `UNSUPPORTED_MEDIA_TYPE` |
| 422 | `UNPROCESSABLE_ENTITY` |
| 429 | `RATE_LIMITED` |
| 500 | `INTERNAL_ERROR` |
| 501 | `NOT_IMPLEMENTED` |
| 503 | `SERVICE_UNAVAILABLE` |
| 507 | `INSUFFICIENT_STORAGE` |

その他の 4xx は `BAD_REQUEST` に、その他の 5xx は `INTERNAL_ERROR` にフォールバックします。

ルートがより具体的なコードを設定する場合もあり、その場合はレスポンスにそのコードが入ります。たとえば、AI バンドルが見つからないためにツールを実行できないときは、機能固有のコードが返されます。そうしたコードは、それを発生させる機能の説明の中で解説されています。

## 認証とアクセス {#auth-codes}

| `code` | ステータス | 対処 |
|--------|--------|------------|
| `AUTH_REQUIRED` | 401 | セッショントークンまたは API キー (`si_...`) を付けて `Authorization: Bearer <token>` を送信してください。 |
| `FORBIDDEN` | 403 | 認証情報は有効ですが、権限がありません。管理者に権限を依頼してください。 |
| `MUST_CHANGE_PASSWORD` | 403 | 他のエンドポイントを呼び出す前に、アカウントのパスワードを変更する必要があります。セッショントークンを付けて `POST /api/auth/change-password` を呼び出し、その後で再試行してください。 |
| `USER_DISABLED` | 403 | アカウントが無効になっています。管理者が再度有効にする必要があります。 |
| `LOGIN_THROTTLED` | 429 | サインインの失敗が多すぎます。しばらく待ってから再試行してください。 |
| `VALIDATION_ERROR` | 400 | リクエストボディまたはパラメーターがバリデーションに失敗しました。`details` が問題点を示します。 |

初回起動時の管理者アカウントは `admin` で、パスワードは `admin` です。ただし `DEFAULT_USERNAME` または `DEFAULT_PASSWORD` で変更した場合は除きます。`SKIP_MUST_CHANGE_PASSWORD` が設定されていない限り、このアカウントはパスワードが変更されるまで、すべての呼び出しで `MUST_CHANGE_PASSWORD` を受け取ります。

## ジョブ {#job-codes}

失敗したジョブは、HTTP エラーではなくジョブ自体に理由を報告します。`GET /api/v1/jobs/{jobId}` から `error.code` と `error.message` を読み取ってください。[進捗の追跡](/ja/api/rest#progress-tracking)を参照してください。

失敗したジョブが `error.code` を保持するのは、失敗の原因が入力エラーまたはサーバー側の障害である場合だけです。それ以外の失敗にはメッセージのみが付きます。

| `code` | 意味 | 対処 |
|--------|--------|------------|
| `CANCELED` | ジョブがユーザーによってキャンセルされました。HTTP ステータスではありません。進捗イベントは、このコードを持つ `phase: failed` を運びます。 | ユーザーによるキャンセルとして扱ってください。自動で再試行しないでください。 |
| `INPUT_MISSING` | ジョブが実行される前に入力が削除されました。 | ファイルをもう一度アップロードしてください。 |
| `ENGINE_UNAVAILABLE` | 必要なエンジンをサーバー上で起動できませんでした。 | 管理者がインストールを修復した後に再試行してください。 |

## 認証と MFA {#mfa-codes}

| `code` | ステータス | 意味 | 対処 |
|--------|--------|---------|------------|
| `MFA_ENROLLMENT_REQUIRED` | 403 | MFA ポリシーで登録が必須ですが、このインスタンスではユーザーを登録できません (エンタープライズライセンスがありません)。ライセンスのあるインスタンスは、代わりに `requiresMfaEnrollment: true` とともに 200 を返し、ユーザーを登録の手順へ案内します。 | 再試行しないでください。管理者がポリシーを変更するか、オフラインのリカバリー CLI を使用する必要があります。 |
| `MFA_POLICY_UNAVAILABLE` | 503 | サインイン中に、サーバーが MFA ポリシーを読み取れませんでした。 | 少し待ってからサインインを再試行してください。 |
| `INVALID_CODE` | 401 | TOTP またはリカバリーコードが正しくありません。 | ユーザーに新しいコードを入力してもらい、再試行してください。失敗が続くと `MFA_ATTEMPTS_EXHAUSTED` になります。 |
| `MFA_ATTEMPTS_EXHAUSTED` | 401 | 誤ったコードが多すぎます。チャレンジは破棄されました。 | サインインをやり直して、新しいチャレンジを取得してください。 |
| `MFA_EXPIRED` | 401 | MFA または登録のチャレンジが期限切れか、一致しません。 | サインインをやり直してください。 |
| `MFA_NOT_CONFIGURED` | 401 | アカウントに TOTP シークレットがないため、コードを確認できません。 | コードでサインインする前に MFA を登録してください。 |
| `MFA_ALREADY_ENABLED` | 409 | このアカウントでは MFA がすでに有効です。 | 再度登録しないでください。 |
| `NO_PENDING_ENROLLMENT` | 400 | 保留中の登録がないまま、登録の確認が届きました。 | 先に登録エンドポイントを呼び出してください。 |
| `MFA_NOT_ENABLED` | 400 | この操作には MFA が有効である必要がありますが、このユーザーでは無効です。 | 操作をスキップするか、先に MFA を有効にしてください。 |
| `MFA_DECRYPTION_FAILED` | 500 | 保存されている TOTP シークレットを復号できません。 | 運用者による対応が必要です。通常は、暗号化キーが変更されたことを意味します。`DATA_ENCRYPTION_KEY` と `DATA_ENCRYPTION_KEY_PREVIOUS` を確認してください。 |
| `DECRYPTION_FAILED` | 500 | 保存されている値 (設定、Webhook の認証ヘッダー、または TOTP シークレット) を復号できません。 | 上記と同様に、運用者による対応が必要です。再試行しないでください。 |
| `IDLE_TIMEOUT` | 401 | 一定時間操作がなかったため、セッションの有効期限が切れました。 | もう一度サインインしてください。 |
| `INVALID_PASSWORD` | 401 | パスワード変更時の現在のパスワードが正しくありません。 | ユーザーに現在のパスワードを入力してもらってください。 |
| `PASSWORD_CHANGED` | 409 | このリクエストの実行中に、別のセッションでパスワードが変更されたか、管理者がリセットしました。 | もう一度サインインしてください。 |
| `OIDC_NO_PASSWORD` | 400 | SSO で作成されたアカウントに対して、パスワードの変更またはリセットが要求されました。 | ユーザーを ID プロバイダーへ案内してください。 |

## OIDC {#oidc-codes}

サインイン中の OIDC の失敗では、JSON ボディは返されません。ログインのルートは、一般的な理由を付けてログインページへリダイレクトし、監査ログにコードが記録されます。ID プロバイダーに接続できない場合でも、ログアウトのルートはローカルのセッションを終了します。

| `code` | ステータス | 意味 | 対処 |
|--------|--------|---------|------------|
| `OIDC_ISSUER_SCHEME_MISMATCH` | なし (リダイレクト) | 発行者の URL は `http` ですが、`EXTERNAL_URL` が `https` であるため、クライアントはディスカバリーを拒否します。 | 管理者: 発行者を `https` で提供するか、インスタンスを `http` で実行してください。 |
| `OIDC_DISCOVERY_TIMEOUT` | なし (リダイレクト) | 発行者のディスカバリーがタイムアウトしました。 | サーバーから発行者に到達できることを確認してから、再試行してください。 |
| `OIDC_DISCOVERY_FAILED` | なし (リダイレクト) | 別の理由でディスカバリーに失敗しました。 | 発行者の URL と、サーバーの外向きのアクセスを確認してください。 |
| `OIDC_END_SESSION_INVALID` | なし (ログアウトは継続) | ID プロバイダーの `end_session_endpoint` が有効な URL ではありません。ローカルのセッションは引き続き消去されます。 | 管理者: プロバイダーのメタデータを修正してください。 |
| `OIDC_END_SESSION_SCHEME` | なし (ログアウトは継続) | `end_session_endpoint` が、サーバーで許可されていないスキームを使用しています。ローカルのセッションは引き続き消去されます。 | 管理者: プロバイダーのメタデータを修正してください。 |

## SAML {#saml-codes}

SAML の失敗では `code` は設定されません。アサーションに失敗すると、`saml_auth_failed` を付けてログインページへリダイレクトされ、`SAML_LOGIN_FAILED` の監査イベントに理由が記録されます。

## SCIM {#scim-codes}

SCIM のルートは、RFC 7644 のエラーエンベロープ (`schemas`、`detail`、`status`、場合によっては `scimType`) で応答します。`code` は設定されません。HTTP ステータスで分岐してください。

## チーム、ロール、ユーザー {#team-role-codes}

チーム名またはロール名が重複した場合は一般的な `CONFLICT` が返され、チームまたはロールが存在しない場合は `NOT_FOUND` が返されます。

| `code` | ステータス | 意味 | 対処 |
|--------|--------|---------|------------|
| `ESCALATION_DENIED` | 403 | 呼び出し元のロールでは、その変更が許可されていません。対象が呼び出し元の権限より上位にある、ロールが組み込みである、または呼び出し元が持っていない権限をリクエストが付与しようとしています。 | 再試行しないでください。より高い権限を持つユーザーに依頼してください。 |
| `UNKNOWN_ROLE` | 400 | ロール ID が既存のロールと一致しません。 | ロール ID を修正してください。ロールを一覧表示して確認できます。 |
| `UNKNOWN_TEAM` | 400 | チーム ID が既存のチームと一致しません。 | チーム ID を修正してください。 |
| `SELF_DEMOTE` | 400 | 管理者が自分自身の管理者ロールを削除しようとしました。 | 別の管理者に変更してもらってください。 |
| `SELF_DELETE` | 400 | 管理者が自分自身のアカウントを削除しようとしました。 | 別の管理者に削除してもらってください。 |
| `LAST_ADMIN` | ユーザー関連のルートでは 400、GDPR の消去ルートでは 409 | この変更により管理者がいなくなる、またはすべての管理者を含むチームが消去されることになります。 | 先に別のユーザーを管理者にしてください。 |
| `USER_LIMIT_REACHED` | 403 | インスタンスが `MAX_USERS` の上限に達しています。 | ユーザーを削除するか、`MAX_USERS` を引き上げてください。 |

## 機能と AI バンドル {#feature-codes}

任意の AI バンドルを必要とするツール、バッチ実行、パイプラインは、次のコードを使用します。

| `code` | ステータス | 意味 | 対処 |
|--------|--------|---------|------------|
| `FEATURE_NOT_INSTALLED` | 501 | ツール、またはパイプラインやバッチの 1 つのステップに、インストールされていないバンドルが必要です。ボディには `feature` (バンドル ID) と `featureName` が含まれます。 | 設定でバンドルをインストールしてから、再試行してください。 |
| `FEATURE_INCOMPATIBLE` | 501 | インストール済みの機能では、要求された品質または言語に対応できません。 | 設定を変更するか、対応するバンドルをインストールしてください。 |
| `ENGINE_UNAVAILABLE` | 503 | 必要なエンジンを起動できなかったか、リクエストの検証後に OCR ランタイムが削除されました。 | 管理者が機能を修復または再インストールした後に再試行してください。 |
| `BROWSER_NOT_AVAILABLE` | 503 | Chromium がインストールされていないため、HTML to image を実行できません。 | 管理者にブラウザーのインストールを依頼してください。 |
| `BROWSER_CRASHED` | 503 | スクリーンショット用のブラウザーがレンダリング中にクラッシュしました。 | リクエストを再試行してください。 |

## ツール {#tool-codes}

| `code` | ステータス | 意味 | 対処 |
|--------|--------|---------|------------|
| `INPUT_MISSING` | 410 | アップロードされた入力が、ジョブの実行前に削除されました。 | ファイルをもう一度アップロードして、ジョブを送信してください。 |
| `ANALYSIS_EXPIRED` | 410 | 証明写真の解析結果が、生成の前に期限切れになりました。 | 写真をもう一度解析してから、生成してください。 |
| `BACKGROUND_REMOVAL_EXPIRED` | 410 | 背景除去の結果が、後続のステップの前に期限切れになりました。 | もう一度背景を除去してください。 |
| `NOT_ANIMATED` | 400 | Remove GIF Background が静止画を受け取りました。 | 静止画には Remove Background を使用してください。 |
| `TOO_MANY_FRAMES` | 400 | アニメーションのフレーム数が、サーバーで許可されている数 (`GIF_BG_MAX_FRAMES`) を超えています。 | より短いアニメーションを送信するか、管理者に上限の引き上げを依頼してください。 |

## ファイル {#file-codes}

| `code` | ステータス | 意味 | 対処 |
|--------|--------|---------|------------|
| `STORAGE_QUOTA_EXCEEDED` | 413 | ファイルに保存すると、ユーザーのストレージ容量を超えます。 | ファイルを削除するか、管理者に容量の追加を依頼してください。 |
| `INVALID_STORED_NAME` | 400 | サーバーが、保存されたファイル名を拒否しました。 | ファイルをもう一度アップロードしてください。 |

## パイプラインとバッチ {#pipeline-codes}

パイプラインとバッチのリクエストは、バンドルが必要な各ステップについて、上記の機能コードを返します。すでに使用されているジョブ ID を指定すると、ステータス 409 で `CONFLICT` が返されます。新しいジョブ ID を送信してください。

## 設定 {#settings-codes}

| `code` | ステータス | 意味 | 対処 |
|--------|--------|---------|------------|
| `UNKNOWN_SETTING` | 400 | このキーは既知の設定ではありません。 | キー名を確認してください。 |
| `READONLY_SETTING` | 400 | この設定は API 経由では変更できません。 | 環境変数または管理画面から変更してください。 |
| `DEPENDENCY_VALIDATION_FAILED` | 400 | 新しい値が他の設定と矛盾しています。ボディの `setting` に該当する設定が示され、`validationErrors` に問題の一覧が入ります。 | 一覧にある設定を修正してから、再試行してください。 |
| `SETTING_DECRYPTION_FAILED` | 500 | 保存されている設定を復号できません。 | `DECRYPTION_FAILED` と同様に、運用者による対応が必要です。 |

設定に対する `VALIDATION_ERROR` では、`details` にスキーマ上の問題が入ります。

## エンタープライズ {#enterprise-codes}

| `code` | ステータス | 意味 | 対処 |
|--------|--------|---------|------------|
| `FEATURE_NOT_LICENSED` | 403 | この設定またはポリシーにはエンタープライズライセンスが必要です。たとえば SSO の強制や MFA ポリシーです。 | ライセンスのあるインスタンスを使用するか、この設定をオフのままにしてください。 |
| `IP_NOT_ALLOWED` | 403 | リクエストの IP アドレスが許可リストに含まれていません。 | 許可されたネットワークから接続してください。 |
| `INVALID_CIDR` | 400 | 許可リストのエントリが有効な CIDR ではありません。メッセージに不正なエントリが一覧表示されます。 | エントリを修正して、もう一度保存してください。 |
| `SELF_LOCKOUT` | 400 | 許可リストを保存すると、呼び出し元の現在の IP がブロックされます。 | 先に現在の IP をリストに追加してください。 |

ユーザーまたはチームがリーガルホールド下にある場合、GDPR の消去ルートはステータス 409 で、通常の `CONFLICT` を返します。

## クライアントが受け取らないコード {#internal-codes}

これらのコードは、ログ、テレメトリ、または Fastify 自身のエラーのためにサーバーのソースに存在します。クライアントがレスポンスボディやジョブの行でこれらを受け取ることはないため、これらに対するクライアントロジックは書かないでください。

| `code` | 送られる先 |
|--------|---------------|
| `ALERT_DECRYPTION_FAILED` | アラート評価器によってエラートラッキングに報告されます。アラート Webhook の認証ヘッダーを復号できません。 |
| `SIEM_DECRYPTION_FAILED` | SIEM 転送によってエラートラッキングに報告されます。SIEM の認証ヘッダーを復号できません。 |
| `WEBHOOK_DECRYPTION_FAILED` | エラートラッキングに報告されます。同じ障害に遭遇したリクエストには `DECRYPTION_FAILED` で応答します。 |
| `STAGED_DISCARD_FAILED` | ステージングされたアップロードを削除できないときに、エラートラッキングに報告されます。 |
| `USERNAME_RACE_EXHAUSTED` | SSO の自動作成が、再試行のたびにユーザー名の競合に負けた場合に発生します。ログインページにはエラーが表示されます。 |
| `ERR_OUT_OF_RANGE` | 無効なバイト範囲に対して、オブジェクトストレージのリーダーがスローします。 |
| `ETIMEDOUT` | GDPR エクスポートのタイムアウトエラーに設定されます。エクスポートは失敗しますが、再度リクエストできます。 |
| `FST_REQ_FILE_TOO_LARGE` | 上限を超えたアップロードに対する Fastify のコードです。クライアントは `PAYLOAD_TOO_LARGE` 付きの 413、またはルート独自の 413 メッセージを受け取ります。 |
| `TARGET_SIZE_EXCEEDED` | 目標サイズの圧縮が目標に届かなかったときにスローされます。このエラーにはステータスもコードもないため、クライアントは一般的な失敗を受け取ります。 |
