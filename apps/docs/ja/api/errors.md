# エラーコード {#error-codes}

すべての JSON エラーレスポンスは同じ形式です。

```json
{
  "error": "Job not found",
  "code": "NOT_FOUND",
  "requestId": "req-42"
}
```

| フィールド | 常に存在 | 意味 |
|-------|----------------|---------|
| `error` | はい | 人が読めるメッセージです。ユーザーに表示しても問題ありません。パースしないでください。 |
| `code` | はい | 安定した機械可読なコードです。分岐にはこれを使います。 |
| `requestId` | はい | このリクエストに対するサーバー側の ID です。問題を報告するときに添えてください。サーバーログと一致します。 |
| `details` | 場合による | 一部の 4xx エラーに付く追加情報です。たとえばバリデーションメッセージです。 |

メッセージはリリースごとに変わることがあります。コードは変わらないため、クライアントのロジックは `code` に対して書いてください。

## HTTP ステータスから決まるコード {#status-codes}

ルートが独自のコードを設定していない場合、サーバーはステータスからコードを導きます。

| HTTP ステータス | `code` |
|-------------|--------|
| 400 | `BAD_REQUEST` |
| 401 | `AUTH_REQUIRED` |
| 403 | `FORBIDDEN` |
| 404 | `NOT_FOUND` |
| 409 | `CONFLICT` |
| 413 | `PAYLOAD_TOO_LARGE` |
| 415 | `UNSUPPORTED_MEDIA_TYPE` |
| 422 | `UNPROCESSABLE_ENTITY` |
| 429 | `RATE_LIMITED` |
| 500 | `INTERNAL_ERROR` |
| 501 | `NOT_IMPLEMENTED` |
| 503 | `SERVICE_UNAVAILABLE` |
| 507 | `INSUFFICIENT_STORAGE` |

その他の 4xx は `BAD_REQUEST` に、その他の 5xx は `INTERNAL_ERROR` にフォールバックします。

ルートがより具体的なコードを設定する場合もあり、その場合はレスポンスにそのコードが入ります。たとえば、AI バンドルが見つからないためにツールを実行できないときは、機能固有のコードが返されます。そうしたコードは、それを発生させる機能の説明の中で解説されています。

## 認証とアクセス {#auth-codes}

| `code` | ステータス | 対処 |
|--------|--------|------------|
| `AUTH_REQUIRED` | 401 | `Authorization: Bearer <token>` を、セッショントークンまたは API キー (`si_...`) を付けて送信してください。 |
| `FORBIDDEN` | 403 | 認証情報は有効ですが、権限がありません。管理者に権限を依頼してください。 |
| `MUST_CHANGE_PASSWORD` | 403 | 他のエンドポイントを呼び出す前に、アカウントのパスワードを変更する必要があります。セッショントークンを付けて `POST /api/auth/change-password` を呼び出し、その後で再試行してください。 |
| `USER_DISABLED` | 403 | アカウントが無効になっています。管理者が再度有効にする必要があります。 |
| `LOGIN_THROTTLED` | 429 | サインインの失敗が多すぎます。しばらく待ってから再試行してください。 |
| `VALIDATION_ERROR` | 400 | リクエストボディまたはパラメーターがバリデーションに失敗しました。`details` が問題点を示します。 |

初回起動時の管理者アカウントは `admin` で、パスワードは `admin` です。ただし `DEFAULT_USERNAME` または `DEFAULT_PASSWORD` で変更した場合は除きます。`SKIP_MUST_CHANGE_PASSWORD` が設定されていない限り、このアカウントはパスワードが変更されるまで、すべての呼び出しで `MUST_CHANGE_PASSWORD` を受け取ります。

## ジョブ {#job-codes}

失敗したジョブは、HTTP エラーではなくジョブ自体に理由を報告します。`error.code` と `error.message` を `GET /api/v1/jobs/{jobId}` から読み取ってください。[進捗の追跡](/ja/api/rest#progress-tracking)を参照してください。

失敗したジョブが `error.code` を保持するのは、失敗が入力エラーまたはサーバー障害の場合のみです。それ以外の失敗はメッセージだけを持ちます。

| `code` | 意味 | 対処 |
|--------|---------|------------|
| `CANCELED` | ジョブがユーザーによってキャンセルされました。HTTP ステータスではありません。進捗イベントはこのコードを持つ `phase: failed` を運びます。 | ユーザーによるキャンセルとして扱ってください。自動的に再試行しないでください。 |
| `INPUT_MISSING` | ジョブが実行される前に入力が削除されました。 | ファイルを再度アップロードしてください。 |
| `ENGINE_UNAVAILABLE` | 必要なエンジンをサーバーで起動できませんでした。 | 管理者がインストールを修復した後に再試行してください。 |
| `JOB_STALLED` | クライアントには返されません。サーバーのエラーレポートのラベルです。ワーカーがキューの許容回数を超えてジョブのロックを失いました。多くの場合、サーバーの再起動、またはメモリや CPU の不足が原因です。ジョブは、中断されたことを伝えるメッセージとともに失敗します。 | 再試行してください。繰り返し発生する場合は、サーバーのメモリを増やすか、`CONCURRENT_JOBS` を下げてください。 |

## 認証と MFA {#mfa-codes}

| `code` | ステータス | 意味 | 対処 |
|--------|--------|---------|------------|
| `MFA_ENROLLMENT_REQUIRED` | 403 | MFA ポリシーで登録が必要ですが、このインスタンスではユーザーを登録できません (エンタープライズライセンスなし)。ライセンスのあるインスタンスは、代わりに `requiresMfaEnrollment: true` を付けて 200 を返し、ユーザーを登録へ案内します。 | 再試行しないでください。管理者がポリシーを変更するか、オフラインのリカバリ CLI を使う必要があります。 |
| `MFA_POLICY_UNAVAILABLE` | 503 | サインイン中に、サーバーが MFA ポリシーを読み取れませんでした。 | しばらくしてからサインインを再試行してください。 |
| `INVALID_CODE` | 401 | TOTP またはリカバリコードが正しくありません。 | ユーザーに新しいコードを尋ねて再試行してください。失敗が続くと `MFA_ATTEMPTS_EXHAUSTED` になります。 |
| `MFA_ATTEMPTS_EXHAUSTED` | 401 | 誤ったコードが多すぎます。チャレンジは破棄されました。 | サインインをやり直して、新しいチャレンジを取得してください。 |
| `MFA_EXPIRED` | 401 | MFA または登録のチャレンジが期限切れか、一致しません。 | サインインをやり直してください。 |
| `MFA_NOT_CONFIGURED` | 401 | アカウントに TOTP シークレットがないため、コードを確認できません。 | コードでサインインする前に MFA を登録してください。 |
| `MFA_ALREADY_ENABLED` | 409 | アカウントではすでに MFA が有効です。 | 再度登録しないでください。 |
| `NO_PENDING_ENROLLMENT` | 400 | 保留中の登録がないまま、登録の確認が届きました。 | 先に登録エンドポイントを呼び出してください。 |
| `MFA_NOT_ENABLED` | 400 | この操作には MFA が有効である必要がありますが、このユーザーでは無効です。 | 操作をスキップするか、先に MFA を有効にしてください。 |
| `MFA_DECRYPTION_FAILED` | 500 | 保存されている TOTP シークレットを復号できません。 | 運用者の対応が必要です。通常は暗号化キーが変更されたことを意味します。`DATA_ENCRYPTION_KEY` と `DATA_ENCRYPTION_KEY_PREVIOUS` を確認してください。 |
| `DECRYPTION_FAILED` | 500 | 保存されている値 (設定、Webhook の認証ヘッダー、または TOTP シークレット) を復号できません。 | 上記と同じく、運用者の対応が必要です。再試行しないでください。 |
| `IDLE_TIMEOUT` | 401 | 一定時間操作がなかったため、セッションが期限切れになりました。 | 再度サインインしてください。 |
| `INVALID_PASSWORD` | 401 | パスワード変更時の現在のパスワードが正しくありません。 | ユーザーに現在のパスワードを尋ねてください。 |
| `PASSWORD_CHANGED` | 409 | このリクエストの実行中に、別のセッションでパスワードが変更されたか、管理者がリセットしました。 | 再度サインインしてください。 |
| `OIDC_NO_PASSWORD` | 400 | SSO で作成されたアカウントに対して、パスワードの変更またはリセットが要求されました。 | ユーザーを ID プロバイダーへ案内してください。 |

## OIDC {#oidc-codes}

サインイン中の OIDC の失敗では JSON ボディは返されません。ログインルートは汎用的な理由を付けてログインページへリダイレクトし、監査ログにコードが記録されます。ID プロバイダーに到達できない場合でも、ログアウトルートはローカルセッションを終了します。

| `code` | ステータス | 意味 | 対処 |
|--------|--------|---------|------------|
| `OIDC_ISSUER_SCHEME_MISMATCH` | なし (リダイレクト) | 発行者 URL は `http` ですが、`EXTERNAL_URL` が `https` のため、クライアントはディスカバリーを拒否します。 | 管理者: 発行者を `https` で提供するか、インスタンスを `http` で実行してください。 |
| `OIDC_DISCOVERY_TIMEOUT` | なし (リダイレクト) | 発行者のディスカバリーがタイムアウトしました。 | サーバーが発行者に到達できるか確認してから再試行してください。 |
| `OIDC_DISCOVERY_FAILED` | なし (リダイレクト) | ディスカバリーが別の理由で失敗しました。 | 発行者 URL とサーバーのアウトバウンドアクセスを確認してください。 |
| `OIDC_END_SESSION_INVALID` | なし (ログアウトは続行) | ID プロバイダーの `end_session_endpoint` が有効な URL ではありません。ローカルセッションは引き続き消去されます。 | 管理者: プロバイダーのメタデータを修正してください。 |
| `OIDC_END_SESSION_SCHEME` | なし (ログアウトは続行) | `end_session_endpoint` が、サーバーが許可していないスキームを使用しています。ローカルセッションは引き続き消去されます。 | 管理者: プロバイダーのメタデータを修正してください。 |

## SAML {#saml-codes}

SAML の失敗では `code` は設定されません。アサーションに失敗すると `saml_auth_failed` を付けてログインページへリダイレクトされ、`SAML_LOGIN_FAILED` 監査イベントに理由が記録されます。

## SCIM {#scim-codes}

SCIM ルートは RFC 7644 のエラーエンベロープ (`schemas`、`detail`、`status`、場合によっては `scimType`) で応答します。`code` は設定されません。HTTP ステータスで分岐してください。

## チーム、ロール、ユーザー {#team-role-codes}

チーム名またはロール名の重複には汎用の `CONFLICT` が返され、存在しないチームまたはロールには `NOT_FOUND` が返されます。

| `code` | ステータス | 意味 | 対処 |
|--------|--------|---------|------------|
| `ESCALATION_DENIED` | 403 | 呼び出し元のロールでは、この変更は許可されていません。対象が呼び出し元の権限より上位にあるか、ロールが組み込みであるか、呼び出し元が持っていない権限をリクエストが付与しようとしています。 | 再試行しないでください。より強い権限を持つユーザーに依頼してください。 |
| `UNKNOWN_ROLE` | 400 | ロール ID が既存のロールと一致しません。 | ロール ID を修正してください。ロールの一覧から探せます。 |
| `UNKNOWN_TEAM` | 400 | チーム ID が既存のチームと一致しません。 | チーム ID を修正してください。 |
| `SELF_DEMOTE` | 400 | 管理者が自分自身の管理者ロールを削除しようとしました。 | 別の管理者に変更してもらってください。 |
| `SELF_DELETE` | 400 | 管理者が自分自身のアカウントを削除しようとしました。 | 別の管理者に削除してもらってください。 |
| `LAST_ADMIN` | ユーザールートでは 400、GDPR パージルートでは 409 | この変更により管理者がいなくなるか、すべての管理者を含むチームがパージされることになります。 | 先に別のユーザーを管理者にしてください。 |
| `USER_LIMIT_REACHED` | 403 | インスタンスが `MAX_USERS` の上限に達しています。 | ユーザーを削除するか、`MAX_USERS` を引き上げてください。 |

## 機能と AI バンドル {#feature-codes}

任意の AI バンドルを必要とするツール、バッチ実行、パイプラインは、これらのコードを使用します。

| `code` | ステータス | 意味 | 対処 |
|--------|--------|---------|------------|
| `FEATURE_NOT_INSTALLED` | 501、またはスマートクロップの顔モードでは 400 | ツール、またはパイプラインやバッチの 1 ステップに、インストールされていないバンドルが必要です。ボディには `feature` (バンドル ID) と `featureName` が含まれます。 | 設定でバンドルをインストールしてから再試行してください。 |
| `FEATURE_CPU_UNSUPPORTED` | 409 | バンドルの x86-64 ライブラリが AVX を必要とし、このサーバーの CPU が対応していないため、インストールまたはオフラインインポートが拒否されました。ダウンロードもインストールも行われていません。ボディには `feature` (バンドル ID) と `reason` (`cpu-no-avx`) が含まれます。`GET /api/v1/features` は同じバンドルを `compatibility: "incompatible"` と `compatibilityReason: "cpu-no-avx"` で報告します。 | AVX 対応の CPU か arm64 で SnapOtter を実行してください。他のバンドルは引き続きインストールできます。 |
| `FEATURE_INSTALL_BUSY` | 409 | インストーラーが共有の AI 環境に書き込み中で、そこで停止すると、インストール済みのすべての AI ツールが壊れてしまうため、キャンセルが拒否されました。 | インストールが終わるまで待ち、不要であればその後でバンドルをアンインストールしてください。 |
| `FEATURE_INCOMPATIBLE` | 501、または高速 OCR が読み取れない言語を受け取った場合は 400 | インストール済みの機能では、要求された品質または言語に対応できません。 | 設定を変更するか、対応するバンドルをインストールしてください。 |
| `ENGINE_UNAVAILABLE` | 503 | 必要なエンジンを起動できなかったか、リクエストの検証後に OCR ランタイムが削除されました。 | 管理者が機能を修復または再インストールした後に再試行してください。 |
| `BROWSER_NOT_AVAILABLE` | 503 | Chromium がインストールされていないため、HTML から画像への変換を実行できません。 | 管理者にブラウザーのインストールを依頼してください。 |
| `BROWSER_CRASHED` | 503 | スクリーンショット用ブラウザーがレンダリング中にクラッシュしました。 | リクエストを再試行してください。 |

## ツール {#tool-codes}

| `code` | ステータス | 意味 | 対処 |
|--------|--------|---------|------------|
| `INPUT_MISSING` | 410 | アップロードされた入力が、ジョブが実行される前に削除されました。 | ファイルを再度アップロードして、ジョブを送信してください。 |
| `ANALYSIS_EXPIRED` | 410 | パスポート写真の分析が、生成の前に期限切れになりました。 | 写真を再度分析してから生成してください。 |
| `BACKGROUND_REMOVAL_EXPIRED` | 410 | 背景削除の結果が、後続のステップの前に期限切れになりました。 | 背景を再度削除してください。 |
| `NOT_ANIMATED` | 400 | GIF 背景削除が静止画像を受け取りました。 | 静止画像には背景削除を使ってください。 |
| `TOO_MANY_FRAMES` | 400 | アニメーションのフレーム数が、サーバーの許容数 (`GIF_BG_MAX_FRAMES`) を超えています。 | より短いアニメーションを送信するか、管理者に上限の引き上げを依頼してください。 |
| `TOO_MANY_PIXELS` | 400 | アニメーションのキャンバスにフレーム数を掛けた値が、サーバーの上限を超えています。GIF 背景削除では 268,402,689 ピクセル (16383 x 16383)、その他のアニメーションツールでは GIF ワークロードの上限です。 | フレーム数を減らすか、より小さいアニメーションを送信してください。 |
| `MULTI_FRAME_UNSUPPORTED` | 400 | AI 画像ツールが、複数ページの TIFF、またはアニメーション GIF や WebP を受け取り、出力形式ではすべてのフレームが残ることになります。これらのツールは、モデルを 1 枚ずつの画像に対して実行します。 | ファイルを個別の画像に分割してください。ツールに出力形式の設定がある場合は、PNG などの静止画形式を選ぶと最初のフレームだけが処理されます。 |
| `IMAGE_TOO_LARGE` | 400 | 画像のピクセル数が、デコーダーが受け付ける数を超えています。 | より小さい画像を送信してください。 |
| `SVG_TOO_COMPLEX` | 400 | SVG が `JOB_TIMEOUT_FAST_S` 以内にラスタライズを完了しませんでした。原因はたいてい、`<use>` が繰り返す図形に付けたフィルターで、コピーごとにフィルターが再描画されるためです。 | フィルターや繰り返される図形を簡素化するか、管理者に上限の引き上げを依頼してください。 |
| `RESULT_TOO_LARGE` | 400 | この設定では、エンコーダーまたはピクセル数の上限を超える大きさの画像になります。 | より小さい画像を使うか、結果が小さくなる設定を使ってください。 |
| `DOCUMENT_UNREADABLE` | 400 | LibreOffice または pandoc がドキュメントを開けませんでした。破損しているか、パスワードで保護されているか、拡張子が示す形式ではない可能性があります。 | ファイルがオフィスアプリで開けることを確認してから、再度送信してください。 |
| `PDF_DAMAGED` | 400 | PDF エンジンがドキュメント構造の破損を検出しました。 | ファイルを PDF 修復にかけてから再試行してください。 |
| `PDF_PASSWORD_PROTECTED` | 400 | PDF が暗号化されており、このツールでは開けません。 | 先に PDF のロック解除で解除してください。 |
| `NO_AUDIO_TRACK` | 400 | ファイルに、音声ツールが使える音声ストリームがありません。 | 音声を含むファイルを送信してください。 |
| `MEDIA_UNDECODABLE` | 400 | ffmpeg が音声または動画を読み取れませんでした。パケット、コーデックパラメーター、`moov` アトムが見つからないか、解析できないデータがありました。 | ファイルがメディアプレーヤーで再生できることを確認するか、再エクスポートしてから再試行してください。 |
| `ENCODED_TEXT_INVALID` | 400 | Base64 エンコード / デコードが、Base64 ではない入力を受け取りました。空白は無視され、標準とURL セーフの両方のアルファベットを受け付けます。 | テキストに余分な文字や途切れた末尾がないか確認してください。 |
| `DECODED_DATA_NOT_TEXT` | 400 | Base64 としては有効ですが、デコード結果が UTF-8 テキストではなくバイナリデータです。 | テキストを表示する代わりにファイルとして保存するツールでデコードしてください。 |
| `PAGE_OUT_OF_RANGE` | 400 | ページ範囲に、PDF に存在しないページが含まれています。 | ページ数を確認し、その範囲内の指定を送信してください。 |
| `INVALID_PAGE_RANGE` | 400 | ページ範囲の構文が正しくありません。 | `1-3,5` のようなページ番号を使ってください。 |
| `CANNOT_REMOVE_ALL_PAGES` | 400 | ページ削除で、すべてのページの削除が要求されました。 | 少なくとも 1 ページは残してください。 |
| `NESTING_TOO_DEEP` | 400 | JSON または XML のネストが 100 階層を超えています。 | ドキュメントをフラットにしてから変換してください。 |
| `IMAGE_UNDECODABLE` | 400 | 画像をデコードできないか、サイズを読み取れません。ファイルが破損しているか、デコーダーが対応していないエンコードを使っている可能性があります。 | 別のアプリから画像を再エクスポートするか、先に PNG または JPEG に変換してください。 |
| `INVALID_SETTINGS` | 400 | 設定が範囲外か、このファイルに合っていません。たとえば、画像の外側へのトリミング、サイズ 0 へのリサイズ、アニメーションに存在しない GIF フレーム、存在しないパスポート規格などです。`error` のテキストが設定名を示します。 | `error` で示された設定を修正してから再試行してください。 |
| `CHART_DATA_INVALID` | 400 | グラフ作成が、ファイルからグラフデータを読み取れませんでした。CSV または JSON を解析できない、数値の列がない、行数が 100 を超えている、または負の値があります。どれに当たるかは `error` のテキストに書かれています。 | 最大 100 行で、各行がラベルと 0 以上の数値である CSV または JSON を送信してください。 |
| `NO_FACE_DETECTED` | 400 | パスポート写真が、画像内に顔を見つけられませんでした。 | 明るい照明の下で撮影した、正面向きの鮮明な写真を送信してください。 |
| `TARGET_SIZE_UNREACHABLE` | 400 | 圧縮、またはパスポート写真のサイズ制限で、縮小しても指定サイズ以下にできません。 | より大きい目標サイズを指定するか、先に画像をトリミングしてください。 |
| `TOO_MANY_PAGES` | 400 | OCR が、1 つのジョブで処理できるページ数を超えて要求されました。 | ページ範囲でページ数を減らして選択してください。 |
| `OCR_OUTPUT_TOO_LARGE` | 500 | 複数ページの TIFF に対する OCR が、ページ全体で 1,000,000 バイトを超えるテキストを読み取り、1 件の結果として保存できる量を超えました。 | TIFF を小さなファイルに分割し、それぞれに OCR を実行してください。 |
| `METADATA_DAMAGED` | 400 | メタデータ編集で、画像の既存の EXIF データが破損していることが分かり、安全に書き換えられません。 | 先に画像メタデータ削除でメタデータを取り除いてから編集してください。 |
| `REMOTE_RESOURCES_DISABLED` | 400 | HTML または Markdown から PDF への変換で、ネットワーク上の画像、スタイルシート、フォントへの参照が見つかりました。サーバーはこれらを取得しません。 | リソースをファイルに埋め込んで (たとえば `data:` URI として)、再試行してください。 |

## ファイル {#file-codes}

| `code` | ステータス | 意味 | 対処 |
|--------|--------|---------|------------|
| `STORAGE_QUOTA_EXCEEDED` | 413 | ファイルへの保存が、ユーザーのストレージ容量の上限を超えます。 | ファイルを削除するか、管理者に容量の追加を依頼してください。 |
| `INVALID_STORED_NAME` | 400 | サーバーが、保存されているファイル名を拒否しました。 | ファイルを再度アップロードしてください。 |

## パイプラインとバッチ {#pipeline-codes}

パイプラインとバッチのリクエストは、バンドルを必要とする各ステップについて、上記の機能コードを返します。すでに使用されているジョブ ID は、ステータス 409 で `CONFLICT` を返します。新しいジョブ ID を送信してください。

## 設定 {#settings-codes}

| `code` | ステータス | 意味 | 対処 |
|--------|--------|---------|------------|
| `UNKNOWN_SETTING` | 400 | キーが既知の設定ではありません。 | キー名を確認してください。 |
| `READONLY_SETTING` | 400 | この設定は API では変更できません。 | 環境変数または管理 UI から変更してください。 |
| `DEPENDENCY_VALIDATION_FAILED` | 400 | 新しい値が他の設定と競合しています。ボディは `setting` で設定を示し、`validationErrors` に問題を列挙します。 | 挙げられた設定を修正してから再試行してください。 |
| `SETTING_DECRYPTION_FAILED` | 500 | 保存されている設定を復号できません。 | `DECRYPTION_FAILED` と同じく、運用者の対応が必要です。 |

設定に対する `VALIDATION_ERROR` では、`details` にスキーマの問題が入ります。

## エンタープライズ {#enterprise-codes}

| `code` | ステータス | 意味 | 対処 |
|--------|--------|---------|------------|
| `FEATURE_NOT_LICENSED` | 403 | 設定またはポリシーにエンタープライズライセンスが必要です。たとえば SSO の強制や MFA ポリシーです。 | ライセンスのあるインスタンスを使うか、その設定をオフのままにしてください。 |
| `IP_NOT_ALLOWED` | 403 | リクエストの IP アドレスが許可リストにありません。 | 許可されたネットワークから接続してください。 |
| `INVALID_CIDR` | 400 | 許可リストのエントリが有効な CIDR ではありません。メッセージに不正なエントリが列挙されます。 | エントリを修正して、もう一度保存してください。 |
| `SELF_LOCKOUT` | 400 | 許可リストを保存すると、呼び出し元の現在の IP がブロックされます。 | 先に現在の IP をリストに追加してください。 |

ユーザーまたはチームがリーガルホールド下にある場合、GDPR パージルートはステータス 409 で単純な `CONFLICT` を返します。

## クライアントが受け取らないコード {#internal-codes}

これらのコードは、ログ、テレメトリ、または Fastify 自身のエラーのためにサーバーのソースに存在します。クライアントはレスポンスボディやジョブ行でこれらを受け取らないため、これらに対してクライアントのロジックを書かないでください。

| `code` | 送られる先 |
|--------|---------------|
| `ALERT_DECRYPTION_FAILED` | アラート評価器からエラートラッキングへ報告されます。アラート Webhook の認証ヘッダーを復号できません。 |
| `SIEM_DECRYPTION_FAILED` | SIEM 転送からエラートラッキングへ報告されます。SIEM の認証ヘッダーを復号できません。 |
| `WEBHOOK_DECRYPTION_FAILED` | エラートラッキングへ報告されます。同じ障害に当たったリクエストは `DECRYPTION_FAILED` で応答します。 |
| `STAGED_DISCARD_FAILED` | ステージングされたアップロードを削除できないときに、エラートラッキングへ報告されます。 |
| `RETENTION_DEADLINE_BACKFILLED` | ストレージ TTL スイープが、完了したジョブに欠けているチームの保持期限を補完するときに、エラートラッキングへ報告されます。その後、そのジョブのファイルはチームの保持設定に従います。 |
| `USERNAME_RACE_EXHAUSTED` | SSO の自動作成が、再試行のたびにユーザー名の競合に負けたときに発生します。ログインページには代わりにエラーが表示されます。 |
| `ERR_OUT_OF_RANGE` | 無効なバイト範囲に対して、オブジェクトストレージのリーダーがスローします。 |
| `ETIMEDOUT` | GDPR エクスポートのタイムアウトエラーに設定されます。エクスポートは失敗しますが、再度リクエストできます。 |
| `FST_REQ_FILE_TOO_LARGE` | 上限を超えたアップロードに対する Fastify のコードです。クライアントは `PAYLOAD_TOO_LARGE` 付きの 413、またはルート独自の 413 メッセージを受け取ります。 |
| `TARGET_SIZE_EXCEEDED` | 目標サイズ指定の圧縮が目標に届かなかったときにスローされます。このエラーにはステータスもコードもないため、クライアントは汎用的な失敗を受け取ります。 |
| `OCR_CACHE_PERMISSIONS` | AI データボリュームのために OCR ランタイムキャッシュが全ユーザーに書き込み可能になった場合に、運用上の障害としてエラートラッキングへ報告されます。インストールジョブは、ストレージの問題を示すメッセージで失敗します。 |
| `OCR_RUNTIME_UNREACHABLE` | サーバーが OCR ランタイムをダウンロードするために huggingface.co に到達できなかった場合に、運用上の障害としてエラートラッキングへ報告されます。インストールジョブは、ネットワークアクセス、`HTTPS_PROXY`、`HF_ENDPOINT`、オフラインインポートに関するメッセージで失敗します。 |
