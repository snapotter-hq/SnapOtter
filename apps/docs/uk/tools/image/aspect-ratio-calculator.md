# Калькулятор співвідношення сторін {#aspect-ratio-calculator}

Введіть початкові ширину та висоту, потім нову ширину або нову висоту, і отримайте іншу сторону, щоб пропорції лишилися незмінними. Співвідношення повертається в найпростішому вигляді, тож 1920 × 1080 дає 16:9. У вебзастосунку можна почати зі стандартного співвідношення (16:9, 4:3, 3:2, 1:1, 21:9, 9:16, 4:5) і перемикатися між альбомною та портретною орієнтацією.

## Кінцева точка API {#api-endpoint}

`POST /api/v1/tools/image/aspect-ratio-calculator`

Приймає тіло JSON, а не дані форми multipart, і відповідає числами, а не файлом для завантаження.

## Параметри {#parameters}

| Параметр | Тип | Типове значення | Опис |
|-----------|------|---------|-------------|
| `width` | number | (обов'язковий) | Початкова ширина. |
| `height` | number | (обов'язковий) | Початкова висота. |
| `newWidth` | number | - | Цільова ширина. Відповідь обчислює з неї `newHeight`. |
| `newHeight` | number | - | Цільова висота. Відповідь обчислює з неї `newWidth`. |
| `round` | boolean | `true` | Округлити обчислену сторону до цілого числа. Коли `false`, зберігаються два знаки після коми. |

Кожен розмір має бути між `0.0001` та `1000000`. Надсилайте `newWidth` або `newHeight`, але не обидва. Пропустіть обидва, щоб отримати лише спрощене співвідношення.

## Приклад запиту {#example-request}

```bash
curl -X POST http://localhost:1349/api/v1/tools/image/aspect-ratio-calculator \
  -H "Authorization: Bearer si_your-api-key" \
  -H "Content-Type: application/json" \
  -d '{"width": 1920, "height": 1080, "newWidth": 1280}'
```

## Приклад відповіді {#example-response}

```json
{
  "width": 1920,
  "height": 1080,
  "ratio": "16:9",
  "ratioDecimal": 1.7778,
  "newWidth": 1280,
  "newHeight": 720
}
```

`newWidth` та `newHeight` мають значення `null`, якщо запит не містив жодного з них.

## Примітки {#notes}

- Дробові розміри зводяться до співвідношення цілих чисел із точністю до чотирьох знаків після коми, тому `8.5` × `11` повертається як `17:22`.
- `ratioDecimal` це ширина, поділена на висоту, округлена до чотирьох знаків після коми.
- Обчислена сторона ніколи не повертається як `0`. З округленням вона щонайменше `1`, а без округлення щонайменше `0.01`.
- Надсилання одночасно `newWidth` та `newHeight` або розміру поза допустимим діапазоном повертає 400.
- Калькулятор ніколи не читає і не записує файл. Щоб застосувати числа, скористайтеся інструментом [Зміна розміру зображення](/uk/tools/image/resize) або [Обрізка зображення](/uk/tools/image/crop).
