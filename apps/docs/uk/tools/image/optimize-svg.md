# Оптимізація SVG {#optimize-svg}

Зменшуйте SVG-файли, видаляючи сліди редактора, зайві атрибути й надлишкові десяткові знаки, і завантажуйте результат як SVG. На відміну від інструмента «Оптимізація для вебу», результат ніколи не растеризується.

## Кінцева точка API {#api-endpoint}

`POST /api/v1/tools/image/optimize-svg`

Приймає дані форми multipart із файлом `.svg` або `.svgz` та JSON-полем `settings`.

## Параметри {#parameters}

| Параметр | Тип | Обов'язковий | За замовчуванням | Опис |
|-----------|------|----------|---------|-------------|
| precision | number | Ні | `3` | Кількість десяткових знаків, що зберігаються в даних контурів і числах (від 0 до 8). Менші значення дають менші файли й трохи менш плавні криві. |
| multipass | boolean | Ні | `true` | Запускати оптимізатор повторно, доки результат не перестане зменшуватися |
| removeMetadata | boolean | Ні | `true` | Видаляти коментарі, `<metadata>`, `<desc>` і дані, специфічні для редакторів. Вимкніть, щоб зберегти їх. |
| pretty | boolean | Ні | `false` | Додавати відступи для читабельності замість мінімізації в кілька рядків |

## Приклад запиту {#example-request}

```bash
curl -X POST http://localhost:1349/api/v1/tools/image/optimize-svg \
  -F "file=@logo.svg" \
  -F 'settings={"precision":3,"multipass":true,"removeMetadata":true,"pretty":false}'
```

## Приклад відповіді {#example-response}

```json
{

  "originalSize": 48213,

```

## Примітки {#notes}

- Вхідний файл має бути SVG або SVGZ. Растрове зображення відхиляється з `400` і кодом `IMAGE_UNDECODABLE`.
- Вхід `.svgz` спершу розпаковується, а результат завжди звичайний `.svg`.
- Після розпакування розмір SVG обмежено 10 МБ. Більший файл відхиляється з `400` і кодом `SVG_TOO_LARGE`.
- `viewBox` і `<title>` завжди зберігаються, тому графіка й надалі масштабується та зберігає доступну назву.
- Вхід і результат проходять через санітайзер SVG, який видаляє скрипти й інший активний вміст.
- Зменшення `precision` дає найбільшу економію розміру для графіки з великою кількістю контурів. Перевірте результат візуально за значень від 0 до 2.
