# Trim Video {#trim-video}

Вирізає кліп із відео. Можна залишити частину між часом початку та кінця або відрізати фіксований фрагмент на початку та в кінці. Є також режим покадрово точного розрізання.

У застосунку поля часу приймають прості секунди (`90`), `MM:SS` (`1:30`) або `HH:MM:SS` (`1:02:03.5`). API приймає секунди.

## API Endpoint {#api-endpoint}

`POST /api/v1/tools/video/trim-video`

Приймає дані форми multipart із відеофайлом і полем JSON `settings`.

## Parameters {#parameters}

| Parameter | Type | Required | Default | Description |
|-----------|------|----------|---------|-------------|
| mode | string | No | `range` | `range` залишає частину від `startS` до `endS`. `ends` відрізає `cutStartS` на початку та `cutEndS` у кінці |
| startS | number | No | `0` | Режим діапазону: час початку в секундах (має бути >= 0) |
| endS | number | Range mode | - | Режим діапазону: час кінця в секундах (має бути після startS) |
| cutStartS | number | No | `0` | Режим країв: кількість секунд, які відрізати на початку |
| cutEndS | number | No | `0` | Режим країв: кількість секунд, які відрізати в кінці |
| precise | boolean | No | `false` | Перекодувати весь діапазон, щоб початковий і кінцевий кадри були точними, замість копіювання від наступного ключового кадру |

## Example Request {#example-request}

```bash
curl -X POST http://localhost:1349/api/v1/tools/video/trim-video \
  -H "Authorization: Bearer si_your-api-key" \
  -F "file=@clip.mp4" \
  -F 'settings={"startS": 5, "endS": 30, "precise": true}'
```

Відріжте перші 5 секунд і останні 10 секунд незалежно від тривалості відео:

```bash
curl -X POST http://localhost:1349/api/v1/tools/video/trim-video \
  -H "Authorization: Bearer si_your-api-key" \
  -F "file=@clip.mp4" \
  -F 'settings={"mode": "ends", "cutStartS": 5, "cutEndS": 10}'
```

## Notes {#notes}

- Коли `precise` дорівнює `false` (за замовчуванням), кліп починається точно з того кадру, який ви вказали. Перекодовуються лише кадри між цим початком і наступним ключовим кадром, решта копіюється, тому це лишається швидким. Кінець може бути довшим на кадр-два, адже скопійований потік зберігає кадри, від яких залежать попередні кадри. Джерела, які не вдається безпечно зістикувати (H.264 з 10-бітним кольором або з черезрядковою розгорткою, інші кодеки, яким потрібен перекодований початок, а також файли AVI, FLV, MPEG і TS), натомість перекодовуються повністю.
- Якщо встановити `precise` у `true`, увесь діапазон завжди перекодовується, тож обидва краї точні, але це триває довше.
- У режимі діапазону `endS` має бути більшим за `startS`. Якщо `endS` виходить за кінець відео, кліп триває до кінця.
- У режимі країв принаймні одне зі значень `cutStartS` і `cutEndS` має бути більшим за нуль, а разом вони мають залишати частину відео. Оскільки відрізання вимірюється від тривалості кожного файла, одне налаштування працює для пакета відео з різною тривалістю.
