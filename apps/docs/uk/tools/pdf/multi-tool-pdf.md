# PDF Multi-Tool {#multi-tool-pdf}

Зберіть PDF з явного плану сторінок: переупорядковуйте, дублюйте, обертайте або видаляйте сторінки, а також витягуйте сторінки з додаткових PDF — усе в одному запиті.

## API-ендпоінт {#api-endpoint}

`POST /api/v1/tools/pdf/multi-tool-pdf`

Приймає multipart-дані форми з одним або кількома PDF-файлами та JSON-полем `settings`.
Підтримується до 20 вхідних документів і 1 200 вихідних сторінок на запит.

## Параметри {#parameters}

| Параметр | Тип | Обов'язковий | Опис |
|-----------|------|----------|-------------|
| items | array | Так | План вихідних сторінок у порядку виводу. Кожен елемент — `{ "doc": <int>, "page": <int>, "rot": <90\|180\|270, optional> }`. `doc` індексує завантажені файли в порядку завантаження (з нуля); `page` — номер сторінки з одиницею в цьому документі. |
| pageCounts | array | Так | Реальна кількість сторінок кожного завантаженого документа в тому ж порядку. Сторінка плану, що виходить за межі кількості сторінок свого документа, відхиляється з кодом 400. |

## Приклад запиту {#example-request}

Візьміть сторінки 3 і 1 першого документа, потім сторінки 1 і 2 другого, обертаючи першу вихідну сторінку на 90° за годинниковою стрілкою:

```bash
curl -X POST http://localhost:1349/api/v1/tools/pdf/multi-tool-pdf \
  -H "Authorization: Bearer si_your-api-key" \
  -F "file=@document.pdf" \
  -F "file=@extra.pdf" \
  -F 'settings={"items":[{"doc":0,"page":3,"rot":90},{"doc":0,"page":1},{"doc":1,"page":1},{"doc":1,"page":2}],"pageCounts":[3,2]}'
```

## Приклад відповіді {#example-response}

```json
{
  "jobId": "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
  "downloadUrl": "/api/v1/download/a1b2c3d4-e5f6-7890-abcd-ef1234567890/document_multi-tool.pdf",
  "originalSize": 2450000,
  "processedSize": 2450000
}
```

## Примітки {#notes}

- Та сама сторінка може з'являтися кілька разів у `items`, щоб її дублювати.
- Сторінки, відсутні в `items`, пропускаються у вихідному документі.
- `rot` записує нову орієнтацію відображення на скопійованій сторінці (у поєднанні з наявним обертанням); вміст сторінки не змінюється.
- Обертання застосовується до кожної вихідної копії, тому дублікати можуть мати різні обертання.
- Вихідний документ є новим плоским документом; закладки джерела та метадані на рівні документа не зберігаються.
- Обробка потребує бінарного файлу qpdf, який постачається в офіційному Docker-образі.
