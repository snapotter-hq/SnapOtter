# Зміна розміру сторінок PDF {#resize-pdf-pages}

Змінює розмір усіх сторінок у PDF. Вміст масштабується під нову сторінку й центрується, тому текст, векторна графіка та штрихкоди залишаються чіткими. Скористайтеся цим, щоб перетворити транспортну етикетку на сторінку 4x6 дюймів для термопринтера або перенести документ між A4 та US Letter.

## Кінцева точка API {#api-endpoint}

`POST /api/v1/tools/pdf/resize-pdf-pages`

Приймає багаточастинні дані форми з файлом PDF та полем JSON `settings`.

## Параметри {#parameters}

| Параметр | Тип | Обов’язковий | За замовчуванням | Опис |
|-----------|------|----------|---------|-------------|
| pageSize | string | Ні | `"4x6in"` | Цільовий розмір: `4x6in`, `100x150mm`, `a4`, `a5`, `a6`, `letter`, `legal` або `custom` |
| width | number | Ні | `4` | Власна ширина сторінки, використовується, коли `pageSize` має значення `custom` |
| height | number | Ні | `6` | Власна висота сторінки, використовується, коли `pageSize` має значення `custom` |
| unit | string | Ні | `"in"` | Одиниця виміру власного розміру: `in` або `mm` |
| keepOrientation | boolean | Ні | `false` | Повернути цільовий розмір відповідно до орієнтації кожної сторінки замість примусової ширини на висоту |

## Приклад запиту {#example-request}

```bash
curl -X POST http://localhost:1349/api/v1/tools/pdf/resize-pdf-pages \
  -H "Authorization: Bearer si_your-api-key" \
  -F "file=@label.pdf" \
  -F 'settings={"pageSize": "4x6in"}'
```

## Приклад відповіді {#example-response}

```json
{
  "jobId": "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
  "downloadUrl": "/api/v1/download/a1b2c3d4-e5f6-7890-abcd-ef1234567890/label_resized.pdf",
  "originalSize": 84200,
  "processedSize": 85100
}
```

## Примітки {#notes}

- Сторінки масштабуються за розміром, але не розтягуються. Якщо співвідношення сторін відрізняється, залишок місця лишається порожнім.
- Зміна розміру не обрізає сторінку. Етикетка, надрукована на чверті сторінки Letter чи A4, і далі займає лише чверть нової сторінки.
- Власні розміри мають бути від 0,5 до 200 дюймів (12,7-5080 мм) з кожного боку.
- Розмір сторінки змінюється за її crop box, якщо він є, тож в обрізаної сторінки зберігається лише обрізана область.
