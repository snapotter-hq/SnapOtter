# Об'єднання текстових файлів {#merge-text}

Об'єднайте кілька текстових файлів або файлів Markdown в один файл. Файли з'єднуються в порядку завантаження, тому, якщо порядок важливий, змініть його в списку файлів перед запуском.

## Кінцева точка API {#api-endpoint}

`POST /api/v1/tools/files/merge-text`

Приймає дані форми multipart з двома або більше текстовими файлами та необов'язковим JSON-рядком `settings`.

## Параметри {#parameters}

| Параметр | Тип | За замовчуванням | Опис |
|-----------|------|---------|-------------|
| `separator` | string | `"blank-line"` | Що вставляється між файлами: `"blank-line"`, `"rule"` (рядок `---`) або `"filename-heading"` (назва кожного файлу як заголовок) |

## Приклад запиту {#example-request}

```bash
curl -X POST http://localhost:1349/api/v1/tools/files/merge-text \
  -H "Authorization: Bearer si_your-api-key" \
  -F "file=@chapter-1.md" \
  -F "file=@chapter-2.md" \
  -F 'settings={"separator":"filename-heading"}'
```

## Приклад відповіді {#example-response}

```json
{
  "jobId": "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
  "downloadUrl": "/api/v1/download/a1b2c3d4-e5f6-7890-abcd-ef1234567890/merged.md",
  "originalSize": 8200,
  "processedSize": 8240
}
```

## Примітки {#notes}

- Приймає файли `.txt`, `.md`, `.markdown`, `.csv` і `.log`, від 2 до 50 в одному запиті.
- Кожен файл має бути текстом UTF-8. Двійковий файл або файл не в UTF-8 відхиляється, а його назву вказано в помилці.
- Якщо всі вхідні файли мають однакове розширення, результат зберігає його (`merged.md`, `merged.log`). Змішані вхідні файли дають `merged.txt`.
- З `filename-heading` вивід Markdown використовує заголовки `# name.md`, а вивід у вигляді простого тексту використовує рядки-маркери `==> name.txt <==`.
- Порожні рядки в кінці кожного файлу обрізаються, щоб роздільник охайно стояв між документами. Початкова позначка порядку байтів відкидається.
- Файли CSV з'єднуються як простий текст. Використовуйте [Об'єднання CSV](./merge-csvs), щоб об'єднувати таблиці з єдиним рядком заголовка.
- Файли електронної пошти `.eml` поки не підтримуються.
