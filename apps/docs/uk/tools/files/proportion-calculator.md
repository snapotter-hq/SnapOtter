# Калькулятор пропорцій {#proportion-calculator}

Розв’язує правило трьох (перехресне множення). Введіть три значення, виберіть пряму або обернену пропорцію й отримайте четверте. Значення залишаються у формі після кожної відповіді, тож можна змінити одне число й натиснути Enter, щоб спробувати наступне.

Це математичний розв’язувач пропорцій, а не сітка композиції фотографій за правилом третин.

## Кінцева точка API {#api-endpoint}

`POST /api/v1/tools/files/proportion-calculator`

Приймає тіло JSON, а не багаточастинні дані форми, і відповідає числом, а не файлом для завантаження.

## Параметри {#parameters}

| Назва | Тип | За замовчуванням | Опис |
|------|------|---------|-------------|
| `a` | number | (обов’язковий) | Перше відоме значення. |
| `b` | number | (обов’язковий) | Значення, що відповідає `a`. |
| `c` | number | (обов’язковий) | Третє відоме значення. X - значення, що йому відповідає. |
| `mode` | string | `direct` | `direct` або `inverse`. |

| Режим | Читається як | Формула | Приклад |
|-------|--------------|---------|---------|
| `direct` | A відноситься до B, як C до X | X = B × C ÷ A | 3 яблука коштують 6, отже 10 яблук коштують 20 |
| `inverse` | A × B = C × X | X = A × B ÷ C | 4 робітники витрачають 6 днів, отже 8 робітників витратять 3 дні |

## Приклад запиту {#example-request}

```bash
curl -X POST http://localhost:1349/api/v1/tools/files/proportion-calculator \
  -H "Authorization: Bearer si_your-api-key" \
  -H "Content-Type: application/json" \
  -d '{"a": 3, "b": 6, "c": 10, "mode": "direct"}'
```

## Приклад відповіді {#example-response}

```json
{
  "mode": "direct",
  "x": 20
}
```

## Примітки {#notes}

- Відповідь округлюється до 15 значущих цифр, тому `0.1 × 3 ÷ 3` повертається як `0.1`, а не як `0.10000000000000002`.
- `a` не може бути `0` у прямій пропорції, а `c` не може бути `0` в оберненій, бо кожне з них є дільником. В обох випадках повертається помилка 400.
- Відповідь за межами діапазону, який може зберігати double (вище приблизно `1.8e308` або надто близька до нуля, щоб зберегти точність), повертає помилку 400.
- У вебзастосунку можна вводити `1,5` або `1.5`, а також працюють арабо-індійські цифри та цифри деванагарі. Роздільники тисяч не приймаються.
