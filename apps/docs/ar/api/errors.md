# رموز الأخطاء {#error-codes}

لكل استجابة خطأ بصيغة JSON البنية نفسها:

```json
{
  "error": "Job not found",
  "code": "NOT_FOUND",
  "requestId": "req-42"
}
```

| الحقل | موجود دائمًا | المعنى |
|-------|----------------|---------|
| `error` | نعم | رسالة مقروءة للبشر. آمنة للعرض على المستخدمين. لا تحلّلها برمجيًا. |
| `code` | نعم | رمز ثابت مقروء آليًا. استخدمه في التفرّع المنطقي. |
| `requestId` | نعم | معرّف الخادم لهذا الطلب. اذكره عند الإبلاغ عن مشكلة، فهو يطابق سجل الخادم. |
| `details` | أحيانًا | سياق إضافي لبعض أخطاء 4xx، مثل رسالة التحقق من الصحة. |

قد تتغير الرسائل بين الإصدارات. أما الرموز فلا تتغير، لذا اكتب منطق العميل بالاعتماد على `code`.

## الرموز المشتقة من حالة HTTP {#status-codes}

عندما لا يحدد المسار رمزه الخاص، يشتق الخادم رمزًا من الحالة:

| حالة HTTP | `code` |
|-------------|--------|
| 400 | `BAD_REQUEST` |
| 401 | `AUTH_REQUIRED` |
| 403 | `FORBIDDEN` |
| 404 | `NOT_FOUND` |
| 409 | `CONFLICT` |
| 413 | `PAYLOAD_TOO_LARGE` |
| 415 | `UNSUPPORTED_MEDIA_TYPE` |
| 422 | `UNPROCESSABLE_ENTITY` |
| 429 | `RATE_LIMITED` |
| 500 | `INTERNAL_ERROR` |
| 501 | `NOT_IMPLEMENTED` |
| 503 | `SERVICE_UNAVAILABLE` |
| 507 | `INSUFFICIENT_STORAGE` |

أي حالة 4xx أخرى تعود إلى `BAD_REQUEST`، وأي حالة 5xx أخرى تعود إلى `INTERNAL_ERROR`.

يمكن للمسار تحديد رمز أكثر تخصيصًا، وعندها تحمل الاستجابة ذلك الرمز بدلًا منه. فمثلًا، الأداة التي لا تستطيع العمل بسبب غياب حزمة الذكاء الاصطناعي الخاصة بها تعيد رمزًا خاصًا بالميزة. تُوصف هذه الرموز مع الميزة التي تُصدرها.

## المصادقة والوصول {#auth-codes}

| `code` | الحالة | ما يجب فعله |
|--------|--------|------------|
| `AUTH_REQUIRED` | 401 | أرسل `Authorization: Bearer <token>` مع رمز جلسة أو مفتاح API (`si_...`). |
| `FORBIDDEN` | 403 | بيانات الاعتماد صالحة لكنها تفتقر إلى الصلاحية. اطلب الصلاحية من مسؤول. |
| `MUST_CHANGE_PASSWORD` | 403 | يجب على الحساب تغيير كلمة مروره قبل أن يتمكن من استدعاء نقاط نهاية أخرى. استدعِ `POST /api/auth/change-password` باستخدام رمز الجلسة، ثم أعد المحاولة. |
| `USER_DISABLED` | 403 | الحساب معطّل. يجب على مسؤول إعادة تفعيله. |
| `LOGIN_THROTTLED` | 429 | محاولات تسجيل دخول فاشلة كثيرة جدًا. انتظر قبل المحاولة مرة أخرى. |
| `VALIDATION_ERROR` | 400 | فشل التحقق من صحة جسم الطلب أو معاملاته. `details` يحدد المشكلة. |

حساب المسؤول عند أول تشغيل هو `admin` بكلمة المرور `admin` ما لم يغيّرها `DEFAULT_USERNAME` أو `DEFAULT_PASSWORD`. وما لم يُضبط `SKIP_MUST_CHANGE_PASSWORD`، يحصل ذلك الحساب على `MUST_CHANGE_PASSWORD` في كل استدعاء إلى أن تتغير كلمة المرور.

## المهام {#job-codes}

المهمة الفاشلة تُبلغ عن سببها في المهمة نفسها، لا في خطأ HTTP. اقرأ `error.code` و`error.message` من `GET /api/v1/jobs/{jobId}`. راجع [تتبع التقدم](/ar/api/rest#progress-tracking).

تحتفظ المهمة الفاشلة بـ `error.code` فقط عندما يكون الفشل خطأ في المدخلات أو عطلًا في الخادم. أما حالات الفشل الأخرى فتحمل الرسالة وحدها.

| `code` | المعنى | ما يجب فعله |
|--------|---------|------------|
| `CANCELED` | ألغى مستخدم المهمة. وهو ليس حالة HTTP. تحمل أحداث التقدم `phase: failed` مع هذا الرمز. | تعامل معه على أنه إلغاء من المستخدم. لا تعد المحاولة تلقائيًا. |
| `INPUT_MISSING` | أُزيل الإدخال قبل تشغيل المهمة. | ارفع الملف مرة أخرى. |
| `ENGINE_UNAVAILABLE` | تعذّر تشغيل محرك مطلوب على الخادم. | أعد المحاولة بعد أن يصلح مسؤول التثبيت. |
| `JOB_STALLED` | لا يُعاد إلى العملاء، بل يصنّف تقرير الأخطاء الخاص بالخادم. فقد العامل قفل المهمة عددًا من المرات يتجاوز ما تسمح به الطابور، وغالبًا بسبب إعادة تشغيل الخادم أو نفاد الذاكرة أو المعالج. تفشل المهمة برسالة تفيد بأنها قوطعت. | أعد المحاولة. إذا استمر ذلك، فامنح الخادم ذاكرة أكبر أو خفّض `CONCURRENT_JOBS`. |

| `INVALID_CODE` | 401 | رمز TOTP أو رمز الاسترداد خاطئ. | اطلب من المستخدم رمزًا جديدًا ثم أعد المحاولة. تنتهي الإخفاقات المتكررة بـ `MFA_ATTEMPTS_EXHAUSTED`. |
| `MFA_ATTEMPTS_EXHAUSTED` | 401 | رموز خاطئة كثيرة جدًا. يُهمَل التحدي. | ابدأ تسجيل الدخول من جديد للحصول على تحدٍّ جديد. |

| `MFA_NOT_CONFIGURED` | 401 | ليس للحساب سر TOTP، لذا لا يمكن التحقق من الرمز. | سجّل MFA قبل تسجيل الدخول برمز. |
| `MFA_ALREADY_ENABLED` | 409 | MFA مفعّل بالفعل على الحساب. | لا تسجّل مرة أخرى. |
| `NO_PENDING_ENROLLMENT` | 400 | وصل تأكيد تسجيل دون وجود تسجيل معلّق. | استدعِ نقطة نهاية التسجيل أولًا. |
| `MFA_NOT_ENABLED` | 400 | يتطلب الإجراء أن يكون MFA مفعّلًا، وهو معطّل لهذا المستخدم. | تخطَّ الإجراء، أو فعّل MFA أولًا. |

| `DECRYPTION_FAILED` | 500 | تعذّر فك تشفير قيمة مخزّنة (إعداد، أو ترويسة مصادقة webhook، أو سر TOTP). | إجراء على المشغّل، كما سبق. لا تعد المحاولة. |
| `IDLE_TIMEOUT` | 401 | انتهت صلاحية الجلسة بعد فترة من عدم النشاط. | سجّل الدخول مرة أخرى. |
| `INVALID_PASSWORD` | 401 | كلمة المرور الحالية خاطئة عند تغيير كلمة المرور. | اطلب من المستخدم كلمة المرور الحالية. |
| `PASSWORD_CHANGED` | 409 | تغيّرت كلمة المرور في جلسة أخرى، أو أعاد مسؤول تعيينها، أثناء تنفيذ هذا الطلب. | سجّل الدخول مرة أخرى. |
| `OIDC_NO_PASSWORD` | 400 | طُلب تغيير كلمة المرور أو إعادة تعيينها لحساب أُنشئ عبر SSO. | وجّه المستخدم إلى مزوّد الهوية. |

## OIDC {#oidc-codes}

لا تعيد إخفاقات OIDC أثناء تسجيل الدخول جسم JSON. يعيد مسار تسجيل الدخول التوجيه إلى صفحة تسجيل الدخول بسبب عام، ويسجّل سجل التدقيق الرمز. ولا يزال مسار تسجيل الخروج ينهي الجلسة المحلية عندما يتعذّر الوصول إلى مزوّد الهوية.

| `code` | الحالة | المعنى | ما يجب فعله |
|--------|--------|---------|------------|
| `OIDC_ISSUER_SCHEME_MISMATCH` | لا شيء (إعادة توجيه) | عنوان URL للمُصدِر هو `http`، لكن `EXTERNAL_URL` هو `https`، لذا يرفض العميل الاكتشاف. | المسؤول: قدّم المُصدِر عبر `https`، أو شغّل النسخة عبر `http`. |
| `OIDC_DISCOVERY_TIMEOUT` | لا شيء (إعادة توجيه) | انتهت مهلة اكتشاف المُصدِر. | تحقق من أن الخادم يستطيع الوصول إلى المُصدِر، ثم أعد المحاولة. |
| `OIDC_DISCOVERY_FAILED` | لا شيء (إعادة توجيه) | فشل الاكتشاف لسبب آخر. | تحقق من عنوان URL للمُصدِر ومن وصول الخادم إلى الخارج. |
| `OIDC_END_SESSION_INVALID` | لا شيء (يستمر تسجيل الخروج) | `end_session_endpoint` الخاص بمزوّد الهوية ليس عنوان URL صالحًا. تُمسح الجلسة المحلية مع ذلك. | المسؤول: أصلح بيانات المزوّد الوصفية. |
| `OIDC_END_SESSION_SCHEME` | لا شيء (يستمر تسجيل الخروج) | يستخدم `end_session_endpoint` مخططًا لا يسمح به الخادم. تُمسح الجلسة المحلية مع ذلك. | المسؤول: أصلح بيانات المزوّد الوصفية. |

## SAML {#saml-codes}

لا تضبط إخفاقات SAML `code`. يعيد التأكيد الفاشل التوجيه إلى صفحة تسجيل الدخول مع `saml_auth_failed`، ويسجّل حدث التدقيق `SAML_LOGIN_FAILED` السبب.

## SCIM {#scim-codes}

تستجيب مسارات SCIM بغلاف الأخطاء الخاص بـ RFC 7644 (`schemas` و`detail` و`status` وأحيانًا `scimType`). ولا تضبط `code`. استخدم حالة HTTP في التفرّع.

## الفرق والأدوار والمستخدمون {#team-role-codes}

تعيد أسماء الفرق أو الأدوار المكررة `CONFLICT` العام، ويعيد الفريق أو الدور المفقود `NOT_FOUND`.

| `code` | الحالة | المعنى | ما يجب فعله |
|--------|--------|---------|------------|
| `ESCALATION_DENIED` | 403 | دور المستدعي لا يسمح بالتغيير. الهدف أعلى من صلاحية المستدعي، أو الدور مضمّن، أو الطلب يمنح صلاحيات لا يملكها المستدعي. | لا تعد المحاولة. اطلب من مستخدم ذي صلاحية أعلى. |
| `UNKNOWN_ROLE` | 400 | معرّف الدور لا يطابق دورًا موجودًا. | صحّح معرّف الدور. اعرض قائمة الأدوار للعثور عليه. |
| `UNKNOWN_TEAM` | 400 | معرّف الفريق لا يطابق فريقًا موجودًا. | صحّح معرّف الفريق. |
| `SELF_DEMOTE` | 400 | حاول مسؤول إزالة دور المسؤول الخاص به. | اطلب من مسؤول آخر إجراء التغيير. |
| `SELF_DELETE` | 400 | حاول مسؤول حذف حسابه. | اطلب من مسؤول آخر حذفه. |
| `LAST_ADMIN` | 400 في مسارات المستخدمين، 409 في مسارات حذف GDPR النهائي | سيترك التغيير النسخة بلا مسؤول، أو سيحذف فريقًا يضم كل المسؤولين. | اجعل مستخدمًا آخر مسؤولًا أولًا. |
| `USER_LIMIT_REACHED` | 403 | بلغت النسخة حدّ `MAX_USERS`. | أزل مستخدمًا، أو ارفع `MAX_USERS`. |

## الميزات وحزم الذكاء الاصطناعي {#feature-codes}

تستخدم الأدوات وعمليات الدُفعات وخطوط المعالجة التي تحتاج إلى حزمة ذكاء اصطناعي اختيارية هذه الرموز.

| `code` | الحالة | المعنى | ما يجب فعله |
|--------|--------|---------|------------|
| `FEATURE_NOT_INSTALLED` | 501، أو 400 من وضع الوجوه في Smart Crop | تحتاج الأداة، أو خطوة واحدة من خط معالجة أو دفعة، إلى حزمة غير مثبّتة. يتضمن الجسم `feature` (معرّف الحزمة) و`featureName`. | ثبّت الحزمة من الإعدادات، ثم أعد المحاولة. |
| `FEATURE_CPU_UNSUPPORTED` | 409 | رُفض التثبيت أو الاستيراد دون اتصال لأن مكتبات الحزمة لمعمارية x86-64 تحتاج إلى AVX ومعالج هذا الخادم لا يدعمه. لم يُنزَّل شيء ولم يُثبَّت شيء. يتضمن الجسم `feature` (معرّف الحزمة) و`reason` (`cpu-no-avx`). ويبلغ `GET /api/v1/features` عن الحزمة نفسها مع `compatibility: "incompatible"` و`compatibilityReason: "cpu-no-avx"`. | شغّل SnapOtter على معالج يدعم AVX، أو على arm64. لا تزال الحزم الأخرى تُثبَّت. |
| `FEATURE_INSTALL_BUSY` | 409 | رُفض الإلغاء لأن المثبّت يكتب في بيئة الذكاء الاصطناعي المشتركة، وإيقافه عندئذ سيعطّل كل أدوات الذكاء الاصطناعي المثبّتة. | انتظر حتى ينتهي التثبيت، ثم ألغِ تثبيت الحزمة إن كنت لا تريدها. |
| `FEATURE_INCOMPATIBLE` | 501، أو 400 عندما تتلقى Fast OCR لغة لا تستطيع قراءتها | لا تستطيع الميزة المثبّتة تقديم الجودة أو اللغة المطلوبة. | غيّر الإعداد، أو ثبّت حزمة تدعمه. |
| `ENGINE_UNAVAILABLE` | 503 | تعذّر تشغيل محرك مطلوب، أو أُزيل وقت تشغيل OCR بعد التحقق من صحة الطلب. | أعد المحاولة بعد أن يصلح مسؤول الميزة أو يعيد تثبيتها. |
| `BROWSER_NOT_AVAILABLE` | 503 | Chromium غير مثبّت، لذا لا يمكن تشغيل HTML إلى صورة. | اطلب من مسؤول تثبيت المتصفح. |
| `BROWSER_CRASHED` | 503 | تعطّل متصفح لقطات الشاشة أثناء العرض. | أعد الطلب. |

## خطوط المعالجة والدُفعات {#pipeline-codes}

تعيد طلبات خطوط المعالجة والدُفعات رموز الميزات المذكورة أعلاه لكل خطوة تحتاج إلى حزمة. ويعيد معرّف مهمة مستخدَم بالفعل `CONFLICT` بالحالة 409. أرسل معرّف مهمة جديدًا.

## الإعدادات {#settings-codes}

| `code` | الحالة | المعنى | ما يجب فعله |
|--------|--------|---------|------------|
| `UNKNOWN_SETTING` | 400 | المفتاح ليس إعدادًا معروفًا. | تحقق من اسم المفتاح. |
| `READONLY_SETTING` | 400 | لا يمكن تغيير الإعداد عبر API. | غيّره عبر البيئة أو واجهة المسؤول. |
| `DEPENDENCY_VALIDATION_FAILED` | 400 | تتعارض القيمة الجديدة مع إعدادات أخرى. يحدد الجسم الإعداد في `setting` ويسرد المشكلات في `validationErrors`. | أصلح الإعدادات المدرجة، ثم أعد المحاولة. |
| `SETTING_DECRYPTION_FAILED` | 500 | تعذّر فك تشفير إعداد مخزّن. | إجراء على المشغّل، كما في `DECRYPTION_FAILED`. |

بالنسبة إلى `VALIDATION_ERROR` على إعداد، يحمل `details` مشكلات المخطط.

## المؤسسات {#enterprise-codes}

| `code` | الحالة | المعنى | ما يجب فعله |
|--------|--------|---------|------------|
| `FEATURE_NOT_LICENSED` | 403 | يحتاج الإعداد أو السياسة إلى ترخيص مؤسسي، مثل فرض SSO أو سياسة MFA. | استخدم نسخة مرخّصة، أو اترك الإعداد معطّلًا. |
| `IP_NOT_ALLOWED` | 403 | عنوان IP الخاص بالطلب ليس في قائمة السماح. | اتصل من شبكة مسموح بها. |
| `INVALID_CIDR` | 400 | مدخل في قائمة السماح ليس CIDR صالحًا. تسرد الرسالة المدخلات الخاطئة. | أصلح المدخلات واحفظ مرة أخرى. |
| `SELF_LOCKOUT` | 400 | سيؤدي حفظ قائمة السماح إلى حظر عنوان IP الحالي للمستدعي. | أضف عنوان IP الحالي إلى القائمة أولًا. |

تعيد مسارات حذف GDPR النهائي `CONFLICT` عادية بالحالة 409 عندما يكون مستخدم أو فريق تحت حجز قانوني.

## رموز لا يتلقاها العملاء {#internal-codes}

توجد هذه الرموز في مصدر الخادم للسجلات أو القياس عن بُعد أو أخطاء Fastify نفسها. لا يحصل العميل عليها في جسم استجابة أو صف مهمة، لذا لا تكتب منطق العميل بالاعتماد عليها.

| `code` | إلى أين تذهب |
|--------|---------------|
| `ALERT_DECRYPTION_FAILED` | يُبلَّغ عنه إلى تتبّع الأخطاء بواسطة مقيّم التنبيهات. تعذّر فك تشفير ترويسة مصادقة webhook التنبيه. |
| `SIEM_DECRYPTION_FAILED` | يُبلَّغ عنه إلى تتبّع الأخطاء بواسطة إعادة توجيه SIEM. تعذّر فك تشفير ترويسة مصادقة SIEM. |
| `WEBHOOK_DECRYPTION_FAILED` | يُبلَّغ عنه إلى تتبّع الأخطاء. الطلب الذي واجه الفشل نفسه يستجيب بـ `DECRYPTION_FAILED`. |
| `STAGED_DISCARD_FAILED` | يُبلَّغ عنه إلى تتبّع الأخطاء عندما يتعذّر حذف رفع مرحلي. |
| `RETENTION_DEADLINE_BACKFILLED` | يُبلَّغ عنه إلى تتبّع الأخطاء بواسطة كنس TTL للتخزين عندما يملأ الموعد النهائي المفقود لاحتفاظ الفريق بمهمة منتهية. تتبع ملفات المهمة عندئذ احتفاظ الفريق. |
| `USERNAME_RACE_EXHAUSTED` | يُثار عندما يخسر الإنشاء التلقائي في SSO سباق اسم المستخدم في كل محاولة إعادة. تعرض صفحة تسجيل الدخول خطأ بدلًا من ذلك. |
| `ERR_OUT_OF_RANGE` | يُطلقه قارئ تخزين الكائنات عند نطاق بايتات غير صالح. |
| `ETIMEDOUT` | يُضبط على خطأ المهلة في تصدير GDPR. يفشل التصدير، ويمكن طلبه مرة أخرى. |
| `FST_REQ_FILE_TOO_LARGE` | رمز Fastify لرفع يتجاوز الحد. يحصل العملاء على 413 مع `PAYLOAD_TOO_LARGE`، أو رسالة 413 الخاصة بالمسار. |
| `TARGET_SIZE_EXCEEDED` | يُطلق عندما يخفق ضغط بحجم مستهدف في بلوغ هدفه. ليس للخطأ حالة أو رمز، لذا يحصل العملاء على فشل عام. |
| `OCR_CACHE_PERMISSIONS` | يُبلَّغ عنه إلى تتبّع الأخطاء كعطل تشغيلي عندما يترك حجم بيانات الذكاء الاصطناعي ذاكرة وقت تشغيل OCR قابلة للكتابة من الجميع. تفشل مهمة التثبيت برسالة تسمّي مشكلة التخزين. |
| `OCR_RUNTIME_UNREACHABLE` | يُبلَّغ عنه إلى تتبّع الأخطاء كعطل تشغيلي عندما لم يصل الخادم قط إلى huggingface.co لتنزيل وقت تشغيل OCR. تفشل مهمة التثبيت برسالة عن الوصول إلى الشبكة و`HTTPS_PROXY` و`HF_ENDPOINT` والاستيراد دون اتصال. |
