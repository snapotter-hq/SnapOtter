# حاسبة نسبة العرض إلى الارتفاع {#aspect-ratio-calculator}

أدخل العرض والارتفاع الأصليين، ثم عرضًا جديدًا أو ارتفاعًا جديدًا، لتحصل على الضلع الآخر بحيث تبقى الأبعاد متناسبة. تُعاد النسبة في أبسط صورة، فتصبح 1920 × 1080 هي 16:9. في تطبيق الويب يمكنك البدء من نسبة شائعة (16:9 و4:3 و3:2 و1:1 و21:9 و9:16 و4:5) والتبديل بين الوضع الأفقي والرأسي.

## نقطة نهاية API {#api-endpoint}

`POST /api/v1/tools/image/aspect-ratio-calculator`

يقبل جسم JSON وليس بيانات نموذج متعدّد الأجزاء (multipart)، ويستجيب بأرقام بدلًا من ملف للتنزيل.

## المعاملات {#parameters}

| المعامل | النوع | الافتراضي | الوصف |
|-----------|------|---------|-------------|
| `width` | number | (مطلوب) | العرض الأصلي. |
| `height` | number | (مطلوب) | الارتفاع الأصلي. |
| `newWidth` | number | - | العرض المستهدف. تحسب الاستجابة منه `newHeight`. |
| `newHeight` | number | - | الارتفاع المستهدف. تحسب الاستجابة منه `newWidth`. |
| `round` | boolean | `true` | تقريب الضلع المحسوب إلى عدد صحيح. وعندما تكون القيمة `false` يُحتفظ بمنزلتين عشريتين. |

يجب أن تقع كل قيمة للأبعاد بين `0.0001` و`1000000`. أرسل `newWidth` أو `newHeight` وليس كليهما. اترك الاثنين معًا للحصول على النسبة المبسّطة فقط.

## مثال على الطلب {#example-request}

```bash
curl -X POST http://localhost:1349/api/v1/tools/image/aspect-ratio-calculator \
  -H "Authorization: Bearer si_your-api-key" \
  -H "Content-Type: application/json" \
  -d '{"width": 1920, "height": 1080, "newWidth": 1280}'
```

## مثال على الاستجابة {#example-response}

```json
{
  "width": 1920,
  "height": 1080,
  "ratio": "16:9",
  "ratioDecimal": 1.7778,
  "newWidth": 1280,
  "newHeight": 720
}
```

تكون `newWidth` و`newHeight` `null` عندما لا يرسل الطلب أيًّا منهما.

## ملاحظات {#notes}

- تُختزل الأحجام الكسرية إلى نسبة أعداد صحيحة باستخدام حتى أربع منازل عشرية، فتُعاد `8.5` × `11` على هيئة `17:22`.
- `ratioDecimal` هي العرض مقسومًا على الارتفاع، مقرَّبة إلى أربع منازل عشرية.
- لا يُعاد الضلع المحسوب أبدًا على هيئة `0`. فمع التقريب تكون قيمته `1` على الأقل، ومن دون تقريب تكون `0.01` على الأقل.
- يؤدي إرسال `newWidth` و`newHeight` معًا، أو إرسال بُعد خارج النطاق المسموح، إلى إعادة الخطأ 400.
- لا تقرأ الحاسبة أي ملف ولا تكتب أي ملف. لتطبيق الأرقام استخدم [تغيير حجم الصورة](/ar/tools/image/resize) أو [اقتصاص الصورة](/ar/tools/image/crop).
