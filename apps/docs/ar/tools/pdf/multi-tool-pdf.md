# أداة PDF متعددة {#multi-tool-pdf}

تجميع ملف PDF من خطة صفحات صريحة: إعادة ترتيب الصفحات، أو تكرارها، أو تدويرها، أو حذفها، وسحب صفحات من ملفات PDF إضافية، كل ذلك في طلب واحد.

## نقطة نهاية API {#api-endpoint}

`POST /api/v1/tools/pdf/multi-tool-pdf`

يقبل بيانات نموذج multipart مع ملف PDF واحد أو أكثر وحقل JSON `settings`.
يُدعم ما يصل إلى 20 مستنداً مدخلاً و1,200 صفحة خرج لكل طلب.

## المعاملات {#parameters}

| المعامل | النوع | مطلوب | الوصف |
|-----------|------|----------|-------------|
| items | array | نعم | خطة صفحات الخرج، بترتيب الخرج. كل عنصر هو `{ "doc": <int>, "page": <int>, "rot": <90\|180\|270, optional> }`. `doc` يفهرس الملفات المرفوعة بترتيب الرفع (ابتداءً من 0)؛ `page` هو رقم صفحة (ابتداءً من 1) في ذلك المستند. |
| pageCounts | array | نعم | العدد الحقيقي لصفحات كل مستند مرفوع، بالترتيب نفسه. تُرفض صفحة في الخطة تتجاوز عدد صفحات مستندّها برمز 400. |

## مثال على الطلب {#example-request}

خذ الصفحات 3 و1 من المستند الأول، ثم الصفحات 1 و2 من الثاني، مع تدوير أول صفحة خرج 90° باتجاه عقارب الساعة:

```bash
curl -X POST http://localhost:1349/api/v1/tools/pdf/multi-tool-pdf \
  -H "Authorization: Bearer si_your-api-key" \
  -F "file=@document.pdf" \
  -F "file=@extra.pdf" \
  -F 'settings={"items":[{"doc":0,"page":3,"rot":90},{"doc":0,"page":1},{"doc":1,"page":1},{"doc":1,"page":2}],"pageCounts":[3,2]}'
```

## مثال على الاستجابة {#example-response}

```json
{
  "jobId": "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
  "downloadUrl": "/api/v1/download/a1b2c3d4-e5f6-7890-abcd-ef1234567890/document_multi-tool.pdf",
  "originalSize": 2450000,
  "processedSize": 2450000
}
```

## ملاحظات {#notes}

- يمكن أن تظهر نفس الصفحة عدة مرات في `items` لتكرارها.
- الصفحات غير الموجودة في `items` تُحذف من الخرج.
- `rot` يسجّل اتجاه العرض الجديد على الصفحة المنسوخة (مُركّباً مع أي تدوير موجود)؛ محتوى الصفحة لا يُمس.
- يُطبَّق التدوير لكل نسخة خرج، لذا يمكن أن يكون للنسخ المكررة تدويرات مختلفة.
- الخرج هو مستند جديد مسطّح؛ الإشارات المرجعية (bookmarks) والبيانات الوصفية على مستوى المستند لا تُحتفظ بها.
- تتطلب المعالجة الملف الثنائي qpdf، الذي يُشحن في صورة Docker الرسمية.
