# حاسبة النسبة والتناسب {#proportion-calculator}

يحلّ قاعدة الثلاثة (الضرب التبادلي). اكتب ثلاث قيم، واختر تناسبًا طرديًا أو عكسيًا، واحصل على القيمة الرابعة. تبقى القيم في النموذج بعد كل إجابة، فيمكنك تغيير رقم واحد والضغط على Enter لتجربة الحالة التالية.

هذا حلّال للنسبة والتناسب الرياضي، وليس شبكة قاعدة الأثلاث لتكوين الصور.

## نقطة نهاية API {#api-endpoint}

`POST /api/v1/tools/files/proportion-calculator`

يقبل جسم JSON وليس بيانات نموذج متعدد الأجزاء، ويردّ برقم بدلًا من ملف للتنزيل.

## المعاملات {#parameters}

| الاسم | النوع | الافتراضي | الوصف |
|------|------|---------|-------------|
| `a` | number | (مطلوب) | القيمة المعروفة الأولى. |
| `b` | number | (مطلوب) | القيمة المقابلة لـ `a`. |
| `c` | number | (مطلوب) | القيمة المعروفة الثالثة. X هي القيمة المقابلة لها. |
| `mode` | string | `direct` | `direct` أو `inverse`. |

| الوضع | يُقرأ | الصيغة | مثال |
|------|---------|---------|---------|
| `direct` | A إلى B كما أن C إلى X | X = B × C ÷ A | 3 تفاحات تكلّف 6، إذن 10 تفاحات تكلّف 20 |
| `inverse` | A × B = C × X | X = A × B ÷ C | 4 عمال يحتاجون 6 أيام، إذن 8 عمال يحتاجون 3 أيام |

## مثال طلب {#example-request}

```bash
curl -X POST http://localhost:1349/api/v1/tools/files/proportion-calculator \
  -H "Authorization: Bearer si_your-api-key" \
  -H "Content-Type: application/json" \
  -d '{"a": 3, "b": 6, "c": 10, "mode": "direct"}'
```

## مثال استجابة {#example-response}

```json
{
  "mode": "direct",
  "x": 20
}
```

## ملاحظات {#notes}

- تُقرَّب الإجابة إلى 15 رقمًا معنويًا، لذا يعود `0.1 × 3 ÷ 3` بالقيمة `0.1` وليس `0.10000000000000002`.
- لا يمكن أن يكون `a` مساويًا لـ `0` في التناسب الطردي، ولا أن يكون `c` مساويًا لـ `0` في التناسب العكسي، لأن كلًّا منهما هو المقسوم عليه. وكلاهما يُرجع خطأ 400.
- الإجابة التي تقع خارج النطاق الذي يستطيع النوع double حمله (فوق نحو `1.8e308`، أو قريبة جدًا من الصفر بحيث تفقد دقتها) تُرجع خطأ 400.
- في تطبيق الويب يمكنك كتابة `1,5` أو `1.5`، كما تعمل الأرقام الهندية العربية وأرقام ديفاناغاري. لا تُقبل فواصل الآلاف.
