# Калькулятор соотношения сторон {#aspect-ratio-calculator}

Введите исходную ширину и высоту, затем новую ширину или новую высоту, и получите вторую сторону с сохранением пропорций. Соотношение возвращается в простейшем виде, поэтому 1920 × 1080 это 16:9. В веб-приложении можно начать с распространённого соотношения (16:9, 4:3, 3:2, 1:1, 21:9, 9:16, 4:5) и переключаться между альбомной и портретной ориентацией.

## Конечная точка API {#api-endpoint}

`POST /api/v1/tools/image/aspect-ratio-calculator`

Принимает тело JSON (не multipart) и отвечает числами, а не файлом для скачивания.

## Параметры {#parameters}

| Имя | Тип | По умолчанию | Описание |
|------|------|---------|-------------|
| `width` | number | (обязательный) | Исходная ширина. |
| `height` | number | (обязательный) | Исходная высота. |
| `newWidth` | number | - | Целевая ширина. Ответ вычисляет по ней `newHeight`. |
| `newHeight` | number | - | Целевая высота. Ответ вычисляет по ней `newWidth`. |
| `round` | boolean | `true` | Округлять вычисленную сторону до целого числа. При `false` сохраняются два знака после запятой. |

Каждый размер должен быть в пределах от `0.0001` до `1000000`. Передавайте `newWidth` или `newHeight`, но не оба сразу. Если не передавать ни один из них, вернётся только упрощённое соотношение.

## Пример запроса {#example-request}

```bash
curl -X POST http://localhost:1349/api/v1/tools/image/aspect-ratio-calculator \
  -H "Authorization: Bearer si_your-api-key" \
  -H "Content-Type: application/json" \
  -d '{"width": 1920, "height": 1080, "newWidth": 1280}'
```

## Пример ответа {#example-response}

```json
{
  "width": 1920,
  "height": 1080,
  "ratio": "16:9",
  "ratioDecimal": 1.7778,
  "newWidth": 1280,
  "newHeight": 720
}
```

`newWidth` и `newHeight` равны `null`, если в запросе не было ни одного из них.

## Примечания {#notes}

- Дробные размеры приводятся к соотношению целых чисел с точностью до четырёх знаков после запятой, поэтому `8.5` × `11` возвращается как `17:22`.
- `ratioDecimal` это ширина, делённая на высоту, с округлением до четырёх знаков после запятой.
- Вычисленная сторона никогда не возвращается равной `0`. При включённом округлении она не меньше `1`, а при выключенном не меньше `0.01`.
- Если передать одновременно `newWidth` и `newHeight` или размер вне допустимого диапазона, вернётся ошибка 400.
- Калькулятор никогда не читает и не записывает файлы. Чтобы применить полученные числа, используйте [Изменение размера изображения](/ru/tools/image/resize) или [Обрезка изображения](/ru/tools/image/crop).
