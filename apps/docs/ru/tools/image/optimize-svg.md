# Оптимизация SVG {#optimize-svg}

Уменьшайте SVG-файлы, удаляя следы редактора, лишние атрибуты и избыточные десятичные знаки, и скачивайте результат как SVG. В отличие от инструмента «Оптимизация для веб», результат никогда не растеризуется.

## Эндпоинт API {#api-endpoint}

`POST /api/v1/tools/image/optimize-svg`

Принимает данные формы multipart с файлом `.svg` или `.svgz` и JSON-полем `settings`.

## Параметры {#parameters}

| Параметр | Тип | Обязательный | По умолчанию | Описание |
|-----------|------|----------|---------|-------------|
| precision | number | Нет | `3` | Количество десятичных знаков, сохраняемых в данных контуров и числах (от 0 до 8). Меньшие значения дают файлы поменьше и чуть менее плавные кривые. |
| multipass | boolean | Нет | `true` | Запускать оптимизатор повторно, пока результат не перестанет уменьшаться |
| removeMetadata | boolean | Нет | `true` | Удалять комментарии, `<metadata>`, пустые или созданные редакторами элементы `<desc>` и данные, специфичные для редакторов. Отключите, чтобы сохранить их. |
| pretty | boolean | Нет | `false` | Добавлять отступы для читаемости вместо минификации в несколько строк |

## Пример запроса {#example-request}

```bash
curl -X POST http://localhost:1349/api/v1/tools/image/optimize-svg \
  -F "file=@logo.svg" \
  -F 'settings={"precision":3,"multipass":true,"removeMetadata":true,"pretty":false}'
```

## Пример ответа {#example-response}

```json
{
  "jobId": "a1b2c3d4-e5f6-7890-abcd-ef1234567890",

  "originalSize": 48213,
  "processedSize": 17904
}
```

## Примечания {#notes}

- Входной файл должен быть SVG или SVGZ. Растровое изображение отклоняется с `400` и кодом `IMAGE_UNDECODABLE`.
- Вход `.svgz` сначала распаковывается, а результат всегда обычный `.svg`.
- После распаковки размер SVG ограничен 10 МБ. Файл больше отклоняется с `400` и кодом `SVG_TOO_LARGE`.
- `viewBox` и `<title>` всегда сохраняются, поэтому графика по-прежнему масштабируется и сохраняет доступное имя.
- Вход и результат проходят через санитайзер SVG, который удаляет скрипты и другое активное содержимое.
- Уменьшение `precision` даёт наибольшую экономию размера для графики с большим числом контуров. Проверьте результат визуально при значениях от 0 до 2.
