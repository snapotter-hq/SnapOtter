# Объединение текстовых файлов {#merge-text}

Объедините несколько текстовых файлов или файлов Markdown в один файл. Файлы соединяются в порядке загрузки, поэтому, если порядок важен, переставьте их в списке файлов перед запуском.

## Конечная точка API {#api-endpoint}

`POST /api/v1/tools/files/merge-text`

Принимает данные формы multipart с двумя или более текстовыми файлами и необязательной JSON-строкой `settings`.

## Параметры {#parameters}

| Параметр | Тип | По умолчанию | Описание |
|-----------|------|---------|-------------|
| `separator` | string | `"blank-line"` | Что вставляется между файлами: `"blank-line"`, `"rule"` (строка `---`) или `"filename-heading"` (имя каждого файла в виде заголовка) |

## Пример запроса {#example-request}

```bash
curl -X POST http://localhost:1349/api/v1/tools/files/merge-text \
  -H "Authorization: Bearer si_your-api-key" \
  -F "file=@chapter-1.md" \
  -F "file=@chapter-2.md" \
  -F 'settings={"separator":"filename-heading"}'
```

## Пример ответа {#example-response}

```json
{
  "jobId": "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
  "downloadUrl": "/api/v1/download/a1b2c3d4-e5f6-7890-abcd-ef1234567890/merged.md",
  "originalSize": 8200,
  "processedSize": 8240
}
```

## Примечания {#notes}

- Принимает файлы `.txt`, `.md`, `.markdown`, `.csv` и `.log`, от 2 до 50 в одном запросе.
- Каждый файл должен быть текстом в UTF-8. Двоичный файл или файл не в UTF-8 отклоняется, а его имя указывается в ошибке.
- Если у всех входных файлов одинаковое расширение, результат сохраняет его (`merged.md`, `merged.log`). Смешанные входные файлы дают `merged.txt`.
- С `filename-heading` вывод Markdown использует заголовки `# name.md`, а вывод в виде простого текста использует строки-маркеры `==> name.txt <==`.
- Пустые строки в конце каждого файла удаляются, чтобы разделитель аккуратно стоял между документами. Начальная метка порядка байтов отбрасывается.
- Файлы CSV соединяются как простой текст. Используйте [Объединение CSV](./merge-csvs), чтобы объединять таблицы с единственной строкой заголовка.
- Файлы электронной почты `.eml` пока не поддерживаются.
