# Калькулятор пропорций {#proportion-calculator}

Решает тройное правило (перекрёстное умножение). Введите три значения, выберите прямую или обратную пропорцию и получите четвёртое. Значения остаются в форме после каждого ответа, так что можно изменить одно число и нажать Enter, чтобы попробовать следующее.

Это математический решатель пропорций, а не сетка композиции фотографий по правилу третей.

## Конечная точка API {#api-endpoint}

`POST /api/v1/tools/files/proportion-calculator`

Принимает тело JSON, а не multipart form data, и отвечает числом, а не файлом для загрузки.

## Параметры {#parameters}

| Имя | Тип | По умолчанию | Описание |
|------|------|---------|-------------|
| `a` | number | (обязательный) | Первое известное значение. |
| `b` | number | (обязательный) | Значение, соответствующее `a`. |
| `c` | number | (обязательный) | Третье известное значение. X - значение, которое ему соответствует. |
| `mode` | string | `direct` | `direct` или `inverse`. |

| Режим | Читается как | Формула | Пример |
|-------|--------------|---------|--------|
| `direct` | A относится к B, как C к X | X = B × C ÷ A | 3 яблока стоят 6, значит 10 яблок стоят 20 |
| `inverse` | A × B = C × X | X = A × B ÷ C | 4 рабочих тратят 6 дней, значит 8 рабочих потратят 3 дня |

## Пример запроса {#example-request}

```bash
curl -X POST http://localhost:1349/api/v1/tools/files/proportion-calculator \
  -H "Authorization: Bearer si_your-api-key" \
  -H "Content-Type: application/json" \
  -d '{"a": 3, "b": 6, "c": 10, "mode": "direct"}'
```

## Пример ответа {#example-response}

```json
{
  "mode": "direct",
  "x": 20
}
```

## Примечания {#notes}

- Ответ округляется до 15 значащих цифр, поэтому `0.1 × 3 ÷ 3` возвращается как `0.1`, а не как `0.10000000000000002`.
- `a` не может быть `0` в прямой пропорции, а `c` не может быть `0` в обратной, потому что каждое из них является делителем. В обоих случаях возвращается ошибка 400.
- Ответ за пределами диапазона, который может хранить double (выше примерно `1.8e308` или слишком близкий к нулю, чтобы сохранить точность), возвращает ошибку 400.
- В веб-приложении можно вводить `1,5` или `1.5`, а также работают арабо-индийские цифры и цифры деванагари. Разделители тысяч не принимаются.
