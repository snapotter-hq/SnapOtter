# Изменение размера страниц PDF {#resize-pdf-pages}

Изменение размера всех страниц в PDF. Содержимое масштабируется по новой странице и центрируется, поэтому текст, векторная графика и штрихкоды остаются чёткими. Используйте это, чтобы превратить транспортную этикетку в страницу 4x6 дюймов для термопринтера или перенести документ между A4 и US Letter.

## Конечная точка API {#api-endpoint}

`POST /api/v1/tools/pdf/resize-pdf-pages`

Принимает multipart form data с файлом PDF и JSON-полем `settings`.

## Параметры {#parameters}

| Параметр | Тип | Обязательный | По умолчанию | Описание |
|-----------|------|----------|---------|-------------|
| pageSize | string | Нет | `"4x6in"` | Целевой размер: `4x6in`, `100x150mm`, `a4`, `a5`, `a6`, `letter`, `legal` или `custom` |
| width | number | Нет | `4` | Произвольная ширина страницы, используется, когда `pageSize` равно `custom` |
| height | number | Нет | `6` | Произвольная высота страницы, используется, когда `pageSize` равно `custom` |
| unit | string | Нет | `"in"` | Единица измерения произвольного размера: `in` или `mm` |
| keepOrientation | boolean | Нет | `false` | Повернуть целевой размер в соответствии с ориентацией каждой страницы, а не принудительно задавать ширину на высоту |

## Пример запроса {#example-request}

```bash
curl -X POST http://localhost:1349/api/v1/tools/pdf/resize-pdf-pages \
  -H "Authorization: Bearer si_your-api-key" \
  -F "file=@label.pdf" \
  -F 'settings={"pageSize": "4x6in"}'
```

## Пример ответа {#example-response}

```json
{
  "jobId": "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
  "downloadUrl": "/api/v1/download/a1b2c3d4-e5f6-7890-abcd-ef1234567890/label_resized.pdf",
  "originalSize": 84200,
  "processedSize": 85100
}
```

## Примечания {#notes}

- Страницы масштабируются по размеру, но не растягиваются. Если соотношение сторон отличается, оставшееся место остаётся пустым.
- Изменение размера не обрезает страницу. Этикетка, напечатанная на четверти страницы Letter или A4, по-прежнему занимает только четверть новой страницы.
- Произвольные размеры должны быть от 0,5 до 200 дюймов (12,7-5080 мм) по каждой стороне.
- Размер страницы изменяется по её crop box, если он есть, поэтому у обрезанной страницы сохраняется только обрезанная область.
