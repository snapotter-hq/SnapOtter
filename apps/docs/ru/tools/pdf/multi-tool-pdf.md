# PDF Multi-Tool {#multi-tool-pdf}

Соберите PDF по явному плану страниц: переупорядочивайте, дублируйте, поворачивайте или удаляйте страницы и извлекайте страницы из дополнительных PDF за один запрос.

## API Endpoint {#api-endpoint}

`POST /api/v1/tools/pdf/multi-tool-pdf`

Принимает multipart-данные формы с одним или несколькими PDF-файлами и полем JSON `settings`.
За один запрос поддерживается до 20 входных документов и 1200 выходных страниц.

## Parameters {#parameters}

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| items | array | Yes | План выходных страниц в порядке вывода. Каждый элемент — `{ "doc": <int>, "page": <int>, "rot": <90\|180\|270, optional> }`. `doc` индексирует загруженные файлы в порядке загрузки (с нуля); `page` — номер страницы в этом документе (с единицы). |
| pageCounts | array | Yes | Реальное количество страниц каждого загруженного документа в том же порядке. Страница плана, выходящая за пределы количества страниц своего документа, отклоняется с кодом 400. |

## Example Request {#example-request}

Возьмите страницы 3 и 1 первого документа, затем страницы 1 и 2 второго, повернув первую выходную страницу на 90° по часовой стрелке:

```bash
curl -X POST http://localhost:1349/api/v1/tools/pdf/multi-tool-pdf \
  -H "Authorization: Bearer si_your-api-key" \
  -F "file=@document.pdf" \
  -F "file=@extra.pdf" \
  -F 'settings={"items":[{"doc":0,"page":3,"rot":90},{"doc":0,"page":1},{"doc":1,"page":1},{"doc":1,"page":2}],"pageCounts":[3,2]}'
```

## Example Response {#example-response}

```json
{
  "jobId": "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
  "downloadUrl": "/api/v1/download/a1b2c3d4-e5f6-7890-abcd-ef1234567890/document_multi-tool.pdf",
  "originalSize": 2450000,
  "processedSize": 2450000
}
```

## Notes {#notes}

- Одну и ту же страницу можно указать в `items` несколько раз, чтобы дублировать её.
- Страницы, отсутствующие в `items`, не попадают в вывод.
- `rot` записывает новую ориентацию отображения на скопированной странице (в сочетании с существующим поворотом); содержимое страницы не изменяется.
- Поворот применяется к каждой выходной копии, поэтому у дубликатов могут быть разные повороты.
- Вывод — новый плоский документ; исходные закладки и метаданные уровня документа не сохраняются.
- Для обработки требуется бинарный файл qpdf, который входит в официальный образ Docker.
