# Список изменений {#changelog}

## v2.2.0 {#v2-2-0}

Большая часть 2.2 — это укрепление безопасности. Пользователь без прав администратора с делегированной ролью `users:manage` мог захватить экземпляр, а у каждого эндпоинта инструментов, как выяснилось, отсутствовала проверка разрешений. Обновляйтесь, если у вас больше одного пользователя.

Остальное — длинный хвост самостоятельного развёртывания: загрузки, которые начинались и никогда не заканчивались, пресеты, ломавшиеся при добавлении второго файла, контейнеры, уходившие в цикл перезапусков, пока Postgres ещё поднимался. Заодно появились два новых инструмента. Документация и сайт теперь переведены на 21 язык, а интерфейс наконец проходит по контрасту WCAG AA.

> [!IMPORTANT]
> Если вы выдали `users:manage` не администратору через пользовательскую роль, эта роль могла захватить учётные записи администраторов в версиях с 2.0.0 по 2.1.0. Подробности в разделе «Безопасность».

### Безопасность {#v2-2-0-security}

- **Повышение привилегий через делегированную роль `users:manage` (GHSA-9xgh-95qh-2x7h).** Пользователь без прав администратора, получивший `users:manage` через пользовательскую роль, мог сбросить пароль или удалить учётную запись с более высокими привилегиями, включая встроенного администратора, и захватить экземпляр. Сброс пароля и удаление учётной записи теперь проверяют полномочия вызывающего над целью, поэтому делегированная роль не может действовать выше своего уровня. Затронуты версии с 2.0.0 по 2.1.0. Сообщил 李春来 (Chunlai Li). (#616)
- **Каждый эндпоинт инструментов теперь защищён проверкой.** Доступ к инструментам проверялся маршрут за маршрутом, поэтому все 45 написанных вручную маршрутов должны были помнить об одном и том же вызове, и ни один этого не делал. Роль без `tools:use` всё ещё могла запускать image-to-pdf, erase-object, upscale, sign-pdf и остальные. Теперь проверка живёт в одном preHandler, привязанном к найденному маршруту, поэтому она покрывает подпути и любой маршрут, добавленный позже. (#646)
- **Ограничение частоты запросов можно было обойти на установках Docker.** Образ поставлялся с `TRUST_PROXY=true`, поэтому IP клиента брался из заголовка запроса, и поддельный `X-Forwarded-For` проходил мимо ограничителя входа. Теперь по умолчанию используется список доверенных частных сетей. (#649)
- **Запись настроек проверяется для каждой настройки**, а не один раз на входе, а импорт конфигурации стал транзакционным, поэтому отклонённый ключ не может оставить применённой половину конфигурации. (#618)
- **Имена файлов библиотеки не могут выйти за пределы своего корня хранения.** Подставленное сохранённое имя, которое вредоносный импорт SQLite из 1.x копирует дословно, могло читать или удалять файлы вне каталога files. Достижимо только после того, как оператор импортирует предоставленную злоумышленником базу SQLite 1.x, — это единственный путь, позволяющий выбрать сохранённое имя. Сообщил @Alpastx. (GHSA-55w2-8cqf-w969, #600)
- **Отмена задания проверяет владение**, поэтому аутентифицированный пользователь больше не может отменить чужое задание по его id. Сообщил @Alpastx. (GHSA-wqxf-gj2p-689x, #599)
- **Повторный аудит всего дерева 2.0 выявил, что ещё оставалось открытым**: перехваченное утверждение SAML можно было воспроизвести, MFA-запрос не сбрасывался после любого числа неверных кодов, поиск API-ключа на каждый запрос был полным сканированием таблицы, `MAX_WORKSPACE_SIZE_GB` оказался мёртвой настройкой, а SVG-санитайзер пропускал href с `javascript:` без кавычек. (#620)
- **Исправлено девять раскрытых CVE**: fast-uri, svgo, sharp и tar транзитивно (#619), плюс Pillow 12.3.0 (#517). Декодирование RAW на arm64 теперь собирает LibRaw 0.22.2 из исходников вместо компоновки с неисправленной системной копией. (#649)

### Новые возможности {#v2-2-0-new-features}

- **Скруглённая обрезка**: маски в виде скруглённого квадрата и «сквиркла» в стиле iOS с управлением радиусом углов. Сделано для фавиконов и иконок приложений. (#602)
- **Удаление фона GIF**: уберите фон из анимированного GIF, WebP или APNG покадрово и получите обратно прозрачную анимацию. (#502)
- **Лассо и режим высокого качества в Object Eraser**: рисуйте произвольный контур вместо закрашивания каждого пикселя и при желании установите пакет диффузионного инпейнтинга для более чистого заполнения больших областей. (#503, #566)
- **Сохранить как новый или перезаписать.** Раньше редактирование файла в библиотеке молча заменяло оригинал. Теперь вы выбираете при каждом сохранении, и по умолчанию оригинал остаётся. (#564, #577)
- **Пресеты соотношения сторон в Resize.** Выберите 1:1, 4:3 или 16:9, и два измерения останутся заблокированными, без апскейлинга. (#530)
- **Двухуровневый OCR**: быстрый уровень встроен в образ и работает офлайн без загрузки, а более точная среда выполнения устанавливается по требованию. (#519)
- **Печатайте где угодно, чтобы искать.** Начните печатать на панели управления или на главной странице, и текст попадёт в поле поиска. (#644)
- **Документация и сайт на 21 языке**: сайт документации, лендинги и справочник по API теперь переведены и присоединились к интерфейсу приложения. Новое руководство по развёртыванию на маломощных машинах охватывает Raspberry Pi и машины с 2 ГБ. (#548)
- **Более понятные названия инструментов**: 18 неоднозначных названий теперь уточняют себя, поэтому «Compress» стало «Compress Image». Идентификаторы инструментов и маршруты не изменились, так что закладки не сломаются. (#520)

### Улучшения {#v2-2-0-improvements}

- **Контраст WCAG AA по всему интерфейсу**: палитра была настроена так, что яркий оранжевый остаётся на заливках, а текст и подписи используют доступные чернильные токены, и все 57 индикаторов фокуса теперь проходят порог 3:1 для нетекстовых элементов. (#567, #574)
- **Апскейлинг и удаление фона больше не выглядят зависшими**: индикатор прогресса движется во время инференса вместо того, чтобы застывать на 30%, и оба инструмента предупреждают, что хост только на CPU работает гораздо медленнее. (#605, #608)
- **Сообщения о таймауте называют настоящую причину** и учитывают хосты только на CPU вместо того, чтобы винить загрузку. (#596)
- **SnapOtter ждёт Postgres и Redis при запуске** вместо цикла перезапусков — и в Compose, и в образе «всё в одном». Установка в Proxmox LXC до этого перезапускалась 76 раз. (#537, #595)
- **Загрузки выживают за обратным прокси**: SnapOtter просит nginx и совместимые прокси не буферизировать ответы с файлами, что обычно и есть причина загрузки, которая начинается и никогда не заканчивается. (#604, #607)
- **Compress PDF попадает близко к целевому размеру** и честно говорит, когда цель недостижима. (#522)
- **Мобильные элементы управления инструментов остаются доступными**, поскольку оболочки приложения теперь подстраиваются под динамический вьюпорт. (#559)
- **Convert Audio показывает настройку частоты дискретизации.** (#561)
- **Администраторы могут ослабить минимальную длину пароля** вплоть до 1 для доверенного экземпляра в локальной сети. (#543)
- **MFA настраивается самостоятельно**, лазейка блокировки политики закрыта, а входы через OIDC или SAML получают настоящий запрос MFA вместо жёсткой блокировки. (#531, #536)
- **Голое `Error: Error` теперь называет свою причину.** Ошибки кодирования Sharp, завершения AI-сайдкара, не-JSON вывода сайдкара документов и сбои удаления фона раньше приходили с вырезанной причиной. (#532, #534, #535, #538, #612)
- **Диалог справки переведён.** Его подписи сочетаний клавиш и текст для начала работы были на английском, хотя готовые переводы лежали неиспользованными во всех 21 файле локалей. (#647)

### Примечания к обновлению {#v2-2-0-upgrade-notes}

Переносить ничего не нужно, но два поставляемых значения по умолчанию изменились:

- **`TRUST_PROXY` теперь по умолчанию `loopback,linklocal,uniquelocal`** вместо доверия всем узлам. Сети Docker bridge и Compose попадают в этот диапазон, поэтому большинству установок менять ничего не нужно. Если ваш обратный прокси обращается к SnapOtter с публичного адреса, задайте `TRUST_PROXY` явно, иначе ограничение частоты запросов и журналы аудита будут приписывать каждый запрос прокси.
- **`MAX_AI_JOBS_PER_USER` по умолчанию равен 5** AI-заданиям для одного файла в работе на пользователя. Пакетные запуски и конвейеры AI остаются без ограничений.

Новые необязательные параметры: `DB_STARTUP_TIMEOUT_MS`, `SUBPROCESS_MEMORY_LIMIT_MB` (выключен по умолчанию) и `GIF_BG_MAX_FRAMES`.

## v2.0.0 {#v2-0-0}

SnapOtter 2.0 превращает набор инструментов для изображений в полноценный пакет для работы с файлами: более 200 инструментов в пяти модальностях (Image, Video, Audio, PDF и Files), перестроенный на Postgres 17 и очередь задач на базе Redis, с запуском одной командой `docker run`. Это крупный выпуск; прочитайте раздел «Несовместимые изменения» перед обновлением с версии 1.x.

### Новые возможности {#new-features}

- **Четыре новые модальности инструментов**: Video, Audio, PDF и Files присоединяются к Image, доводя каталог до более чем 200 инструментов.
- **Устойчивые фоновые задачи**: очередь на базе Redis (BullMQ) выполняет каждый инструмент как отслеживаемую задачу с прогрессом в реальном времени через SSE.
- **Режим одного контейнера «всё в одном»**: одна команда `docker run` загружает полноценный экземпляр со встроенными Postgres и Redis.
- **AI-пакеты по требованию**: удаление фона, OCR, транскрипция, апскейлинг, обнаружение и улучшение лиц, стирание объектов, колоризация и реставрация фотографий устанавливаются из интерфейса. Ускорение на GPU определяется для каждого фреймворка.
- **Sign PDF**: нарисуйте, наберите или загрузите подпись и разместите её на PDF прямо в браузере.
- **Automate**: визуальный конструктор конвейеров, который объединяет инструменты в цепочки, с девятью готовыми шаблонами.
- **83 пресета конвертации в один клик**: специальные конвертеры JPG-в-PNG, MP4-в-GIF и подобные с нечётким поиском.
- **Редактор изображений на основе слоёв**: редактор на движке Konva по адресу `/editor` с кистями, фигурами, корректировками, фильтрами и кривыми.
- **Библиотека Files**: сохраните любой результат и повторно используйте его как входные данные для другого инструмента.
- Закреплённые инструменты, масштабирование и панорамирование на холсте, 21 язык и корпоративные возможности (OIDC/SSO, SAML, SCIM, хранилище S3, права доступа на уровне инструментов, экспорт журнала аудита, распределённая трассировка).

### Улучшения {#improvements}

### Несовместимые изменения {#breaking-changes}

2.0 заменяет встроенную базу данных SQLite на Postgres 17 и добавляет Redis 8 для очереди задач. Ваши данные 1.x переносятся автоматически при первом запуске, но стек контейнеров изменился, поэтому сначала сделайте резервную копию всего тома `/data` (1.x работает с SQLite в режиме WAL, поэтому зафиксированные данные обычно находятся в `snapotter.db-wal`). Затем выберите образ с одним контейнером (встроенные Postgres и Redis, только root) или стек Compose (приложение плюс Postgres 17 и Redis 8). См. [руководство по миграции](https://github.com/snapotter-hq/SnapOtter/blob/main/MIGRATING.md) и [руководство по обновлению](/ru/guide/upgrading).

## v1.17.0 {#v1-17-0}

Пять новых инструментов, полноценный редактор изображений, вход через SSO, 20 языков. Наверное, это стоило бы разбить на три отдельных выпуска, но получилось так.

### Новые возможности {#new-features-3}

- **Редактор изображений**: слои, кисти, фигуры, корректировки, фильтры, кривые, сочетания клавиш. Работает в вашем браузере, обрабатывает на вашем оборудовании.
- **Аутентификация OIDC / SSO**: вход через Google, GitHub, Okta или любой провайдер OpenID Connect. Задайте несколько переменных окружения, и ваша команда будет использовать существующие учётные записи.
- **Генератор мемов**: 100 встроенных шаблонов с отрисовкой текста через opentype.js. Или загрузите собственное изображение.
- **Beautify**: загрузите скриншот, получите отполированное изображение. Рамки устройств (macOS, Windows, браузер), тени, градиенты, пресеты для соцсетей.
- **Симуляция дальтонизма**: предпросмотр того, как изображения выглядят при протанопии, дейтеранопии, тританопии и других нарушениях цветовосприятия.
- **Исправление прозрачности PNG**: обнаруживает псевдопрозрачные PNG и исправляет их с помощью HR-маттинга BiRefNet. Необязательное удаление водяных знаков через инпейнтинг LaMa.
- **AI-расширение холста**: расширяет границы изображения с помощью AI-заливки. Три уровня качества (быстрый, сбалансированный, качественный) в зависимости от того, сколько времени GPU вы готовы потратить.
- **20 языков**: арабский, китайский (упрощённый/традиционный), чешский, нидерландский, французский, немецкий, хинди, индонезийский, итальянский, японский, корейский, польский, португальский, русский, испанский, тайский, турецкий, украинский, вьетнамский. RTL работает для арабского.
- **Импорт по URL**: вставляйте URL в зону загрузки или импортируйте пачкой из списка. Загрузка на стороне сервера с защитой от SSRF.
- **Многофайловый ластик**: рисуйте маски стирания сразу по нескольким изображениям, обрабатывайте их все одним кликом. Штрихи сохраняются для каждого изображения.
- **Импорт/экспорт конвейеров**: сохраняйте цепочки инструментов в JSON, делитесь ими с другими.
- **17 новых форматов RAW с камер** через exiftool, а также ввод QOI, JP2, EPS, DDS, CUR, DPX, FITS, PPM/PGM/PBM, SVGZ и APNG. Новые кодеки вывода для BMP, ICO, JP2, QOI. Экспорт AVIF, TIFF, GIF, JXL и PSD восстановлен из ранее утерянной ветки.

### Улучшения {#improvements-2}

- **Улучшение изображений**: старый конвейер заменён на CLAHE + normalise + gamma. Новый переключатель Deep Enhance использует AI-модель для более выраженных результатов.
- **Реставрация фото**: обнаружение царапин переписано с 8-угловой фильтрацией Otsu. Инпейнтинг LaMa теперь работает в исходном разрешении.
- **Экзотические форматы повсюду**: OCR, image-to-PDF, генератор фавиконок, композиция, сшивка и векторизация теперь декодируют HEIC, RAW, PSD.
- **Сжатие**: допуск целевого размера ужесточён с 5% до 1%. Целевой размер стал режимом по умолчанию. Добавлены кнопки-степперы и переключатель единиц КБ/МБ.
- **Очистка Sentry**: отфильтровано 644 неактуальных события. Настоящие ошибки теперь обрабатываются корректно.
- **Определение GPU**: улучшена диагностика для контейнеров, где CUDA присутствует, а nvidia-smi нет.
- **Режим без аутентификации**: анонимный пользователь заносится в БД с ролью admin. API-ключи, конвейеры и файлы пользователей больше не ломаются на ограничениях внешних ключей.
- **2705+ новых тестов** по модульным, интеграционным и E2E-тестам.

### Исправления ошибок {#bug-fixes-3}

- Апскейлинг на CPU больше не завершается по тайм-ауту на NAS и маломощном оборудовании.
- Логотип QR-кода больше не заставляет предпросмотр исчезнуть навсегда.
- Исправлено переполнение при обрезке для высоких портретных изображений.
- Файлы TIFF с альфа-каналом корректно принудительно выводятся в PNG вместо порчи.
- Декодирование HDR/EXR преобразует в 8 бит перед CLAHE, устраняя сбои декодирования.
- Входные буферы для ключевых точек лица преобразуются в PNG перед Python-сайдкаром, устраняя сбои.
- Поиск дубликатов обрабатывает пачки со смешанными форматами и сетевые ошибки.
- Предпросмотр Beautify обновляется в реальном времени.
