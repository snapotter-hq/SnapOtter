# 변경 로그 {#changelog}

## v2.2.0 {#v2-2-0}

2.2의 대부분은 보안과 안정성 강화입니다. 위임된 `users:manage` 역할을 가진 비관리자가 인스턴스를 탈취할 수 있었고, 모든 도구 엔드포인트에 권한 검사가 빠져 있었습니다. 사용자가 둘 이상인 인스턴스를 운영한다면 업그레이드하세요.

나머지는 셀프 호스팅의 자잘한 문제들입니다. 시작만 하고 끝나지 않던 다운로드, 파일을 두 번째 추가하는 순간 깨지던 프리셋, Postgres가 아직 올라오는 중에 크래시 루프를 돌던 컨테이너 같은 것들입니다. 새 도구 두 개도 추가되었습니다. 이제 문서와 웹사이트가 21개 언어로 번역되었고, 인터페이스도 마침내 WCAG AA 명암비 기준을 충족합니다.

> [!IMPORTANT]
> 사용자 지정 역할로 비관리자에게 `users:manage`를 부여했다면, 그 역할은 2.0.0부터 2.1.0까지 관리자 계정을 탈취할 수 있었습니다. 자세한 내용은 보안 항목을 참고하세요.

### 보안 {#v2-2-0-security}

- **위임된 `users:manage` 역할을 통한 권한 상승(GHSA-9xgh-95qh-2x7h).** 사용자 지정 역할을 통해 `users:manage`를 보유한 비관리자가 내장 관리자를 포함한 상위 권한 계정의 비밀번호를 재설정하거나 해당 계정을 삭제해 인스턴스를 탈취할 수 있었습니다. 이제 비밀번호 재설정과 계정 삭제 시 호출자가 대상에 대해 갖는 권한을 검증하므로, 위임된 역할은 자신의 권한 수준을 넘어설 수 없습니다. 영향 범위: 2.0.0부터 2.1.0까지. 제보: 李春来 (Chunlai Li). (#616)
- **모든 도구 엔드포인트에 이제 접근 검사가 적용됩니다.** 도구 접근 권한이 경로마다 개별적으로 적용되어, 직접 작성한 45개 경로가 모두 같은 호출을 기억해야 했지만 그중 어느 것도 그러지 못했습니다. `tools:use`가 없는 역할도 image-to-pdf, erase-object, upscale, sign-pdf 등을 계속 실행할 수 있었습니다. 이제 검사는 매칭된 경로를 기준으로 동작하는 하나의 preHandler에 있으므로 하위 경로와 앞으로 추가되는 경로까지 모두 포괄합니다. (#646)
- **Docker 설치에서 속도 제한을 우회할 수 있었습니다.** 이미지가 `TRUST_PROXY=true`를 함께 배포해서 클라이언트 IP가 요청 헤더에서 결정됐고, 위조된 `X-Forwarded-For`로 로그인 리미터를 통과할 수 있었습니다. 이제 기본값은 사설 네트워크 신뢰 목록입니다. (#649)
- **설정 쓰기는 입구에서 한 번이 아니라 설정별로 검사**되며, 구성 가져오기가 트랜잭션으로 처리되어 거부된 키 때문에 구성이 일부만 적용되는 일이 없습니다. (#618)
- **라이브러리 파일 이름이 저장소 루트를 벗어날 수 없습니다.** 악의적인 1.x SQLite 가져오기가 그대로 복사하는 조작된 저장 이름으로 파일 디렉터리 밖의 파일을 읽거나 삭제할 수 있었습니다. 공격자가 제공한 1.x SQLite 데이터베이스를 운영자가 가져온 뒤에만 도달할 수 있으며, 저장 이름을 임의로 선택할 수 있는 유일한 경로입니다. 제보: @Alpastx. (GHSA-55w2-8cqf-w969, #600)
- **작업 취소에 소유권 검사가 적용되어**, 인증된 사용자가 다른 사용자의 작업을 ID로 취소할 수 없습니다. 제보: @Alpastx. (GHSA-wqxf-gj2p-689x, #599)
- **2.0 전체 트리를 재감사하여 아직 열려 있던 문제를 잡았습니다**: 캡처된 SAML assertion 재생, 잘못된 코드를 몇 번 입력해도 유지되던 MFA 챌린지, 요청마다 전체 테이블 스캔을 수행하던 API 키 조회, 죽은 설정이던 `MAX_WORKSPACE_SIZE_GB`, 그리고 따옴표 없는 `javascript:` href를 통과시키던 SVG 새니타이저. (#620)
- **공개된 CVE 9건 패치**: fast-uri, svgo, sharp, tar 전이 의존성(#619)과 Pillow 12.3.0(#517). arm64의 RAW 디코딩은 이제 패치되지 않은 시스템 사본을 링크하는 대신 LibRaw 0.22.2를 소스에서 빌드합니다. (#649)

### 새로운 기능 {#v2-2-0-new-features}

- **둥근 자르기**: 둥근 사각형과 iOS 스타일 스쿼클 마스크를 제공하며 모서리 반경을 조절할 수 있습니다. 파비콘과 앱 아이콘을 위해 만들었습니다. (#602)
- **GIF 배경 제거**: 애니메이션 GIF, WebP 또는 APNG의 배경을 프레임별로 제거하고 투명한 애니메이션으로 돌려받습니다. (#502)
- **개체 지우개 올가미 및 고품질 모드**: 픽셀을 하나하나 칠하는 대신 자유 곡선을 그려 선택하고, 필요하면 더 깔끔한 대면적 채우기를 위한 디퓨전 인페인팅 번들을 선택적으로 설치할 수 있습니다. (#503, #566)
- **새로 저장 또는 덮어쓰기.** 라이브러리 파일을 편집하면 원본이 조용히 대체되곤 했습니다. 이제 편집할 때마다 선택할 수 있고, 기본값은 원본을 유지합니다. (#564, #577)
- **Resize의 종횡비 프리셋.** 1:1, 4:3, 16:9를 고르면 업스케일 없이 두 치수가 고정된 상태로 유지됩니다. (#530)
- **2단계 OCR**: 빠른 계층은 이미지에 내장되어 다운로드 없이 오프라인으로 실행되고, 더 정확한 런타임은 필요할 때 설치합니다. (#519)
- **아무 곳에서나 입력해 검색.** 대시보드나 홈페이지에서 입력을 시작하면 검색 상자로 들어갑니다. (#644)
- **21개 언어로 제공되는 문서와 웹사이트**: 문서 사이트, 랜딩 페이지, API 레퍼런스가 모두 번역되어 앱 인터페이스에 합류했습니다. 라즈베리 파이와 2GB 머신을 다루는 새로운 저사양 배포 가이드도 추가되었습니다. (#548)
- **더 명확해진 도구 이름**: 모호했던 18개 이름이 스스로를 설명하도록 바뀌어 "Compress"가 "Compress Image"가 되었습니다. 도구 ID와 경로는 그대로이므로 북마크가 깨지지 않습니다. (#520)

### 개선 사항 {#v2-2-0-improvements}

- **인터페이스 전반의 WCAG AA 명암비**: 팔레트를 다시 조정해 선명한 주황색은 채우기에 남기고 텍스트와 레이블은 접근 가능한 잉크 토큰을 사용하도록 했으며, 57개의 포커스 표시기가 모두 3:1 비텍스트 기준을 통과합니다. (#567, #574)
- **업스케일과 배경 제거가 멈춘 것처럼 보이지 않습니다**: 진행 표시줄이 30%에 멈춰 있지 않고 추론 중에도 나아가며, 두 도구 모두 CPU 전용 호스트에서는 훨씬 느리다는 경고를 표시합니다. (#605, #608)
- **시간 초과 메시지가 실제 원인을 알려주고** CPU 전용 호스트를 고려합니다. 더 이상 업로드 탓으로 돌리지 않습니다. (#596)
- **SnapOtter가 시작 시 Postgres와 Redis를 기다리므로** Compose든 올인원 이미지든 크래시 루프를 돌지 않습니다. 어떤 Proxmox LXC 설치는 이 문제로 76번 재시작했습니다. (#537, #595)
- **다운로드가 리버스 프록시를 견딥니다**: SnapOtter가 nginx와 호환 프록시에 파일 응답을 버퍼링하지 말라고 요청합니다. 셀프 호스팅 다운로드가 시작만 하고 끝나지 않는 흔한 원인입니다. (#604, #607)
- **Compress PDF가 목표 크기에 근접하며**, 목표에 도달할 수 없을 때는 그렇다고 솔직하게 알려줍니다. (#522)
- **모바일 도구 컨트롤에 계속 접근할 수 있습니다**: 앱 셸이 동적 뷰포트에 맞춰 크기를 잡습니다. (#559)
- **Convert Audio에서 샘플레이트 설정을 노출합니다.** (#561)
- **관리자가 최소 비밀번호 길이를 완화할 수 있으며**, 신뢰할 수 있는 LAN 인스턴스라면 1까지 낮출 수 있습니다. (#543)
- **MFA가 셀프서비스가 되었고** 정책 잠금 문제가 해결됐으며, OIDC 또는 SAML 로그인은 강제 차단 대신 실제 MFA 챌린지를 받습니다. (#531, #536)
- **`Error: Error`만 나오던 오류가 이제 원인을 알려줍니다.** Sharp 인코딩 실패, AI 사이드카 종료, JSON이 아닌 문서 사이드카 출력, 배경 제거 실패가 모두 이유가 지워진 채 도착하곤 했습니다. (#532, #534, #535, #538, #612)
- **도움말 대화상자가 번역되었습니다.** 단축키 레이블과 시작하기 텍스트가 영어로 하드코딩되어 있었고, 완성된 번역은 21개 로케일 파일에 쓰이지 않은 채 남아 있었습니다. (#647)

### 업그레이드 참고 사항 {#v2-2-0-upgrade-notes}

마이그레이션할 것은 없지만, 배포 기본값 두 가지가 바뀌었습니다:

- **`TRUST_PROXY`의 기본값이 모든 피어를 신뢰하는 대신 `loopback,linklocal,uniquelocal`이 되었습니다.** Docker 브리지와 Compose 네트워크가 이 범위에 속하므로 대부분의 구성에서는 변경할 필요가 없습니다. 리버스 프록시가 공인 주소에서 SnapOtter에 도달한다면 `TRUST_PROXY`를 명시적으로 설정하세요. 그렇지 않으면 속도 제한과 감사 로그가 모든 요청을 프록시의 것으로 기록합니다.
- **`MAX_AI_JOBS_PER_USER`의 기본값은 사용자당 단일 파일 AI 작업 5개**입니다. 배치 및 파이프라인 AI 실행에는 상한이 없습니다.

새로운 선택적 설정: `DB_STARTUP_TIMEOUT_MS`, `SUBPROCESS_MEMORY_LIMIT_MB`(기본 비활성), `GIF_BG_MAX_FRAMES`.

## v2.0.0 {#v2-0-0}

SnapOtter 2.0은 이미지 툴킷을 완전한 파일 조작 스위트로 확장합니다. 다섯 가지 모달리티(Image, Video, Audio, PDF, Files)에 걸친 200개 이상의 도구를 Postgres 17과 Redis 기반 작업 큐 위에 다시 구축했으며, 한 번의 명령으로 실행되는 `docker run`를 제공합니다. 이번은 메이저 릴리스입니다. 1.x에서 업그레이드하기 전에 호환성을 깨는 변경 사항을 읽어보세요.

### 새로운 기능 {#new-features}

- **네 가지 새로운 도구 모달리티**: Video, Audio, PDF, Files가 Image에 합류하여 카탈로그가 200개 이상의 도구로 늘어났습니다.
- **내구성 있는 백그라운드 작업**: Redis 기반 큐(BullMQ)가 모든 도구를 실시간 SSE 진행률과 함께 추적되는 작업으로 실행합니다.
- **올인원 단일 컨테이너 모드**: 하나의 `docker run`로 임베디드 Postgres와 Redis가 포함된 완전한 인스턴스를 부팅합니다.
- **온디맨드 AI 번들**: 배경 제거, OCR, 전사, 업스케일, 얼굴 감지 및 보정, 개체 지우개, 컬러화, 사진 복원이 UI에서 설치됩니다. GPU 가속은 프레임워크별로 감지됩니다.
- **Sign PDF**: 서명을 그리거나, 입력하거나, 업로드하여 브라우저에서 PDF에 배치합니다.
- **Automate**: 도구를 연결하는 시각적 파이프라인 빌더로, 아홉 개의 사전 구축된 템플릿을 제공합니다.
- **원클릭 변환 프리셋 83개**: JPG-to-PNG, MP4-to-GIF 등 전용 변환기와 퍼지 검색을 지원합니다.
- **레이어 기반 이미지 편집기**: 브러시, 도형, 조정, 필터, 커브를 갖춘 `/editor`의 Konva 기반 편집기입니다.
- **Files 라이브러리**: 모든 결과를 저장하고 다른 도구의 입력으로 재사용합니다.
- 고정된 도구, 캔버스 내 확대/축소 및 이동, 21개 언어, 그리고 엔터프라이즈 기능(OIDC/SSO, SAML, SCIM, S3 스토리지, 도구별 권한, 감사 로그 내보내기, 분산 추적)을 제공합니다.

### 개선 사항 {#improvements}

- 실행 중인 프로세스를 취소합니다. (#137)
- DNG를 포함하여 LibRaw를 통한 전체 해상도 RAW 디코딩을 지원합니다. (#289)
- 비루트 및 외부 UID 배포(TrueNAS, Unraid, OpenShift, PUID/PGID)를 지원합니다. (#230, #127)
- 정확한 AI 설치 감지와 강화된 설치 흐름을 제공합니다. (#214, #352)
- 개인정보 보호 강화: 자동 서드파티 송신을 제거하고, 선택적 엄격 오프라인 모드를 추가했습니다.
- 분석이 꺼져 있어도 항상 표시되는 피드백 버튼을 제공합니다.

### 버그 수정 {#bug-fixes}

- `RATE_LIMIT_PER_MIN=0`이 도구 경로에 대한 속도 제한을 다시 비활성화합니다. (#271)
- Docker 이미지 내부의 AI virtualenv 경로를 복구했습니다. (#390)
- sharp 0.35.2+ 호환성을 지원합니다. (#362)
- 이미지 편집기 레이아웃 수정: 눈금자, 채우기 동작, 사이드바, 캔버스 크기 조정. (#258, #259)
- 이탈리아어 번역을 완료했습니다. (#231, #206, #425)
- 오디오 normalize 및 loudnorm이 원본 샘플레이트를 유지합니다.
- SSRF 강화: 숫자 IPv6 CIDR 매칭과 확장된 URL 사전 스캔을 적용했습니다. (#287)
- 생성된 PDF에 Producer로 SnapOtter가 표시됩니다.
- mediapipe가 Python 3.13 및 Debian 13에 설치됩니다.

### 호환성을 깨는 변경 사항 {#breaking-changes}

2.0은 임베디드 SQLite 데이터베이스를 Postgres 17로 대체하고 작업 큐를 위해 Redis 8을 추가합니다. 1.x 데이터는 첫 부팅 시 자동으로 마이그레이션되지만 컨테이너 스택이 변경되었으므로 먼저 전체 `/data` 볼륨을 백업하세요(1.x는 SQLite를 WAL 모드로 실행하므로 커밋된 데이터는 보통 `snapotter.db-wal`에 있습니다). 그런 다음 단일 컨테이너 이미지(임베디드 Postgres 및 Redis, 루트 전용) 또는 Compose 스택(앱과 Postgres 17 및 Redis 8)을 선택하세요. [마이그레이션 가이드](https://github.com/snapotter-hq/SnapOtter/blob/main/MIGRATING.md)와 [업그레이드 가이드](/ko/guide/upgrading)를 참고하세요.


다섯 개의 새 도구, 완전한 이미지 편집기, SSO 로그인, 20개 언어를 제공합니다. 아마 세 개의 별도 릴리스로 나뉘었어야 했지만, 어쨌든 여기까지 왔습니다.

### 새로운 기능 {#new-features-3}

- **이미지 편집기** - 레이어, 브러시, 도형, 조정, 필터, 커브, 키보드 단축키를 제공합니다. 브라우저에서 실행되고 사용자의 하드웨어에서 처리됩니다.
- **OIDC / SSO 인증** - Google, GitHub, Okta 또는 모든 OpenID Connect 공급자로 로그인합니다. 몇 개의 환경 변수를 설정하면 팀이 기존 계정을 사용합니다.
- **밈 생성기** - opentype.js를 통한 텍스트 렌더링이 포함된 100개의 내장 템플릿을 제공합니다. 또는 직접 이미지를 업로드합니다.
- **Beautify** - 스크린샷을 넣으면 다듬어진 이미지가 나옵니다. 디바이스 프레임(macOS, Windows, 브라우저), 그림자, 그라데이션, 소셜 미디어 프리셋을 제공합니다.
- **색맹 시뮬레이션** - 적색맹, 녹색맹, 청색맹 등 색각 이상에서 이미지가 어떻게 보이는지 미리 봅니다.
- **PNG 투명도 수정기** - 가짜 투명 PNG를 감지하고 BiRefNet HR-matting으로 수정합니다. LaMa 인페인팅을 통한 선택적 워터마크 제거를 지원합니다.
- **AI 캔버스 확장** - AI 채우기로 이미지 경계를 확장합니다. GPU 시간을 얼마나 투자할지에 따라 세 가지 품질 등급(fast, balanced, quality)을 제공합니다.
- **20개 언어** - 아랍어, 중국어(간체/번체), 체코어, 네덜란드어, 프랑스어, 독일어, 힌디어, 인도네시아어, 이탈리아어, 일본어, 한국어, 폴란드어, 포르투갈어, 러시아어, 스페인어, 태국어, 터키어, 우크라이나어, 베트남어를 지원합니다. 아랍어의 경우 RTL이 작동합니다.
- **URL 가져오기** - 드롭존에 URL을 붙여넣거나 목록에서 일괄 가져옵니다. SSRF 보호가 적용된 서버 측 페치를 제공합니다.
- **다중 파일 지우개** - 여러 이미지에 걸쳐 지우기 마스크를 그리고 한 번의 클릭으로 모두 처리합니다. 스트로크는 이미지별로 유지됩니다.
- **파이프라인 가져오기/내보내기** - 도구 체인을 JSON으로 저장하고 다른 사람과 공유합니다.
- **17개의 새 카메라 RAW 형식**을 exiftool을 통해 추가했으며, QOI, JP2, EPS, DDS, CUR, DPX, FITS, PPM/PGM/PBM, SVGZ, APNG 입력을 지원합니다. BMP, ICO, JP2, QOI에 대한 새 출력 코덱을 추가했습니다. AVIF, TIFF, GIF, JXL, PSD 내보내기를 이전에 손실된 브랜치에서 복구했습니다.

### 개선 사항 {#improvements-2}

- **이미지 향상** - 기존 파이프라인을 CLAHE + normalise + gamma로 교체했습니다. 새로운 Deep Enhance 토글은 더 적극적인 결과를 위해 AI 모델을 사용합니다.
- **사진 복원** - 8각도 Otsu 필터링으로 스크래치 감지를 다시 작성했습니다. 이제 LaMa 인페인팅이 원본 해상도에서 실행됩니다.
- **어디서나 이색적인 형식** - OCR, image-to-PDF, 파비콘 생성기, composition, stitch, vectorize가 이제 모두 HEIC, RAW, PSD를 디코딩합니다.
- **Compress** - 목표 크기 허용 오차를 5%에서 1%로 좁혔습니다. 목표 크기가 기본 모드입니다. 스테퍼 버튼과 KB/MB 단위 선택기를 추가했습니다.
- **Sentry 정리** - 조치 불가능한 이벤트 644건을 필터링했습니다. 이제 실제 오류가 올바르게 처리됩니다.
- **GPU 감지** - CUDA는 있지만 nvidia-smi가 없는 컨테이너에 대한 진단을 개선했습니다.
- **인증 비활성화 모드** - 익명 사용자가 admin 역할로 DB에 시드됩니다. API 키, 파이프라인, 사용자 파일이 더 이상 FK 제약 조건에서 깨지지 않습니다.
- 단위, 통합, E2E 전반에 걸쳐 **2,705개 이상의 새 테스트**를 추가했습니다.

### 버그 수정 {#bug-fixes-3}

- CPU 업스케일이 NAS 박스와 저전력 하드웨어에서 더 이상 시간 초과되지 않습니다.
- QR 코드 로고가 더 이상 미리 보기를 영구적으로 사라지게 하지 않습니다.
- 세로가 긴 초상화 이미지의 크롭 오버플로를 수정했습니다.
- TIFF 알파 파일이 손상을 일으키는 대신 올바르게 PNG 출력을 강제합니다.
- HDR/EXR 디코딩이 CLAHE 전에 8비트로 변환하여 디코딩 실패를 수정합니다.
- 얼굴 랜드마크 입력 버퍼가 Python 사이드카 이전에 PNG로 변환되어 충돌을 수정합니다.
- 중복 찾기가 혼합 형식 배치와 네트워크 오류를 처리합니다.
- Beautify 미리 보기가 실시간으로 업데이트됩니다.
- stitch 및 vectorize의 진행률 표시줄을 추가했습니다.
- SVGZ가 SVG-to-raster로 처리됩니다.
- 퍼센트 인코딩된 X-File-Results 헤더를 통해 비 ASCII 파일 이름을 수정했습니다.
