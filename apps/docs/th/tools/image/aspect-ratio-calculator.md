# เครื่องคำนวณอัตราส่วนภาพ {#aspect-ratio-calculator}

ป้อนความกว้างและความสูงเดิม จากนั้นป้อนความกว้างใหม่หรือความสูงใหม่ แล้วระบบจะคืนค่าด้านที่เหลือเพื่อให้สัดส่วนคงเดิม อัตราส่วนจะถูกคืนในรูปแบบที่ง่ายที่สุด ดังนั้น 1920 × 1080 คือ 16:9 ในเว็บแอปคุณสามารถเริ่มจากอัตราส่วนทั่วไป (16:9, 4:3, 3:2, 1:1, 21:9, 9:16, 4:5) และสลับระหว่างแนวนอนกับแนวตั้งได้

## API Endpoint {#api-endpoint}

`POST /api/v1/tools/image/aspect-ratio-calculator`

รับเนื้อหา JSON (ไม่ใช่ multipart) และตอบกลับเป็นตัวเลขแทนไฟล์ที่ให้ดาวน์โหลด

## Parameters {#parameters}

| Name | Type | Default | Description |
|------|------|---------|-------------|
| `width` | number | (จำเป็น) | ความกว้างเดิม |
| `height` | number | (จำเป็น) | ความสูงเดิม |
| `newWidth` | number | - | ความกว้างเป้าหมาย การตอบกลับจะคำนวณ `newHeight` จากค่านี้ |
| `newHeight` | number | - | ความสูงเป้าหมาย การตอบกลับจะคำนวณ `newWidth` จากค่านี้ |
| `round` | boolean | `true` | ปัดด้านที่คำนวณได้ให้เป็นจำนวนเต็ม เมื่อเป็น `false` จะเก็บทศนิยมสองตำแหน่ง |

ทุกมิติต้องอยู่ระหว่าง `0.0001` ถึง `1000000` ส่ง `newWidth` หรือ `newHeight` อย่างใดอย่างหนึ่ง ไม่ใช่ทั้งสองอย่าง หากไม่ส่งทั้งสองค่า จะได้เฉพาะอัตราส่วนที่ย่อแล้ว

## Example Request {#example-request}

```bash
curl -X POST http://localhost:1349/api/v1/tools/image/aspect-ratio-calculator \
  -H "Authorization: Bearer si_your-api-key" \
  -H "Content-Type: application/json" \
  -d '{"width": 1920, "height": 1080, "newWidth": 1280}'
```

## Example Response {#example-response}

```json
{
  "width": 1920,
  "height": 1080,
  "ratio": "16:9",
  "ratioDecimal": 1.7778,
  "newWidth": 1280,
  "newHeight": 720
}
```

`newWidth` และ `newHeight` จะเป็น `null` เมื่อคำขอไม่ได้ส่งค่าทั้งสองนี้

## Notes {#notes}

- ขนาดที่เป็นเศษส่วนจะถูกลดเป็นอัตราส่วนจำนวนเต็มโดยใช้ทศนิยมสูงสุดสี่ตำแหน่ง ดังนั้น `8.5` × `11` จะได้ `17:22`
- `ratioDecimal` คือความกว้างหารด้วยความสูง ปัดเป็นทศนิยมสี่ตำแหน่ง
- ด้านที่คำนวณได้จะไม่ถูกคืนเป็น `0` เมื่อเปิดการปัดเศษ ค่าจะต่ำสุดที่ `1` และเมื่อปิดการปัดเศษ ค่าจะต่ำสุดที่ `0.01`
- การส่ง `newWidth` และ `newHeight` พร้อมกัน หรือมิติที่อยู่นอกช่วงที่อนุญาต จะได้รับ 400
- เครื่องคำนวณนี้ไม่อ่านหรือเขียนไฟล์ หากต้องการนำตัวเลขไปใช้ ให้ใช้ [ปรับขนาดภาพ](/th/tools/image/resize) หรือ [ครอปภาพ](/th/tools/image/crop)
