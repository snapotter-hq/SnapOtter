# Changelog {#changelog}

## v2.2.0 {#v2-2-0}

เนื้อหาส่วนใหญ่ของ 2.2 คือการเสริมความแข็งแกร่งด้านความปลอดภัย ผู้ใช้ที่ไม่ใช่ผู้ดูแลระบบซึ่งถือบทบาท `users:manage` ที่ได้รับมอบหมายสามารถยึดอินสแตนซ์ได้ และปลายทางเครื่องมือทุกจุดก็ขาดการตรวจสอบสิทธิ์ อัปเกรดหากคุณมีผู้ใช้มากกว่าหนึ่งคน

ส่วนที่เหลือคือปัญหาปลีกย่อยมากมายของการโฮสต์เอง: การดาวน์โหลดที่เริ่มแล้วไม่เคยเสร็จ พรีเซ็ตที่พังทันทีเมื่อคุณเพิ่มไฟล์ที่สอง และคอนเทนเนอร์ที่วนซ้ำการแครชขณะที่ Postgres ยังไม่พร้อม นอกจากนี้ยังมีเครื่องมือใหม่สองรายการ เอกสารและเว็บไซต์ได้รับการแปลเป็น 21 ภาษาแล้ว และอินเทอร์เฟซก็ผ่านเกณฑ์คอนทราสต์ WCAG AA ในที่สุด

> [!IMPORTANT]
> หากคุณให้ `users:manage` แก่ผู้ใช้ที่ไม่ใช่ผู้ดูแลระบบผ่านบทบาทที่กำหนดเอง บทบาทนั้นสามารถยึดบัญชีผู้ดูแลระบบบน 2.0.0 ถึง 2.1.0 ได้ รายละเอียดอยู่ในหัวข้อ Security

### Security {#v2-2-0-security}

- **การยกระดับสิทธิ์ผ่านบทบาท `users:manage` ที่ได้รับมอบหมาย (GHSA-9xgh-95qh-2x7h)** ผู้ใช้ที่ไม่ใช่ผู้ดูแลระบบซึ่งถือ `users:manage` ผ่านบทบาทที่กำหนดเองสามารถรีเซ็ตรหัสผ่านหรือลบบัญชีที่มีสิทธิ์สูงกว่า รวมถึงผู้ดูแลระบบในตัว และยึดอินสแตนซ์ได้ ตอนนี้การรีเซ็ตรหัสผ่านและการลบบัญชีตรวจสอบอำนาจของผู้เรียกเหนือเป้าหมายแล้ว บทบาทที่ได้รับมอบหมายจึงเอื้อมไปเหนือระดับของตัวเองไม่ได้ ได้รับผลกระทบ: 2.0.0 ถึง 2.1.0 รายงานโดย 李春来 (Chunlai Li) (#616)
- **ปลายทางเครื่องมือทุกจุดถูกควบคุมแล้ว** การเข้าถึงเครื่องมือถูกบังคับใช้ทีละเส้นทาง เส้นทางที่เขียนด้วยมือทั้ง 45 เส้นทางจึงต้องจำการเรียกเดียวกัน และไม่มีเส้นทางใดทำได้ บทบาทที่ไม่มี `tools:use` ยังคงรัน image-to-pdf, erase-object, upscale, sign-pdf และอื่น ๆ ได้ ตอนนี้การตรวจสอบอยู่ใน preHandler ตัวเดียวที่อ้างอิงเส้นทางที่ตรงกัน จึงครอบคลุมเส้นทางย่อยและเส้นทางใด ๆ ที่เพิ่มเข้ามาภายหลัง (#646)
- **การจำกัดอัตราถูกข้ามได้บนการติดตั้งแบบ Docker** อิมเมจมาพร้อม `TRUST_PROXY=true` IP ของไคลเอนต์จึงมาจากส่วนหัวของคำขอ และ `X-Forwarded-For` ที่ปลอมขึ้นก็ผ่านตัวจำกัดการเข้าสู่ระบบไปได้ ตอนนี้ค่าเริ่มต้นคือรายการเครือข่ายส่วนตัวที่เชื่อถือได้ (#649)
- **การเขียนการตั้งค่าถูกตรวจสอบทีละรายการ** ไม่ใช่ตรวจครั้งเดียวที่ประตู และการนำเข้าการกำหนดค่าเป็นแบบ transactional แล้ว คีย์ที่ถูกปฏิเสธจึงทิ้งการกำหนดค่าที่ใช้ไปครึ่งเดียวไม่ได้ (#618)
- **ชื่อไฟล์ในคลังหลุดออกจากรากที่จัดเก็บไม่ได้** ชื่อที่จัดเก็บซึ่งถูกสร้างขึ้นอย่างจงใจ และการนำเข้า SQLite 1.x ที่เป็นอันตรายคัดลอกมาตามตัวอักษร สามารถอ่านหรือลบไฟล์นอกไดเรกทอรีไฟล์ได้ เข้าถึงได้เฉพาะหลังผู้ดูแลระบบนำเข้าฐานข้อมูล SQLite 1.x ที่ผู้โจมตีจัดหาให้ ซึ่งเป็นเส้นทางเดียวที่ทำให้เลือกชื่อที่จัดเก็บได้ รายงานโดย @Alpastx (GHSA-55w2-8cqf-w969, #600)
- **การยกเลิกงานบังคับใช้ความเป็นเจ้าของ** ผู้ใช้ที่ยืนยันตัวตนแล้วจึงยกเลิกงานของผู้ใช้รายอื่นด้วย id ไม่ได้อีก รายงานโดย @Alpastx (GHSA-wqxf-gj2p-689x, #599)
- **การตรวจสอบซ้ำทั้งทรี 2.0 จับสิ่งที่ยังเปิดอยู่ได้**: SAML assertion ที่ดักจับได้สามารถเล่นซ้ำได้, การท้าทาย MFA ยังคงใช้ได้แม้กรอกรหัสผิดกี่ครั้งก็ตาม, การค้นหาคีย์ API ต่อคำขอเป็นการสแกนทั้งตาราง, `MAX_WORKSPACE_SIZE_GB` เป็นการกำหนดค่าที่ตายแล้ว และตัวทำ sanitize SVG ยอมให้ href `javascript:` ที่ไม่ได้ใส่เครื่องหมายคำพูดผ่านไปได้ (#620)
- **แพตช์ CVE ที่เปิดเผยแล้วเก้ารายการ**: fast-uri, svgo, sharp และ tar แบบส่งต่อ (#619) พร้อมกับ Pillow 12.3.0 (#517) การถอดรหัส RAW บน arm64 ตอนนี้สร้าง LibRaw 0.22.2 จากซอร์สแทนการลิงก์สำเนาของระบบที่ยังไม่ได้แพตช์ (#649)

### New Features {#v2-2-0-new-features}

- **Rounded Crop**: มาสก์สี่เหลี่ยมมุมมนและ squircle สไตล์ iOS พร้อมตัวควบคุมรัศมีมุม สร้างมาเพื่อ favicon และไอคอนแอป (#602)
- **Remove GIF Background**: ลบพื้นหลังออกจาก GIF, WebP หรือ APNG แบบเคลื่อนไหวทีละเฟรม แล้วได้แอนิเมชันโปร่งใสกลับมา (#502)
- **Object Eraser แบบ lasso และโหมด High Quality**: ลากวนเป็นรูปอิสระแทนการระบายทีละพิกเซล และติดตั้งบันเดิล diffusion inpainting ได้ตามต้องการเพื่อการเติมพื้นที่ขนาดใหญ่ที่สะอาดขึ้น (#503, #566)
- **บันทึกเป็นไฟล์ใหม่ หรือเขียนทับ** การแก้ไขไฟล์ในคลังเคยแทนที่ต้นฉบับโดยไม่แจ้ง ตอนนี้คุณเลือกได้ทุกครั้งที่แก้ไข และค่าเริ่มต้นคือเก็บต้นฉบับไว้ (#564, #577)
- **พรีเซ็ตอัตราส่วนภาพใน Resize** เลือก 1:1, 4:3 หรือ 16:9 แล้วสองมิติจะถูกล็อกไว้ด้วยกัน โดยไม่ขยายภาพ (#530)
- **OCR สองระดับ**: ระดับเร็วถูกฝังอยู่ในอิมเมจและทำงานออฟไลน์โดยไม่ต้องดาวน์โหลด ส่วนรันไทม์ที่แม่นยำกว่าติดตั้งเมื่อต้องการ (#519)
- **พิมพ์ที่ไหนก็ค้นหาได้** เริ่มพิมพ์บนแดชบอร์ดหรือหน้าแรก แล้วข้อความจะไปอยู่ในช่องค้นหา (#644)
- **เอกสารและเว็บไซต์ใน 21 ภาษา**: ไซต์เอกสาร หน้าแลนดิ้ง และเอกสารอ้างอิง API ได้รับการแปลทั้งหมดแล้ว ร่วมกับอินเทอร์เฟซแอป พร้อมคู่มือการปรับใช้สำหรับทรัพยากรต่ำเล่มใหม่ที่ครอบคลุม Raspberry Pi และเครื่อง 2 GB (#548)
- **ชื่อเครื่องมือที่ชัดเจนขึ้น**: ชื่อที่กำกวม 18 ชื่ออธิบายตัวเองได้แล้ว เช่น "Compress" กลายเป็น "Compress Image" id และเส้นทางของเครื่องมือไม่เปลี่ยน ลิงก์ที่บุ๊กมาร์กไว้จึงไม่พัง (#520)

### Improvements {#v2-2-0-improvements}

- **คอนทราสต์ WCAG AA ทั่วอินเทอร์เฟซ**: จานสีถูกปรับใหม่ให้สีส้มสดยังอยู่บนพื้นทึบ ขณะที่ข้อความและป้ายใช้โทเคนหมึกที่เข้าถึงได้ และตัวบ่งชี้โฟกัสทั้ง 57 จุดผ่านเกณฑ์ 3:1 สำหรับองค์ประกอบที่ไม่ใช่ข้อความแล้ว (#567, #574)
- **Upscale และการลบพื้นหลังไม่ดูเหมือนค้างอีกต่อไป**: แถบความคืบหน้าเดินหน้าต่อระหว่างการอนุมานแทนที่จะหยุดนิ่งที่ 30% และทั้งสองเครื่องมือเตือนแล้วว่าโฮสต์ที่มีแต่ CPU นั้นช้ากว่ามาก (#605, #608)
- **ข้อความหมดเวลาระบุสาเหตุที่แท้จริง** และคำนึงถึงโฮสต์ที่มีแต่ CPU แทนที่จะโทษการอัปโหลด (#596)
- **SnapOtter รอ Postgres และ Redis ตอนเริ่มทำงาน** แทนที่จะวนซ้ำการแครช ทั้งใน Compose และอิมเมจแบบครบวงจร ก่อนหน้านี้การติดตั้งบน Proxmox LXC รีสตาร์ตไป 76 ครั้ง (#537, #595)
- **การดาวน์โหลดอยู่รอดผ่านรีเวิร์สพร็อกซี**: SnapOtter ขอให้ nginx และพร็อกซีที่เข้ากันได้ไม่บัฟเฟอร์การตอบกลับไฟล์ ซึ่งเป็นสาเหตุปกติที่การดาวน์โหลดแบบโฮสต์เองเริ่มแล้วไม่เสร็จสักที (#604, #607)
- **Compress PDF ได้ขนาดใกล้เคียงเป้าหมาย** และบอกตามตรงเมื่อเป้าหมายนั้นไปไม่ถึง (#522)
- **ตัวควบคุมเครื่องมือบนมือถือเข้าถึงได้เสมอ** เนื่องจากเปลือกแอปปรับขนาดตาม viewport แบบไดนามิกแล้ว (#559)
- **Convert Audio มีการตั้งค่าอัตราการสุ่มตัวอย่าง** (#561)
- **ผู้ดูแลระบบผ่อนความยาวรหัสผ่านขั้นต่ำได้** ลงไปถึง 1 สำหรับอินสแตนซ์ใน LAN ที่เชื่อถือได้ (#543)
- **MFA เป็นแบบบริการตนเอง** ปัญหาการล็อกเอาต์จากนโยบายถูกแก้แล้ว และการเข้าสู่ระบบด้วย OIDC หรือ SAML ได้รับการท้าทาย MFA จริงแทนการบล็อกแบบตายตัว (#531, #536)
- **`Error: Error` เปล่า ๆ ระบุสาเหตุแล้ว** ความล้มเหลวในการเข้ารหัสของ Sharp, การออกของ AI sidecar, เอาต์พุตเอกสาร sidecar ที่ไม่ใช่ JSON และความล้มเหลวในการลบพื้นหลัง เดิมมาถึงโดยที่สาเหตุถูกลบออกไป (#532, #534, #535, #538, #612)
- **กล่องโต้ตอบช่วยเหลือได้รับการแปลแล้ว** ป้ายทางลัดและข้อความเริ่มต้นใช้งานถูกฮาร์ดโค้ดเป็นภาษาอังกฤษ ขณะที่คำแปลที่เสร็จแล้วนอนไม่ได้ใช้อยู่ในไฟล์ภาษาทั้ง 21 ไฟล์ (#647)

### Bug Fixes {#v2-2-0-bug-fixes}

- **ไฟล์ HEIC จาก iPhone ถูกปฏิเสธ** ว่าไม่สามารถอ่านได้ก่อนจะถึงตัวถอดรหัสที่จัดการมัน (#631)
- **พรีเซ็ตการแปลงล้มเหลวเมื่อมีไฟล์ที่สอง**: jpg-to-pdf และเครื่องแปลง image-to-pdf ที่เกี่ยวข้อง รวมถึง pdf-to-png, pdf-to-jpg และ pdf-to-tiff ต่างคืน `Tool not found` เมื่ออัปโหลดสองไฟล์ (#633, #643)
- **พรีเซ็ตการแปลง PDF สูญเสียปุ่มดาวน์โหลด** (#629)
- **การหมดเวลาการประมวลผลแบบไม่จำกัดไม่ถูกนำมาใช้** และสตรีมความคืบหน้าที่หยุดชะงักกู้คืนได้แล้วแทนที่จะปล่อยให้อินเทอร์เฟซรอต่อไป (#638)
- **การดาวน์โหลดค้างแทนที่จะล้มเหลว** เมื่อไฟล์ที่จัดเก็บสั้นกว่าความยาวที่บันทึกไว้ (#617)
- **เครื่องมือจัดการหน้า PDF ล้มเหลวกับไฟล์สั้นและไฟล์ที่เข้ารหัส**: Remove Pages ใช้ช่วงหน้าเริ่มต้นที่เอกสารต่ำกว่าหกหน้าไม่มี และ PDF ที่ป้องกันด้วยรหัสผ่านล้มเหลวอย่างคลุมเครือภายใน worker (#594)
- **PDF to Text คืนไฟล์ว่างเปล่าโดยไม่แจ้ง** สำหรับ PDF ที่สแกน ตอนนี้มันชี้ให้คุณใช้ OCR และส่งข้อความเป็น UTF-8 (#603)
- **PDF to Word ทำบล็อกข้อความสีหาย** และแยกมันข้ามหน้า (#500)
- **Object Eraser ทิ้งร่องรอยผี** และทำให้วัตถุเล็ก ๆ เบลอในภาพความละเอียดสูง (#501)
- **Stabilize Video เขียนเอาต์พุตที่เล่นไม่ได้** เมื่อไม่มี faststart (#593)
- **การซ่อมแซมโปรแกรมแก้ไขรูปภาพ**: หมุน, พลิก, ปรับขนาด, levels, curves, ฟิลเตอร์ และการล็อกเลเยอร์ (#597)
- **Sign PDF แสดงแคนวาสว่างเปล่า** แทนที่จะรายงานว่าเหตุใด PDF จึงโหลดไม่สำเร็จ (#545)
- **คลังไฟล์บันทึกมิติ 0x0** และข้ามการดูตัวอย่างสำหรับการอัปโหลด HEIC, RAW และ PSD (#636, #637)
- **การติดตั้งบันเดิล AI มากกว่าหนึ่งรายการ** ทำให้ virtualenv ที่ใช้ร่วมกันมีหลายเวอร์ชันและทำให้เครื่องมือสามรายการพังเงียบ ๆ (#649)
- **การแปลงเป็น JXL ที่คุณภาพ 1 ถึง 4 คืน 500** และ ffmpeg ที่หายไปถูกรายงานให้คุณว่าเป็นการอัปโหลดที่เสียหาย (#649)
- **Postgres ที่ล่มชั่วคราวทำให้งานที่เสร็จแล้วตกค้าง** ทิ้งเอาต์พุตไว้บนดิสก์โดยไม่มีแถวใดชี้ไปที่มัน ตอนนี้ตัวกระทบยอดรับงานนั้นมาแทนที่จะทิ้งไป (#649)
- **ปลายทาง Redis ที่เปลี่ยนที่อยู่ทำให้ผู้บริโภคทุกรายค้าง** ขณะที่ health check ยังตอบ 200 (#649)
- **การแก้ไขเว็บไซต์และเอกสาร**: ลิงก์ที่แปลแล้วไม่ทิ้งแฟรกเมนต์ `#` หรือเปลี่ยน `zh-CN` เป็นตัวพิมพ์เล็กอีกต่อไป เมนูนำทางเอกสารอยู่ในวิวพอร์ตบนแท็บเล็ต และทั้งสองไซต์ไม่เรียก GitHub API จากเบราว์เซอร์ของคุณอีกแล้ว (#516, #562, #570, #560)

### Upgrade Notes {#v2-2-0-upgrade-notes}

ไม่มีอะไรต้องย้ายข้อมูล แต่ค่าเริ่มต้นที่จัดส่งมาเปลี่ยนไปสองรายการ:

- **`TRUST_PROXY` ตอนนี้มีค่าเริ่มต้นเป็น `loopback,linklocal,uniquelocal`** แทนการเชื่อถือทุก peer เครือข่าย Docker bridge และ Compose อยู่ในช่วงนั้น การตั้งค่าส่วนใหญ่จึงไม่ต้องเปลี่ยน หากรีเวิร์สพร็อกซีของคุณเข้าถึง SnapOtter จากที่อยู่สาธารณะ ให้ตั้ง `TRUST_PROXY` อย่างชัดเจน ไม่เช่นนั้นการจำกัดอัตราและบันทึกการตรวจสอบจะระบุว่าทุกคำขอมาจากพร็อกซี
- **`MAX_AI_JOBS_PER_USER` มีค่าเริ่มต้นเป็น 5** งาน AI ไฟล์เดียวที่กำลังดำเนินอยู่ต่อผู้ใช้ การรัน AI แบบชุดและไปป์ไลน์ยังไม่มีขีดจำกัด

ปุ่มปรับค่าเสริมใหม่: `DB_STARTUP_TIMEOUT_MS`, `SUBPROCESS_MEMORY_LIMIT_MB` (ปิดโดยค่าเริ่มต้น) และ `GIF_BG_MAX_FRAMES`

## v2.0.0 {#v2-0-0}

SnapOtter 2.0 เปลี่ยนชุดเครื่องมือรูปภาพให้กลายเป็นชุดเครื่องมือจัดการไฟล์แบบครบวงจร: เครื่องมือมากกว่า 200 รายการครอบคลุมห้ารูปแบบ (Image, Video, Audio, PDF และ Files) สร้างขึ้นใหม่บน Postgres 17 และคิวงานที่ใช้ Redis พร้อม `docker run` ด้วยคำสั่งเดียว นี่คือรุ่นใหญ่ อ่านหัวข้อ Breaking changes ก่อนอัปเกรดจาก 1.x

### New features {#new-features}

- **รูปแบบเครื่องมือใหม่สี่ประเภท**: Video, Audio, PDF และ Files เข้าร่วมกับ Image ทำให้แคตตาล็อกมีเครื่องมือมากกว่า 200 รายการ
- **งานเบื้องหลังที่คงทน**: คิวที่ใช้ Redis (BullMQ) รันเครื่องมือทุกตัวเป็นงานที่ติดตามได้ พร้อมความคืบหน้าแบบสด SSE
- **โหมดคอนเทนเนอร์เดียวแบบครบวงจร**: `docker run` เพียงคำสั่งเดียวบูตอินสแตนซ์ที่สมบูรณ์พร้อม Postgres และ Redis แบบฝังในตัว
- **ชุด AI แบบติดตั้งเมื่อต้องการ**: การลบพื้นหลัง, OCR, การถอดเสียง, การขยายภาพ, การตรวจจับและเพิ่มความคมชัดใบหน้า, ยางลบวัตถุ, การลงสี และการฟื้นฟูภาพถ่าย ติดตั้งได้จาก UI ตรวจจับการเร่งความเร็ว GPU แยกตามเฟรมเวิร์ก
- **Sign PDF**: วาด พิมพ์ หรืออัปโหลดลายเซ็นแล้ววางลงบน PDF ในเบราว์เซอร์
- **Automate**: ตัวสร้างไปป์ไลน์แบบภาพที่เชื่อมโยงเครื่องมือเข้าด้วยกัน พร้อมเทมเพลตสำเร็จรูปเก้าแบบ
- **พรีเซ็ตการแปลงแบบคลิกเดียว 83 รายการ**: ตัวแปลง JPG-to-PNG, MP4-to-GIF และอื่น ๆ ที่คล้ายกันโดยเฉพาะ พร้อมการค้นหาแบบคลุมเครือ
- **โปรแกรมแก้ไขรูปภาพแบบเลเยอร์**: โปรแกรมแก้ไขที่ขับเคลื่อนด้วย Konva ที่ `/editor` พร้อมพู่กัน รูปทรง การปรับแต่ง ฟิลเตอร์ และเส้นโค้ง
- **คลังไฟล์ Files**: บันทึกผลลัพธ์ใด ๆ แล้วนำกลับมาใช้เป็นอินพุตของเครื่องมืออื่น
- เครื่องมือที่ปักหมุด, การซูมและเลื่อนในแคนวาส, 21 ภาษา และความสามารถระดับองค์กร (OIDC/SSO, SAML, SCIM, ที่จัดเก็บ S3, สิทธิ์แยกตามเครื่องมือ, การส่งออก audit, distributed tracing)

### Improvements {#improvements}

- ยกเลิกกระบวนการที่กำลังทำงานอยู่ได้ (#137)
- ถอดรหัส RAW ความละเอียดเต็มผ่าน LibRaw รวมถึง DNG (#289)
- การปรับใช้แบบไม่ใช่ root และ UID ต่างเจ้าของ (TrueNAS, Unraid, OpenShift, PUID/PGID) (#230, #127)
- การตรวจจับการติดตั้ง AI ที่แม่นยำและขั้นตอนการติดตั้งที่แข็งแรงขึ้น (#214, #352)
- การเสริมความเป็นส่วนตัว: ไม่มีการส่งข้อมูลออกไปยังบุคคลที่สามโดยอัตโนมัติ พร้อมโหมดออฟไลน์เข้มงวดที่เลือกได้
- ปุ่มให้ข้อเสนอแนะที่แสดงตลอดเวลา แม้จะปิดการวิเคราะห์ข้อมูลก็ตาม

### Bug fixes {#bug-fixes}

- `RATE_LIMIT_PER_MIN=0` ปิดการจำกัดอัตราสำหรับเส้นทางเครื่องมืออีกครั้ง (#271)
- ซ่อมแซมเส้นทาง virtualenv ของ AI ภายในอิมเมจ Docker (#390)
- ความเข้ากันได้กับ sharp 0.35.2+ (#362)
- แก้ไขเลย์เอาต์โปรแกรมแก้ไขรูปภาพ: ไม้บรรทัด, พฤติกรรมการเติมสี, แถบด้านข้าง และการกำหนดขนาดแคนวาส (#258, #259)
- แปลภาษาอิตาลีเสร็จสมบูรณ์ (#231, #206, #425)
- Audio normalize และ loudnorm รักษาอัตราการสุ่มตัวอย่างของต้นฉบับ
- การเสริมความแข็งแกร่ง SSRF: การจับคู่ CIDR ของ IPv6 แบบตัวเลขและการสแกน URL ล่วงหน้าที่ครอบคลุมมากขึ้น (#287)
- PDF ที่สร้างขึ้นจะประทับ SnapOtter เป็น Producer
- mediapipe ติดตั้งได้บน Python 3.13 และ Debian 13

### Breaking changes {#breaking-changes}

2.0 แทนที่ฐานข้อมูล SQLite แบบฝังในตัวด้วย Postgres 17 และเพิ่ม Redis 8 สำหรับคิวงาน ข้อมูล 1.x ของคุณจะย้ายโดยอัตโนมัติเมื่อบูตครั้งแรก แต่สแตกคอนเทนเนอร์เปลี่ยนไปแล้ว ดังนั้นให้สำรองข้อมูลทั้งวอลุ่ม `/data` ของคุณก่อน (1.x รัน SQLite ในโหมด WAL ดังนั้นข้อมูลที่คอมมิตแล้วมักจะอยู่ใน `snapotter.db-wal`) จากนั้นเลือกอิมเมจคอนเทนเนอร์เดียว (Postgres และ Redis แบบฝังในตัว เฉพาะ root) หรือสแตก Compose (แอปพลิเคชันพร้อม Postgres 17 และ Redis 8) ดู [migration guide](https://github.com/snapotter-hq/SnapOtter/blob/main/MIGRATING.md) และ [upgrade guide](/th/guide/upgrading)

## v1.17.0 {#v1-17-0}

เครื่องมือใหม่ห้ารายการ, โปรแกรมแก้ไขรูปภาพแบบเต็ม, การเข้าสู่ระบบ SSO, 20 ภาษา น่าจะควรแยกเป็นสามรุ่นต่างหาก แต่ก็เป็นแบบนี้แหละ

### New features {#new-features-3}

- **โปรแกรมแก้ไขรูปภาพ** - เลเยอร์, พู่กัน, รูปทรง, การปรับแต่ง, ฟิลเตอร์, เส้นโค้ง, แป้นพิมพ์ลัด ทำงานในเบราว์เซอร์ของคุณ ประมวลผลบนฮาร์ดแวร์ของคุณ
- **การยืนยันตัวตน OIDC / SSO** - เข้าสู่ระบบด้วย Google, GitHub, Okta หรือผู้ให้บริการ OpenID Connect ใด ๆ ตั้งค่าตัวแปรสภาพแวดล้อมสองสามตัวแล้วทีมของคุณใช้บัญชีที่มีอยู่แล้ว
- **ตัวสร้างมีม** - เทมเพลตในตัว 100 แบบพร้อมการเรนเดอร์ข้อความผ่าน opentype.js หรืออัปโหลดรูปภาพของคุณเอง
- **Beautify** - วางภาพหน้าจอเข้าไป ได้ภาพที่ขัดเกลาออกมา กรอบอุปกรณ์ (macOS, Windows, เบราว์เซอร์), เงา, การไล่ระดับสี, พรีเซ็ตโซเชียลมีเดีย
- **การจำลองภาวะตาบอดสี** - ดูตัวอย่างว่าภาพจะดูเป็นอย่างไรกับ protanopia, deuteranopia, tritanopia และภาวะการมองเห็นสีบกพร่องอื่น ๆ
- **ตัวแก้ความโปร่งใส PNG** - ตรวจจับ PNG ที่โปร่งใสปลอมและแก้ไขด้วย BiRefNet HR-matting ลบลายน้ำที่เลือกได้ผ่าน LaMa inpainting
- **การขยายแคนวาสด้วย AI** - ขยายขอบเขตของภาพด้วยการเติมด้วย AI สามระดับคุณภาพ (fast, balanced, quality) ขึ้นอยู่กับปริมาณเวลา GPU ที่คุณต้องการแลกเปลี่ยน
- **20 ภาษา** - อาหรับ, จีน (ตัวย่อ/ตัวเต็ม), เช็ก, ดัตช์, ฝรั่งเศส, เยอรมัน, ฮินดี, อินโดนีเซีย, อิตาลี, ญี่ปุ่น, เกาหลี, โปแลนด์, โปรตุเกส, รัสเซีย, สเปน, ไทย, ตุรกี, ยูเครน, เวียดนาม RTL ใช้งานได้สำหรับภาษาอาหรับ
- **การนำเข้า URL** - วาง URL ลงในพื้นที่วางไฟล์หรือนำเข้าจากรายการเป็นชุด การดึงข้อมูลฝั่งเซิร์ฟเวอร์พร้อมการป้องกัน SSRF
- **ยางลบหลายไฟล์** - วาดมาสก์การลบข้ามหลายภาพ ประมวลผลทั้งหมดด้วยคลิกเดียว เส้นวาดคงอยู่แยกตามภาพ
- **การนำเข้า/ส่งออกไปป์ไลน์** - บันทึกห่วงโซ่เครื่องมือเป็น JSON แล้วแบ่งปันกับผู้อื่น
- **รูปแบบ RAW ของกล้องใหม่ 17 รูปแบบ** ผ่าน exiftool รวมถึง QOI, JP2, EPS, DDS, CUR, DPX, FITS, PPM/PGM/PBM, SVGZ และอินพุต APNG โคเดกเอาต์พุตใหม่สำหรับ BMP, ICO, JP2, QOI กู้คืนการส่งออก AVIF, TIFF, GIF, JXL และ PSD จากสาขาที่เคยสูญหาย

### Improvements {#improvements-2}

- **การเพิ่มความคมชัดภาพ** - แทนที่ไปป์ไลน์เดิมด้วย CLAHE + normalise + gamma ปุ่ม Deep Enhance ใหม่ใช้โมเดล AI เพื่อผลลัพธ์ที่เข้มข้นขึ้น
- **ฟื้นฟูภาพถ่าย** - เขียนการตรวจจับรอยขีดข่วนใหม่ด้วยการกรอง Otsu 8 มุม LaMa inpainting ทำงานที่ความละเอียดต้นฉบับแล้ว
- **รูปแบบแปลกทุกที่** - OCR, image-to-PDF, ตัวสร้าง favicon, การจัดวาง, การต่อภาพ และการแปลงเป็นเวกเตอร์ ตอนนี้ถอดรหัส HEIC, RAW, PSD ได้ทั้งหมด
- **บีบอัด** - เข้มความคลาดเคลื่อนของขนาดเป้าหมายจาก 5% เป็น 1% ขนาดเป้าหมายเป็นโหมดเริ่มต้น เพิ่มปุ่มปรับค่าและตัวเลือกหน่วย KB/MB
- **การล้าง Sentry** - กรองเหตุการณ์ที่ไม่ต้องดำเนินการ 644 รายการ ข้อผิดพลาดจริงได้รับการจัดการอย่างถูกต้องแล้ว
- **การตรวจจับ GPU** - การวินิจฉัยที่ดีขึ้นสำหรับคอนเทนเนอร์ที่มี CUDA แต่ไม่มี nvidia-smi
- **โหมดปิดการยืนยันตัวตน** - เพาะผู้ใช้แบบไม่ระบุตัวตนใน DB ด้วยบทบาท admin คีย์ API, ไปป์ไลน์ และไฟล์ผู้ใช้ไม่พังจากข้อจำกัด FK อีกต่อไป
- **การทดสอบใหม่กว่า 2,705 รายการ** ครอบคลุมทั้ง unit, integration และ E2E

### Bug fixes {#bug-fixes-3}
