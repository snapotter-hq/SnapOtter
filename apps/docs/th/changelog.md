# บันทึกการเปลี่ยนแปลง {#changelog}

## v2.3.0 {#v2-3-0}

SnapOtter มียอดดึงอิมเมจเกินหนึ่งล้านครั้งบน Docker Hub และ GHCR รวมกัน และมี 3,000 ดาวบน GitHub นั่นหมายถึงเซิร์ฟเวอร์โฮสต์เองจำนวนมาก รุ่นนี้จึงเป็นคำขอบคุณของเราถึงทุกคนที่รันมันอยู่

ควรอัปเกรดโดยเร็ว 2.3.0 ปิดช่องโหว่ด้านความปลอดภัยหกรายการ หนึ่งในนั้นมีความรุนแรงสูง รายละเอียดอยู่ในส่วนความปลอดภัยด้านล่าง

นอกจากการแก้ไข ยังมีเครื่องมือใหม่ ได้แก่ตัวแก้ไขหน้าแบบ PDF Multi-Tool ค่าที่ตั้งไว้ล่วงหน้าสำหรับบีบอัดให้ได้ขนาดที่ต้องการในคลิกเดียวสำหรับรูปภาพและ PDF และการจัดลำดับหน้าด้วยการลากและวางใน Organize PDF ตอนนี้ OCR อ่านภาษาอาหรับได้ และ pdf-to-text เสนอ OCR เมื่อพบ PDF ที่เป็นภาพสแกน SnapOtter รันภายใต้เส้นทางย่อยอย่าง `/snapotter` หลังรีเวิร์สพร็อกซีได้ แอปไม่ต้องใช้ซูเปอร์ยูสเซอร์ของ Postgres ในการรันอีกต่อไป ผู้ดูแลระบบที่ถูกล็อกออกสามารถกู้คืนได้จากบรรทัดคำสั่ง ส่วนที่เหลือคือการแก้ไขประมาณ 1,400 รายการ ซึ่งส่วนใหญ่เป็นปัญหาที่พวกคุณรายงานมา

> [!IMPORTANT]
> ช่องโหว่ทั้งหกรายการด้านล่างส่งผลต่อ 2.2.0 และบางรายการย้อนไปถึง 2.0.0 หากคุณใช้อินสแตนซ์ร่วมกับผู้ใช้อื่นหรือเปิดให้เข้าถึงจากนอกเครือข่ายของคุณเอง ควรอัปเกรด

- **การอัปโหลด SVG อาจข้ามการทำความสะอาดได้ (GHSA-9c7h-xjrp-8gh3, สูง)** SVG ที่ตัวถอดรหัสภาพปฏิเสธจะถูกเก็บและส่งออกตามเดิมแทนที่จะถูกทำความสะอาด รุ่นที่ได้รับผลกระทบ: 2.2.0 และก่อนหน้า รายงานโดย @xaferima (#1211)
- **สตรีมความคืบหน้าของงานไม่ตรวจสอบว่าใครเป็นผู้ขอ (GHSA-ff22-w6x2-fm98, ปานกลาง)** ตอนนี้ต้องเข้าสู่ระบบและเป็นเจ้าของงาน รุ่นที่ได้รับผลกระทบ: 2.0.0 ถึง 2.2.0 (#1750)
- **ลิงก์ดาวน์โหลดผลลัพธ์ส่งไฟล์ที่อัปโหลดต้นฉบับด้วย (GHSA-jgv3-2jc6-f628, ปานกลาง)** รุ่นที่ได้รับผลกระทบ: 2.2.0 และก่อนหน้า รายงานโดย @emirhancatkin (#3623)
- **เอฟเฟกต์รูปถ่ายพาสปอร์ตและพื้นหลังเชื่อถือ job id ที่ไคลเอนต์ส่งมา (GHSA-3c8g-8v4x-qq9j, ปานกลาง)** รุ่นที่ได้รับผลกระทบ: 2.2.0 และก่อนหน้า รายงานโดย @shaoyuuuuu (#3623)
- **การนำเข้า URL การอัปโหลด และการแสดงตัวอย่างข้ามการตรวจสอบสิทธิ์ของบทบาทและ API key (GHSA-8xxr-g2w8-7f9r, ปานกลาง)** รุ่นที่ได้รับผลกระทบ: 2.2.0 และก่อนหน้า รายงานโดย @nguyenvantiennani (#3780, #707)
- **การบังคับใช้ SSO เผยชื่อผู้ใช้ break-glass (GHSA-q6fg-vvw9-cr8r, ต่ำ)** การเข้าสู่ระบบภายในที่ถูกปฏิเสธจะได้รับ 401 เหมือนการเข้าสู่ระบบที่ล้มเหลวอื่น ๆ รุ่นที่ได้รับผลกระทบ: 2.0.0 ถึง 2.2.0 (#2148)
- **Postgres ไม่รันเป็นซูเปอร์ยูสเซอร์อีกต่อไป** แอปเชื่อมต่อด้วยบทบาทที่อ่านและเขียนข้อมูลได้เท่านั้น การย้ายข้อมูลใช้การเชื่อมต่อแยกต่างหากซึ่งเป็นทางเลือก ดูหมายเหตุการอัปเกรด (#918)
- **อัปเดตไลบรารีที่ต้องแก้ไข** ยกระดับเวอร์ชันขั้นต่ำที่บังคับใช้ของ dompurify และ handlebars ไปเป็นเวอร์ชันที่แก้ไขแล้ว (#4247)

### ฟีเจอร์ใหม่ {#v2-3-0-new-features}

- **PDF Multi-Tool** ตัวแก้ไขหน้าที่จัดลำดับใหม่ ทำซ้ำ หมุน และลบหน้า รวมถึงดึงหน้าจาก PDF อื่นเข้ามา เซิร์ฟเวอร์ประกอบไฟล์สุดท้าย (#1338)
- **บีบอัดให้ได้ขนาดเป้าหมายในคลิกเดียว** ค่าที่ตั้งไว้ล่วงหน้าสำหรับรูปภาพห้าแบบ (20, 50, 100, 200, 500 KB) และสำหรับ PDF ห้าแบบ (100, 200, 500 KB, 1 MB, 2 MB) (#1250, #1377)
- **รัน SnapOtter ภายใต้เส้นทางย่อย** ตั้งค่า `BASE_PATH=/snapotter` แล้วอิมเมจเดียวกันจะให้บริการจากที่นั่น ลิงก์ผลลัพธ์ คุกกี้ การเปลี่ยนเส้นทาง SSO และเอกสาร API ทั้งหมดตามไปด้วย (#1252, #1324)
- **OCR ภาษาอาหรับ** เลือกภาษาอาหรับโดยตรง หรือให้โหมดอัตโนมัติตรวจจับ ใช้ได้กับ OCR ของรูปภาพและ PDF (#4130, #4183)
- **pdf-to-text เสนอ OCR** เมื่อ PDF หรือทั้งแบตช์ไม่มีชั้นข้อความ แทนที่จะส่งไฟล์ว่างกลับมา (#4142, #4198)
- **จัดลำดับหน้าใน Organize PDF ด้วยการลากและวาง** ทั้งเมาส์และการสัมผัส (#1249, #2601)
- **จัดลำดับไฟล์ใหม่ก่อนรันหลายไฟล์** merge, stitch, collage และเครื่องมือหลายไฟล์อื่น ๆ คงลำดับที่คุณตั้งไว้ (#756, #757)
- **ยกเลิกการรันแบบแบตช์และไปป์ไลน์** และงานบนเซิร์ฟเวอร์หยุดจริง (#807)
- **คำสั่งกู้คืนของ `snapotter-admin`** ได้แก่ `reset-password`, `create-admin`, `unlock-user` และการรีเซ็ต MFA สำหรับผู้ดูแลระบบที่ถูกล็อกออกจาก UI เว็บ (#4016)
- **การลงทะเบียน MFA ตอนเข้าสู่ระบบ** เมื่อต้องใช้ MFA ผู้ใช้ที่ยังไม่มีจะตั้งค่าได้ทันที แทนที่จะถูกบล็อก
- **ถ่ายภาพจากกล้องและแอปที่ติดตั้งได้** ถ่ายภาพเข้าเครื่องมือโดยตรงบนมือถือ และติดตั้ง SnapOtter เป็น PWA (#773)
- **ช่องว่างโปร่งใสในกล่องโต้ตอบ Canvas Size ของตัวแก้ไข** (#4111)
- **การแจ้งเตือนอัปเดตสำหรับผู้ดูแลระบบ** เมื่อมี SnapOtter รุ่นใหม่กว่า ผู้ดูแลระบบจะเห็นการแจ้งเตือนที่ปิดได้พร้อมลิงก์ไปยังบันทึกประจำรุ่น การตรวจสอบทำงานผ่านการเชื่อมต่อวิเคราะห์ข้อมูลที่มีอยู่ ดังนั้นจะปิดเมื่อปิดการวิเคราะห์ข้อมูล

### การปรับปรุง {#v2-3-0-improvements}

- **การลบพื้นหลังเร็วขึ้นเมื่อรันซ้ำ** โมเดลคงอยู่ในหน่วยความจำระหว่างคำขอ แทนที่จะโหลดใหม่ทุกครั้ง (#4144)
- **การอัปโหลดแบบแบตช์ใช้หน่วยความจำน้อยลงมาก** แต่ละไฟล์ไปที่ดิสก์ชั่วคราวและประมวลผลทีละไฟล์ แทนที่จะค้างอยู่ใน RAM (#2687)
- **การติดตั้งชุด AI ล้มเหลวอย่างเรียบร้อยและย้อนกลับ** แทนที่จะทิ้ง venv ที่ติดตั้งไม่สมบูรณ์ การติดตั้งการลบพื้นหลังบน Proxmox LXC กลับมาใช้งานได้ และโฮสต์ที่มีหน่วยความจำน้อยได้ขีดจำกัด CPU ที่เหมาะสมก่อนเริ่มงาน (#2628, #2597, #2526, #2546)
- **การตรวจจับ GPU เชื่อถือได้มากขึ้น** ตรวจจับ CUDA ผ่านไดรเวอร์ การ์ดซีรีส์ RTX 50 ถอยกลับไปใช้ CPU แทนที่จะล้มเหลว และตัวเข้ารหัสวิดีโอด้วยฮาร์ดแวร์ถูกทดลองรันก่อนใช้งาน (#4225, #4075, #3980, #3983)
- **`MAX_WORKER_THREADS` ใช้งานได้แล้ว** ก่อนหน้านี้ถูกแยกวิเคราะห์แต่ไม่เคยถูกนำไปใช้ (#3249)
- **เครื่องมือที่ใช้เวลานานได้ระยะหมดเวลาที่ยาว** pdf-to-word, compress-pdf, convert-document และ content-aware resize จะไม่หมดเวลาเร็วเกินไปกับไฟล์ขนาดใหญ่ (#3276)
- **Compress PDF คงความอ่านง่ายของไฟล์สแกน** และแจ้งเมื่อไม่สามารถถึงขนาดเป้าหมายได้ แทนที่จะสร้างไฟล์ที่อ่านไม่ออก (#4112)
- **จำกัดอัตราการเข้าสู่ระบบที่ล้มเหลวตามชื่อผู้ใช้** เกินสิบครั้งในสิบห้านาทีจะได้รับ 429 พร้อม `Retry-After` (#827)
- **ข้อผิดพลาดบอกว่าเกิดอะไรขึ้น** ไบนารีที่หายไป ความผิดพลาดของพื้นที่จัดเก็บ การถูกฆ่าเพราะหน่วยความจำไม่พอ และขีดจำกัดการอัปโหลด ได้ข้อความเฉพาะเจาะจงแทน 500 หรือ 422 เปล่า ๆ
- **บันทึกการตรวจสอบครอบคลุมการรันเครื่องมือ แบตช์ และไปป์ไลน์** และเหตุการณ์ของผู้ใช้ บทบาท ทีม และ GDPR บันทึกว่าใครทำอะไรกับใคร (#3991, #3984)
- **คอนเทนเนอร์แบบครบในตัวหยุดเมื่อบูตครั้งแรกไม่สำเร็จ** แทนที่จะรีสตาร์ตไม่รู้จบ และ Postgres กับ Redis แบบฝังตัวมีกำหนดเวลาเริ่มต้น (#3008, #1130)
- **วันที่และรูปพหูพจน์เป็นไปตามภาษาของคุณ** และสตริงภาษาอังกฤษที่ฝังในโค้ดชุดสุดท้ายได้รับการแปลแล้ว
- **ปรับแต่งมือถือและตัวแก้ไข** เลย์เอาต์ของแถบเลื่อน Sign PDF และการครอบตัดบนโทรศัพท์ การลากด้วยการสัมผัส แปรงพิกเซลที่เร็วขึ้น และ Levels กับ Curves ในการเลิกทำและการบันทึกอัตโนมัติ

### การแก้ไขข้อบกพร่อง {#v2-3-0-bug-fixes}

- **Adjust Colors รวมการตั้งค่าผิดพลาด** อุณหภูมิ ความอิ่มตัว เฉดสี คอนทราสต์ และ sepia ทับกันเองแทนที่จะซ้อนกัน (#3153, #3120, #3469)
- **Pixelate ไม่ทำให้เป็นพิกเซล** และเอาต์พุต PNG ถูกลดจำนวนสีลงอย่างเงียบ ๆ ในเครื่องมือภาพต่าง ๆ (#709, #716)
- **GIF และ WebP แบบเคลื่อนไหวสูญเสียเฟรม** ในหลายเครื่องมือ และพาเลต GIF กับความโปร่งใสออกมาผิด (#1184, #1225, #3407, #2573)
- **การอัปโหลดที่หมุนแล้วสูญเสียคุณภาพ** การปรับทิศทางอัตโนมัติทิ้งการเข้ารหัสแบบไม่สูญเสีย ความโปร่งใส และความลึก 16 บิต ตอนนี้ WebP แบบเคลื่อนไหวหมุนทุกเฟรม (#2384, #2529)
- **TIFF ที่มีความโปร่งใส ไฟล์ HEIF แบบ AV1 และรูปแบบ RAW หลายชนิด** ล้มเหลวหรือสูญเสียอัลฟา (#2609, #2572, #1120)
- **การปรับขนาดแคนวาสของตัวแก้ไขทำให้ภาพถูกย่อขยาย** แทนที่จะเพิ่มพื้นที่รอบภาพ (#2081)
- **ชื่อไฟล์ผลลัพธ์เพี้ยน** `.jpeg` และ `.tif` กลายเป็นชื่ออื่น และไฟล์ที่ขึ้นต้นด้วยจุดหรือชื่อที่ซ้ำนามสกุลทำงานผิดพลาด (#3495, #3382)
- **การบันทึกอัตโนมัติลงไลบรารีไม่สนใจโควตาพื้นที่จัดเก็บ** และตัวนับพื้นที่จัดเก็บอาจติดลบ (#2389, #2585)
- **งานที่ค้างหลังรีสตาร์ต** ตอนนี้ถูกสะสางเมื่อเริ่มต้น แทนที่จะแสดง "กำลังประมวลผล" ตลอดไป (#3219, #3193)
- **การเข้าสู่ระบบ OIDC ตั้งชื่อผู้ใช้ใหม่ทุกคนว่า "admin"** และการเข้าสู่ระบบบน iOS Safari จบที่หน้าข้อผิดพลาดทั้งที่สำเร็จแล้ว (#862, #4021)
- **กฎรหัสผ่านที่ปิดไว้ยังถูกบังคับใช้** ตอนสร้างผู้ใช้ (#1028)
- **PDF ที่เสียหายค้างอยู่ 30 วินาที** ก่อนจะล้มเหลว (#920)
- **การตรวจสอบดิสก์ของชุด AI ขอพื้นที่ประมาณ 18 GB** เพื่อติดตั้งเพียงชุดเดียว (#1248)
- **Compress Video ล้มเหลวกับการบันทึกหน้าจอที่อัตราเฟรมแปรผัน** (#2427)
- **การลบพื้นหลังแบบแบตช์สูญเสียผลลัพธ์ที่เสร็จแล้ว** เมื่อเบราว์เซอร์ลองส่งคำขอซ้ำ (#2015)
- **ช่องตัวเลขในการตั้งค่าล้างค่าไม่ได้** ขณะพิมพ์ (#1449)
- **การปิดการวิเคราะห์ข้อมูลยังเหลือเหตุการณ์ในคิวที่จะส่ง** ประมาณ 30 วินาทีต่อมา ตอนนี้ถูกทิ้งเมื่อคุณเลือกไม่เข้าร่วม (#4270)

### หมายเหตุการอัปเกรด {#v2-3-0-upgrade-notes}

การย้ายข้อมูลทำงานเองเมื่อเริ่มต้น คุณไม่ต้องรัน SQL ใด ๆ

- **บทบาทฐานข้อมูล** ไฟล์ Compose มาตรฐานตอนนี้ให้แอปใช้บทบาทที่อ่านและเขียนข้อมูลได้เท่านั้น (`DATABASE_URL`) และการเชื่อมต่อสิทธิ์สูงแยกต่างหาก (`DATABASE_MIGRATION_URL`) ที่ใช้เฉพาะตอนบูตเพื่อย้ายข้อมูลและมอบสิทธิ์ ไฟล์ Compose ที่มีอยู่ยังใช้งานได้เหมือนเดิม หากไม่ตั้ง `DATABASE_MIGRATION_URL` SnapOtter จะรันด้วยบทบาทเดียว สำหรับการติดตั้งที่ไม่ใช่เครื่องภายใน ให้ตั้ง `POSTGRES_APP_PASSWORD` คู่กับ `POSTGRES_PASSWORD`
- **การตรวจสอบตอนเริ่มต้นเข้มงวดขึ้น** ก่อนหน้านี้ปัญหาเหล่านี้ล้มเหลวทีหลังหรือเงียบ ๆ ตอนนี้จะหยุดคอนเทนเนอร์พร้อมข้อความที่ระบุชื่อตัวแปร ได้แก่ `DEFAULT_LOCALE` ที่ไม่รองรับ (ใช้รหัสที่รองรับอย่าง `de` ไม่ใช่ `de_DE`) `SAML_IDP_SSO_URL`, `SAML_CALLBACK_URL` หรือ `OIDC_ISSUER_URL` ที่รูปแบบผิดเมื่อเปิด SSO รายการ `TRUST_PROXY` ที่ไม่ถูกต้อง `BASE_PATH` ที่ผิด และ `LOG_DIR` ที่เขียนไม่ได้
- **`TRUST_PROXY` ไม่รับจำนวนฮอปอีกต่อไป** ตัวเลขอย่าง `TRUST_PROXY=2` ตอนนี้จะหยุดคอนเทนเนอร์ตอนเริ่มต้น แทนที่จะไม่เชื่อถือพร็อกซีใดเลยอย่างเงียบ ๆ ให้ตั้งเป็นที่อยู่พร็อกซีหรือช่วงที่มีชื่อ (ค่าเริ่มต้นคือ `loopback,linklocal,uniquelocal`) ตั้งเป็น `false` เมื่อไม่มีพร็อกซีหน้า SnapOtter หรือตั้งเป็น `true` เฉพาะเมื่อมีพร็อกซีที่คุณควบคุมอยู่ด้านหน้าบนที่อยู่สาธารณะ (#998)
- **`MAX_WORKER_THREADS` มีผลแล้ว** หากคุณเคยตั้งค่าไว้และไม่เห็นการเปลี่ยนแปลง ตอนนี้จะเห็น
- **รหัสสถานะ API** ความผิดพลาดของเอนจินและพื้นที่จัดเก็บคืน 503 `ENGINE_UNAVAILABLE` (เอนด์พอยต์แบตช์เคยคืน 422) การอัปโหลดเกินขีดจำกัดคืน 413 (เดิม 400) `clientJobId` ที่รูปแบบผิดคืน 400 และที่ถูกใช้ซ้ำคืน 409 (เดิม 500) การรันแบตช์ไปป์ไลน์ของคุณซ้ำคืน 202 `mode=targetSize` ที่ไม่มี `targetSizeKb` คืน 400 การเข้าสู่ระบบภายในที่ถูกปฏิเสธภายใต้การบังคับใช้ SSO คืน 401 แทน 403 `SSO_ENFORCED` การเข้าสู่ระบบที่ถูกจำกัดอัตราคืน 429 `LOGIN_THROTTLED` ผลลัพธ์ remove-background ไม่รวม `originalUrl` อีกต่อไป
- **ตัวแปรทางเลือกใหม่** `BASE_PATH`, `DATABASE_MIGRATION_URL`, `GDPR_EXPORT_TIMEOUT_MS` (ค่าเริ่มต้น 15 นาที `0` ปิดการใช้งาน) `EMBEDDED_REDIS_TIMEOUT_S` (180) และ `EMBEDDED_POSTGRES_TIMEOUT_S` (600)
- **ไฟล์ Compose มาพร้อมกับรุ่น** `docker-compose.yml` และ `docker-compose-gpu.yml` แนบมากับรุ่นนี้ คุณจึงดาวน์โหลดได้โดยตรงจากหน้ารุ่น

## v2.2.0 {#v2-2-0}

2.2 ส่วนใหญ่คือการเสริมความแข็งแกร่ง ผู้ใช้ที่ไม่ใช่ผู้ดูแลระบบซึ่งได้รับบทบาท `users:manage` ที่มอบหมายต่อสามารถยึดอินสแตนซ์ได้ และเอนด์พอยต์ของเครื่องมือทุกตัวพบว่าขาดการตรวจสอบสิทธิ์ ควรอัปเกรดหากคุณมีผู้ใช้มากกว่าหนึ่งคน

ส่วนที่เหลือคือปัญหาจุกจิกของการโฮสต์เอง ได้แก่ ดาวน์โหลดที่เริ่มแล้วไม่เสร็จ ค่าที่ตั้งไว้ล่วงหน้าที่พังทันทีเมื่อเพิ่มไฟล์ที่สอง และคอนเทนเนอร์ที่รีสตาร์ตวนไม่หยุดขณะ Postgres ยังไม่พร้อม มีเครื่องมือใหม่สองตัวด้วย เอกสารและเว็บไซต์ได้รับการแปลเป็น 21 ภาษาแล้ว และอินเทอร์เฟซผ่านเกณฑ์คอนทราสต์ WCAG AA ในที่สุด

> [!IMPORTANT]
> หากคุณมอบ `users:manage` ให้ผู้ใช้ที่ไม่ใช่ผู้ดูแลระบบผ่านบทบาทแบบกำหนดเอง บทบาทนั้นสามารถยึดบัญชีผู้ดูแลระบบได้บน 2.0.0 ถึง 2.1.0 ดูรายละเอียดในส่วนความปลอดภัย

### ความปลอดภัย {#v2-2-0-security}

- **การยกระดับสิทธิ์ผ่านบทบาท `users:manage` ที่มอบหมายต่อ (GHSA-9xgh-95qh-2x7h)** ผู้ใช้ที่ไม่ใช่ผู้ดูแลระบบซึ่งมี `users:manage` ผ่านบทบาทแบบกำหนดเองสามารถรีเซ็ตรหัสผ่านหรือลบบัญชีที่มีสิทธิ์สูงกว่า รวมถึงผู้ดูแลระบบในตัว และยึดอินสแตนซ์ได้ ตอนนี้การรีเซ็ตรหัสผ่านและการลบบัญชีจะตรวจสอบอำนาจของผู้เรียกเหนือเป้าหมาย บทบาทที่มอบหมายต่อจึงเอื้อมเหนือระดับของตนเองไม่ได้ รุ่นที่ได้รับผลกระทบ: 2.0.0 ถึง 2.1.0 รายงานโดย 李春来 (Chunlai Li) (#616)
- **เอนด์พอยต์ของเครื่องมือทุกตัวถูกควบคุมสิทธิ์แล้ว** การเข้าถึงเครื่องมือเคยถูกบังคับใช้ทีละเส้นทาง เส้นทางที่เขียนด้วยมือทั้ง 45 เส้นจึงต้องจำเรียกการตรวจสอบเดียวกัน และไม่มีเส้นใดทำ บทบาทที่ไม่มี `tools:use` ยังรัน image-to-pdf, erase-object, upscale, sign-pdf และอื่น ๆ ได้ ตอนนี้การตรวจสอบอยู่ใน preHandler ตัวเดียวที่อิงเส้นทางที่ตรงกัน จึงครอบคลุมเส้นทางย่อยและเส้นทางใด ๆ ที่เพิ่มภายหลัง (#646)
- **การจำกัดอัตราถูกหลบเลี่ยงได้บนการติดตั้ง Docker** อิมเมจมาพร้อม `TRUST_PROXY=true` IP ของไคลเอนต์จึงมาจากเฮดเดอร์ของคำขอ และ `X-Forwarded-For` ปลอมผ่านตัวจำกัดการเข้าสู่ระบบไปได้ ตอนนี้ค่าเริ่มต้นเป็นรายการเครือข่ายส่วนตัวที่เชื่อถือ (#649)
- **การเขียนการตั้งค่าถูกตรวจสอบรายการตั้งค่า** ไม่ใช่ตรวจครั้งเดียวที่ประตู และการนำเข้าการกำหนดค่าเป็นแบบธุรกรรม คีย์ที่ถูกปฏิเสธจึงไม่ทิ้งการกำหนดค่าที่ใช้ไปครึ่งเดียว (#618)
- **ชื่อไฟล์ในไลบรารีออกนอกรากพื้นที่จัดเก็บไม่ได้** ชื่อที่เก็บไว้ซึ่งออกแบบมาเป็นพิเศษ ซึ่งการนำเข้า SQLite 1.x ที่เป็นอันตรายคัดลอกมาตามตัวอักษร สามารถอ่านหรือลบไฟล์นอกไดเรกทอรีไฟล์ได้ เข้าถึงได้เฉพาะหลังจากผู้ดูแลนำเข้าฐานข้อมูล SQLite 1.x ที่ผู้โจมตีจัดทำให้ ซึ่งเป็นเส้นทางเดียวที่ทำให้เลือกชื่อที่เก็บไว้ได้ รายงานโดย @Alpastx (GHSA-55w2-8cqf-w969, #600)
- **การยกเลิกงานบังคับใช้ความเป็นเจ้าของ** ผู้ใช้ที่ยืนยันตัวตนแล้วจึงยกเลิกงานของผู้ใช้อื่นด้วย id ไม่ได้อีก รายงานโดย @Alpastx (GHSA-wqxf-gj2p-689x, #599)
- **การตรวจสอบซ้ำทั้งต้นไม้ 2.0 พบสิ่งที่ยังเปิดอยู่** SAML assertion ที่ดักจับไว้เล่นซ้ำได้ MFA challenge อยู่รอดแม้ใส่รหัสผิดกี่ครั้ง การค้นหา API key ต่อคำขอเป็นการสแกนทั้งตาราง `MAX_WORKSPACE_SIZE_GB` เป็นการกำหนดค่าที่ไม่ทำงาน และตัวทำความสะอาด SVG ปล่อย href `javascript:` ที่ไม่มีเครื่องหมายอัญประกาศผ่านไป (#620)
- **แก้ CVE ที่เปิดเผยแล้วเก้ารายการ** fast-uri, svgo, sharp และ tar ผ่านการพึ่งพาทางอ้อม (#619) รวมถึง Pillow 12.3.0 (#517) การถอดรหัส RAW บน arm64 ตอนนี้สร้าง LibRaw 0.22.2 จากซอร์สแทนการลิงก์กับสำเนาของระบบที่ไม่ได้แก้ไข (#649)

### ฟีเจอร์ใหม่ {#v2-2-0-new-features}

- **Rounded Crop** มาสก์สี่เหลี่ยมมุมมนและสควิร์เคิลแบบ iOS พร้อมตัวควบคุมรัศมีมุม สร้างมาสำหรับ favicon และไอคอนแอป (#602)
- **Remove GIF Background** ลบพื้นหลังจาก GIF, WebP หรือ APNG แบบเคลื่อนไหวทีละเฟรม และได้ภาพเคลื่อนไหวโปร่งใสกลับมา (#502)
- **ลาสโซและโหมดคุณภาพสูงของ Object Eraser** ลากเส้นวนอิสระแทนการระบายทีละพิกเซล และเลือกติดตั้งชุด diffusion inpainting เพื่อการเติมพื้นที่ใหญ่ที่สะอาดกว่า (#503, #566)
- **บันทึกเป็นไฟล์ใหม่ หรือเขียนทับ** การแก้ไขไฟล์ในไลบรารีเคยแทนที่ไฟล์ต้นฉบับอย่างเงียบ ๆ ตอนนี้คุณเลือกได้ทุกครั้งที่แก้ไข และค่าเริ่มต้นคือเก็บต้นฉบับไว้ (#564, #577)
- **ค่าอัตราส่วนที่ตั้งไว้ล่วงหน้าใน Resize** เลือก 1:1, 4:3 หรือ 16:9 แล้วมิติทั้งสองจะถูกล็อกไว้ โดยไม่ขยายภาพ (#530)
- **OCR สองระดับ** ระดับเร็วฝังอยู่ในอิมเมจและรันออฟไลน์โดยไม่ต้องดาวน์โหลด และรันไทม์ที่แม่นยำกว่าติดตั้งตามต้องการ (#519)
- **พิมพ์ที่ไหนก็ค้นหาได้** เริ่มพิมพ์บนแดชบอร์ดหรือหน้าแรก แล้วข้อความจะไปอยู่ในช่องค้นหา (#644)
- **เอกสารและเว็บไซต์ใน 21 ภาษา** เว็บไซต์เอกสาร หน้า landing และเอกสารอ้างอิง API แปลครบแล้ว ร่วมกับอินเทอร์เฟซของแอป คู่มือการติดตั้งสำหรับทรัพยากรต่ำฉบับใหม่ครอบคลุม Raspberry Pi และเครื่อง 2 GB (#548)
- **ชื่อเครื่องมือชัดเจนขึ้น** ชื่อที่กำกวม 18 ชื่อมีส่วนขยายในตัว เช่น "Compress" กลายเป็น "Compress Image" id และเส้นทางของเครื่องมือไม่เปลี่ยน ดังนั้นสิ่งที่บุ๊กมาร์กไว้ไม่เสีย (#520)

### การปรับปรุง {#v2-2-0-improvements}

- **คอนทราสต์ WCAG AA ทั่วทั้งอินเทอร์เฟซ** ปรับจานสีใหม่ให้สีส้มสดใช้กับพื้นหลังเท่านั้น ส่วนข้อความและป้ายใช้โทเคนสีที่เข้าถึงได้ และตัวบ่งชี้โฟกัสทั้ง 57 รายการผ่านเกณฑ์ 3:1 สำหรับองค์ประกอบที่ไม่ใช่ข้อความ (#567, #574)
- **Upscale และการลบพื้นหลังไม่ดูค้างอีกต่อไป** แถบความคืบหน้าเดินระหว่างการอนุมาน แทนที่จะจอดอยู่ที่ 30% และทั้งสองเครื่องมือเตือนแล้วว่าโฮสต์ที่ใช้ CPU อย่างเดียวช้ากว่ามาก (#605, #608)
- **ข้อความหมดเวลาระบุสาเหตุจริง** และคำนึงถึงโฮสต์ที่ใช้ CPU อย่างเดียว แทนที่จะโทษการอัปโหลด (#596)
- **SnapOtter รอ Postgres และ Redis ตอนเริ่มต้น** แทนที่จะรีสตาร์ตวน ทั้งใน Compose และอิมเมจแบบครบในตัว การติดตั้ง Proxmox LXC เคยรีสตาร์ต 76 ครั้งก่อนหน้านี้ (#537, #595)
- **ดาวน์โหลดอยู่รอดผ่านรีเวิร์สพร็อกซี** SnapOtter ขอให้ nginx และพร็อกซีที่เข้ากันได้ไม่บัฟเฟอร์การตอบกลับที่เป็นไฟล์ ซึ่งเป็นสาเหตุปกติที่ทำให้ดาวน์โหลดบนระบบโฮสต์เองเริ่มแล้วไม่เสร็จ (#604, #607)
- **Compress PDF ได้ขนาดใกล้เป้าหมาย** และบอกตามจริงเมื่อเป้าหมายอยู่เกินเอื้อม (#522)
- **ตัวควบคุมเครื่องมือบนมือถือเอื้อมถึงได้** เมื่อเชลล์ของแอปปรับขนาดตามวิวพอร์ตแบบไดนามิก (#559)
- **Convert Audio มีการตั้งค่าอัตราสุ่มตัวอย่าง** (#561)
- **ผู้ดูแลระบบลดความยาวรหัสผ่านขั้นต่ำได้** ลงไปถึง 1 สำหรับอินสแตนซ์ LAN ที่เชื่อถือได้ (#543)
- **MFA ตั้งค่าเองได้** ปิดช่องล็อกจากนโยบาย และการเข้าสู่ระบบด้วย OIDC หรือ SAML ได้รับ MFA challenge จริง แทนการบล็อกทันที (#531, #536)
- **`Error: Error` เปล่า ๆ ตอนนี้ระบุสาเหตุ** ความล้มเหลวในการเข้ารหัสของ Sharp การออกจากการทำงานของ AI sidecar เอาต์พุตที่ไม่ใช่ JSON จาก document sidecar และความล้มเหลวของการลบพื้นหลัง เคยมาถึงโดยไม่มีเหตุผลแนบ (#532, #534, #535, #538, #612)
- **กล่องโต้ตอบช่วยเหลือแปลแล้ว** ป้ายทางลัดและข้อความเริ่มต้นใช้งานเป็นภาษาอังกฤษที่ฝังในโค้ด ทั้งที่คำแปลที่เสร็จแล้วไม่ได้ถูกใช้ในไฟล์ภาษาทั้ง 21 ไฟล์ (#647)

### การแก้ไขข้อบกพร่อง {#v2-2-0-bug-fixes}

- **ไฟล์ HEIC จาก iPhone ถูกปฏิเสธ** ว่าอ่านไม่ได้ก่อนถึงตัวถอดรหัสที่จัดการมัน (#631)
- **ค่าที่ตั้งไว้ล่วงหน้าของการแปลงล้มเหลวกับไฟล์ที่สอง** jpg-to-pdf และ image-to-pdf ตัวพี่น้อง รวมถึง pdf-to-png, pdf-to-jpg และ pdf-to-tiff ล้วนคืน `Tool not found` เมื่ออัปโหลดสองไฟล์ (#633, #643)
- **ค่าที่ตั้งไว้ล่วงหน้าของการแปลง PDF ปุ่มดาวน์โหลดหาย** (#629)
- **ระยะหมดเวลาประมวลผลแบบไม่จำกัดไม่ถูกเคารพ** และสตรีมความคืบหน้าที่ค้างตอนนี้กู้คืนได้ แทนที่จะปล่อยให้อินเทอร์เฟซรอ (#638)
- **ดาวน์โหลดค้างแทนที่จะล้มเหลว** เมื่อไฟล์ที่เก็บไว้สั้นกว่าความยาวที่บันทึก (#617)
- **เครื่องมือหน้า PDF ล้มเหลวกับไฟล์สั้นและไฟล์ที่เข้ารหัส** Remove Pages ใช้ช่วงหน้าเริ่มต้นที่เอกสารต่ำกว่าหกหน้าไม่มี และ PDF ที่ป้องกันด้วยรหัสผ่านล้มเหลวแบบเข้าใจยากภายในเวิร์กเกอร์ (#594)
- **PDF to Text ส่งไฟล์ว่างกลับมาอย่างเงียบ ๆ** สำหรับ PDF ที่เป็นภาพสแกน ตอนนี้ชี้ไปที่ OCR และส่งข้อความเป็น UTF-8 (#603)
- **PDF to Word ทิ้งบล็อกข้อความสี** และแยกมันกระจายไปทั่วหน้า (#500)
- **Object Eraser ทิ้งรอยผีค้าง** และทำให้วัตถุเล็กเบลอในภาพความละเอียดสูง (#501)
- **Stabilize Video เขียนเอาต์พุตที่เล่นไม่ได้** เมื่อไม่มี faststart (#593)
- **ซ่อมตัวแก้ไขภาพ** หมุน พลิก ปรับขนาด levels curves ฟิลเตอร์ และการล็อกเลเยอร์ (#597)
- **Sign PDF แสดงแคนวาสว่าง** แทนที่จะรายงานว่าทำไม PDF โหลดไม่สำเร็จ (#545)
- **ไลบรารีไฟล์บันทึกขนาด 0x0** และข้ามตัวอย่างสำหรับการอัปโหลด HEIC, RAW และ PSD (#636, #637)
- **การติดตั้งชุด AI มากกว่าหนึ่งชุด** ทำให้ virtualenv ที่ใช้ร่วมกันมีหลายเวอร์ชันและทำให้เครื่องมือสามตัวพังอย่างเงียบ ๆ (#649)
- **การแปลงเป็น JXL ที่คุณภาพ 1 ถึง 4 คืน 500** และ ffmpeg ที่หายไปถูกรายงานให้คุณว่าเป็นการอัปโหลดที่เสียหาย (#649)
- **Postgres ล่มชั่วคราวทำให้งานที่เสร็จแล้วตกค้าง** เหลือเอาต์พุตบนดิสก์โดยไม่มีแถวชี้ไปถึง ตอนนี้ตัวกระทบยอดรับงานนั้นมาแทนที่จะทิ้ง (#649)
- **เอนด์พอยต์ Redis ที่เปลี่ยนที่อยู่ทำให้ผู้บริโภคทุกตัวติดขัด** ขณะที่การตรวจสุขภาพยังตอบ 200 (#649)
- **แก้ไขเว็บไซต์และเอกสาร** ลิงก์ที่แปลแล้วไม่ทิ้งเศษ `#` หรือแปลง `zh-CN` เป็นตัวพิมพ์เล็กอีกต่อไป แถบนำทางของเอกสารอยู่ในวิวพอร์ตบนแท็บเล็ต และทั้งสองไซต์ไม่เรียก GitHub API จากเบราว์เซอร์ของคุณอีกต่อไป (#516, #562, #570, #560)

### หมายเหตุการอัปเกรด {#v2-2-0-upgrade-notes}

ไม่ต้องย้ายข้อมูล แต่ค่าเริ่มต้นที่มาพร้อมกันเปลี่ยนไปสองอย่าง

- **`TRUST_PROXY` ตอนนี้มีค่าเริ่มต้นเป็น `loopback,linklocal,uniquelocal`** แทนที่จะเชื่อถือเพียร์ทุกตัว เครือข่ายบริดจ์ของ Docker และ Compose อยู่ในช่วงนั้น การติดตั้งส่วนใหญ่จึงไม่ต้องเปลี่ยนอะไร หากรีเวิร์สพร็อกซีของคุณเข้าถึง SnapOtter จากที่อยู่สาธารณะ ให้ตั้ง `TRUST_PROXY` อย่างชัดเจน ไม่เช่นนั้นการจำกัดอัตราและบันทึกการตรวจสอบจะระบุว่าทุกคำขอมาจากพร็อกซี
- **`MAX_AI_JOBS_PER_USER` มีค่าเริ่มต้นเป็น 5** งาน AI ไฟล์เดียวที่กำลังทำงานต่อผู้ใช้ การรัน AI แบบแบตช์และไปป์ไลน์ยังไม่จำกัด

ตัวเลือกใหม่ที่ไม่บังคับ `DB_STARTUP_TIMEOUT_MS`, `SUBPROCESS_MEMORY_LIMIT_MB` (ปิดเป็นค่าเริ่มต้น) และ `GIF_BG_MAX_FRAMES`

## v2.0.0 {#v2-0-0}

SnapOtter 2.0 เปลี่ยนชุดเครื่องมือภาพให้เป็นชุดจัดการไฟล์เต็มรูปแบบ มีเครื่องมือกว่า 200 ตัวใน 5 รูปแบบ (รูปภาพ วิดีโอ เสียง PDF และไฟล์) สร้างใหม่บน Postgres 17 และคิวงานที่ใช้ Redis พร้อมคำสั่งเดียว `docker run` นี่เป็นรุ่นหลัก อ่านการเปลี่ยนแปลงที่ทำให้ใช้งานร่วมกันไม่ได้ก่อนอัปเกรดจาก 1.x

### ฟีเจอร์ใหม่ {#new-features}

- **เครื่องมือใหม่สี่รูปแบบ** วิดีโอ เสียง PDF และไฟล์ เข้ามาร่วมกับรูปภาพ ทำให้แคตตาล็อกมีเครื่องมือกว่า 200 ตัว
- **งานเบื้องหลังที่คงทน** คิวที่ใช้ Redis (BullMQ) รันทุกเครื่องมือเป็นงานที่ติดตามได้ พร้อมความคืบหน้าสดผ่าน SSE
- **โหมดคอนเทนเนอร์เดียวแบบครบในตัว** `docker run` เพียงคำสั่งเดียวบูตอินสแตนซ์ที่สมบูรณ์พร้อม Postgres และ Redis แบบฝังตัว
- **ชุด AI ตามต้องการ** การลบพื้นหลัง OCR การถอดเสียง การอัปสเกล การตรวจจับและปรับปรุงใบหน้า ตัวลบวัตถุ การใส่สี และการฟื้นฟูภาพถ่าย ติดตั้งได้จาก UI ตรวจจับการเร่งด้วย GPU ตามเฟรมเวิร์ก
- **Sign PDF** วาด พิมพ์ หรืออัปโหลดลายเซ็น แล้ววางบน PDF ในเบราว์เซอร์
- **Automate** ตัวสร้างไปป์ไลน์แบบภาพที่เชื่อมเครื่องมือเข้าด้วยกัน พร้อมแม่แบบสำเร็จรูปเก้าแบบ
- **ค่าที่ตั้งไว้ล่วงหน้าสำหรับการแปลงในคลิกเดียว 83 แบบ** ตัวแปลงเฉพาะอย่าง JPG-to-PNG, MP4-to-GIF และอื่น ๆ พร้อมการค้นหาแบบคลุมเครือ
- **ตัวแก้ไขภาพแบบเลเยอร์** ตัวแก้ไขที่ขับเคลื่อนด้วย Konva ที่ `/editor` พร้อมแปรง รูปทรง การปรับแต่ง ฟิลเตอร์ และ curves
- **ไลบรารีไฟล์** บันทึกผลลัพธ์ใดก็ได้และนำกลับมาเป็นอินพุตของเครื่องมืออื่น
- เครื่องมือที่ปักหมุด การซูมและแพนในแคนวาส 21 ภาษา และความสามารถระดับเอ็นเตอร์ไพรส์ (OIDC/SSO, SAML, SCIM, พื้นที่จัดเก็บ S3, สิทธิ์รายเครื่องมือ, การส่งออกบันทึกการตรวจสอบ, distributed tracing)

### การปรับปรุง {#improvements}

- ยกเลิกกระบวนการที่กำลังรันได้ (#137)
- ถอดรหัส RAW ความละเอียดเต็มผ่าน LibRaw รวมถึง DNG (#289)
- การติดตั้งแบบไม่ใช่ root และ UID แปลกปลอม (TrueNAS, Unraid, OpenShift, PUID/PGID) (#230, #127)
- ตรวจจับการติดตั้ง AI ได้แม่นยำและกระบวนการติดตั้งที่เข้มงวดขึ้น (#214, #352)
- เสริมความเป็นส่วนตัว ไม่มีการส่งข้อมูลออกไปบุคคลที่สามโดยอัตโนมัติ พร้อมโหมดออฟไลน์เข้มงวดที่เป็นทางเลือก
- ปุ่มข้อเสนอแนะเปิดตลอดเวลา แม้ปิดการวิเคราะห์ข้อมูล

### การแก้ไขข้อบกพร่อง {#bug-fixes}

- `RATE_LIMIT_PER_MIN=0` ปิดการจำกัดอัตราสำหรับเส้นทางเครื่องมืออีกครั้ง (#271)
- ซ่อมพาธ AI virtualenv ภายในอิมเมจ Docker (#390)
- เข้ากันได้กับ sharp 0.35.2 ขึ้นไป (#362)
- แก้เลย์เอาต์ตัวแก้ไขภาพ ไม้บรรทัด พฤติกรรมการเติม แถบข้าง และขนาดแคนวาส (#258, #259)
- แปลภาษาอิตาลีให้สมบูรณ์ (#231, #206, #425)
- Audio normalize และ loudnorm คงอัตราสุ่มตัวอย่างของต้นฉบับ
- เสริมความแข็งแกร่งต่อ SSRF การจับคู่ IPv6 CIDR แบบตัวเลข และการสแกน URL ล่วงหน้าที่กว้างขึ้น (#287)
- PDF ที่สร้างขึ้นถูกประทับ SnapOtter เป็น Producer
- mediapipe ติดตั้งได้บน Python 3.13 และ Debian 13

### การเปลี่ยนแปลงที่ทำให้ใช้งานร่วมกันไม่ได้ {#breaking-changes}

2.0 แทนที่ฐานข้อมูล SQLite แบบฝังด้วย Postgres 17 และเพิ่ม Redis 8 สำหรับคิวงาน ข้อมูล 1.x ของคุณย้ายโดยอัตโนมัติในการบูตครั้งแรก แต่สแตกคอนเทนเนอร์เปลี่ยนไป ดังนั้นให้สำรองวอลุ่ม `/data` ทั้งหมดก่อน (1.x รัน SQLite ในโหมด WAL ข้อมูลที่คอมมิตแล้วจึงมักอยู่ใน `snapotter.db-wal`) จากนั้นเลือกอิมเมจคอนเทนเนอร์เดียว (Postgres และ Redis แบบฝังตัว ใช้ root เท่านั้น) หรือสแตก Compose (แอปพร้อม Postgres 17 และ Redis 8) ดู[คู่มือการย้ายข้อมูล](https://github.com/snapotter-hq/SnapOtter/blob/main/MIGRATING.md)และ[คู่มือการอัปเกรด](/th/guide/upgrading)

```bash
docker pull snapotter/snapotter:2.0.0
```

หรือใช้ Docker Compose

```bash
docker compose pull && docker compose up -d
```

## v1.17.0 {#v1-17-0}

เครื่องมือใหม่ห้าตัว ตัวแก้ไขภาพเต็มรูปแบบ การเข้าสู่ระบบ SSO และ 20 ภาษา ควรแยกเป็นสามรุ่น แต่ก็เป็นอย่างที่เห็น

### ฟีเจอร์ใหม่ {#new-features-3}

- **ตัวแก้ไขภาพ** - เลเยอร์ แปรง รูปทรง การปรับแต่ง ฟิลเตอร์ curves และแป้นพิมพ์ลัด ทำงานในเบราว์เซอร์ของคุณ ประมวลผลบนฮาร์ดแวร์ของคุณ
- **การยืนยันตัวตนแบบ OIDC / SSO** - เข้าสู่ระบบด้วย Google, GitHub, Okta หรือผู้ให้บริการ OpenID Connect ใดก็ได้ ตั้งตัวแปรสภาพแวดล้อมไม่กี่ตัว แล้วทีมของคุณใช้บัญชีเดิมได้
- **ตัวสร้างมีม** - แม่แบบในตัว 100 แบบ พร้อมการเรนเดอร์ข้อความด้วย opentype.js หรืออัปโหลดภาพของคุณเอง
- **Beautify** - ใส่ภาพหน้าจอเข้าไป แล้วได้ภาพที่ขัดเกลาออกมา มีกรอบอุปกรณ์ (macOS, Windows, เบราว์เซอร์) เงา การไล่สี และค่าที่ตั้งไว้ล่วงหน้าสำหรับโซเชียลมีเดีย
- **การจำลองตาบอดสี** - ดูตัวอย่างว่าภาพเป็นอย่างไรสำหรับ protanopia, deuteranopia, tritanopia และภาวะการมองเห็นสีบกพร่องอื่น ๆ
- **ตัวแก้ความโปร่งใสของ PNG** - ตรวจจับ PNG ที่โปร่งใสปลอมและแก้ด้วย BiRefNet HR-matting พร้อมการลบลายน้ำที่เป็นทางเลือกผ่าน LaMa inpainting
- **ขยายแคนวาสด้วย AI** - ขยายขอบเขตภาพด้วยการเติมโดย AI มีสามระดับคุณภาพ (เร็ว สมดุล คุณภาพ) ขึ้นอยู่กับว่าคุณยอมแลกเวลา GPU มากเพียงใด
- **20 ภาษา** - อาหรับ จีน (ตัวย่อ/ตัวเต็ม) เช็ก ดัตช์ ฝรั่งเศส เยอรมัน ฮินดี อินโดนีเซีย อิตาลี ญี่ปุ่น เกาหลี โปแลนด์ โปรตุเกส รัสเซีย สเปน ไทย ตุรกี ยูเครน เวียดนาม รองรับ RTL สำหรับภาษาอาหรับ
- **นำเข้าจาก URL** - วาง URL ลงในช่องวางไฟล์ หรือนำเข้าจำนวนมากจากรายการ ดึงข้อมูลฝั่งเซิร์ฟเวอร์พร้อมการป้องกัน SSRF
- **ตัวลบหลายไฟล์** - วาดมาสก์สำหรับลบข้ามหลายภาพ ประมวลผลทั้งหมดด้วยคลิกเดียว เส้นที่วาดคงอยู่ต่อภาพ
- **นำเข้า/ส่งออกไปป์ไลน์** - บันทึกชุดเครื่องมือเป็น JSON และแบ่งปันกับผู้อื่น
- **รูปแบบ RAW ของกล้องใหม่ 17 รูปแบบ** ผ่าน exiftool พร้อมอินพุต QOI, JP2, EPS, DDS, CUR, DPX, FITS, PPM/PGM/PBM, SVGZ และ APNG โคเดกเอาต์พุตใหม่สำหรับ BMP, ICO, JP2, QOI การส่งออก AVIF, TIFF, GIF, JXL และ PSD กู้คืนจากสาขาที่เคยสูญหาย

### การปรับปรุง {#improvements-2}

- **การปรับปรุงภาพ** - แทนที่ไปป์ไลน์เดิมด้วย CLAHE + normalise + gamma สวิตช์ Deep Enhance ใหม่ใช้โมเดล AI เพื่อผลที่เข้มข้นกว่า
- **Restore photo** - เขียนการตรวจจับรอยขีดข่วนใหม่ด้วยการกรอง Otsu 8 มุม LaMa inpainting รันที่ความละเอียดดั้งเดิมแล้ว
- **รูปแบบแปลกใหม่ทุกที่** - OCR, image-to-PDF, ตัวสร้าง favicon, composition, stitch และ vectorize ถอดรหัส HEIC, RAW, PSD ได้แล้ว
- **Compress** - ความคลาดเคลื่อนของขนาดเป้าหมายแคบลงจาก 5% เป็น 1% ขนาดเป้าหมายเป็นโหมดเริ่มต้น เพิ่มปุ่มปรับค่าและตัวเลือกหน่วย KB/MB
- **ล้าง Sentry** - กรองเหตุการณ์ที่ไม่ต้องดำเนินการ 644 รายการ ข้อผิดพลาดจริงได้รับการจัดการอย่างเหมาะสมแล้ว
- **การตรวจจับ GPU** - การวินิจฉัยที่ดีขึ้นสำหรับคอนเทนเนอร์ที่มี CUDA แต่ไม่มี nvidia-smi
- **โหมดปิดการยืนยันตัวตน** - ผู้ใช้นิรนามถูกเพิ่มในฐานข้อมูลพร้อมบทบาทผู้ดูแลระบบ API key ไปป์ไลน์ และไฟล์ผู้ใช้ไม่พังจากข้อจำกัด FK อีกต่อไป
- **การทดสอบใหม่กว่า 2,705 รายการ** ครอบคลุม unit, integration และ E2E

### การแก้ไขข้อบกพร่อง {#bug-fixes-3}

- Upscale บน CPU ไม่หมดเวลาบนกล่อง NAS และฮาร์ดแวร์พลังงานต่ำอีกต่อไป
- โลโก้ QR code ไม่ทำให้ตัวอย่างหายไปถาวรอีกต่อไป
- แก้การล้นของ crop สำหรับภาพแนวตั้งที่สูง
- ไฟล์ TIFF ที่มีอัลฟาบังคับเอาต์พุต PNG อย่างถูกต้องแทนที่จะเสียหาย
- การถอดรหัส HDR/EXR แปลงเป็น 8 บิตก่อน CLAHE แก้ความล้มเหลวในการถอดรหัส
- บัฟเฟอร์อินพุตจุดสำคัญใบหน้าแปลงเป็น PNG ก่อนส่งให้ Python sidecar แก้การขัดข้อง
- Find duplicates จัดการแบตช์ที่มีหลายรูปแบบและข้อผิดพลาดของเครือข่าย
- ตัวอย่าง Beautify อัปเดตแบบเรียลไทม์
- แถบความคืบหน้าสำหรับ stitch และ vectorize
- SVG-to-raster จัดการ SVGZ
- แก้ชื่อไฟล์ที่ไม่ใช่ ASCII ผ่านเฮดเดอร์ X-File-Results ที่เข้ารหัสแบบ percent
